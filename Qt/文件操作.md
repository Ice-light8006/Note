- `QDir` → 找东西（目录结构）
- `QFile` → 读写东西（文件内容）
- `QFileInfo` → 看东西（属性信息）
# `QDir`

假设目录结构：
```
D:/Test
├── main.cpp
├── a.txt
├── folder1
│   └── b.cpp
```
目录里存的是"条目(entry)"
每一个都是一个"名字":
```
.
..
main.cpp
a.txt
folder1
```

>`"."`和`".."`本质：
>`"."`:当前目录
>`".."`:上一级目录

它们不是文件，是系统内置的导航入口
`Qdir dir("D:/Test");`
表示的意思是：我现在站在D:/Test这个文件夹门口
## `entryList`
`dir.entryList(...)`，等价于“帮我看看这个文件夹里有哪些东西”
假如你调用dir.entryList();
其返回的结果为：
```
.
..
main.cpp
a.txt
folder1
```
# 过滤器（`Filters`）
常见的枚举值：
`QDir::Dirs`
`QDir::Files`
`Qdir::NoDotAndDotDot`
......
本质是“我只想要符合某些条件的条目”

使用方法：
1. 在`QDir`实例上设置
```cpp
#include <QDir>
#include <QDebug>

int main() {
    QDir dir("/path/to/your/directory");

    // 设置过滤条件：只列出文件，不显示 . 和 ..
    // 通过 | 可以设置为同时满足多个枚举规则
    dir.setFilter(QDir::Files | QDir::NoDotAndDotDot);

    // 获取并打印条目列表
    QStringList entries = dir.entryList();
    for (const QString &entry : entries) {
        qDebug() << "找到文件:" << entry;
    }

    return 0;
}
```
2. 直接在`entryList`或者`entryInfoList()`函数中传递
```cpp
#include <QDir>
#include <QDebug>

int main() {
    QDir dir("/path/to/your/directory");

    // 直接在获取列表时传递过滤器
    QStringList entries = dir.entryList(QDir::Files | QDir::NoDotAndDotDot);

    for (const QString &entry : entries) {
        qDebug() << "找到文件:" << entry;
    }

    return 0;
}
```
3. 直接创建`Filter`实例
```cpp
#include <QDir>
#include <QDebug>

int main() {
    // 1. 直接声明并初始化一个 filters 变量
    QDir::Filters myFilters = QDir::Files | QDir::NoDotAndDotDot;

    // 2. 将它传递给 QDir 的 setFilter 方法
    QDir dir("/some/path");
    dir.setFilter(myFilters);

    // 3. 也可以直接用于 entryList
    QStringList entries = dir.entryList(myFilters);
    qDebug() << entries;

    return 0;
}
```
# 递归遍历路径
```cpp
traverse(path+"/"+name)
```
本质："当前目录+子项名字"拼出一个子路径然后递归进去
这里path是你当前正在处理的目录路径，比如：`traverse("D:/Test");`，那么`path == "D:/Test"`
而这里`name`就是`entryList()`里返回的条目名字
但是，如果`name = ".."`，那么`path+"/" +name变成D:/Test/..`，实际等价于：`D:/`
于是递归进了“上一级目录”这样就会导致向上无限递归造成爆炸
如果`name = "."`，那么就会回到当前目录，到当前目录了又还有 `"."`，又会回到当前目录，还会造成无限递归导致爆炸
所以我们可以在`entryList`的形参传入`NoDotAndDotDot`，去除"."和".."
# `QFile`
`QFile`通常用来读文件、写文件
例如：
```cpp
QFile file("a.txt");
file.open(QIODevice::ReadOnly);
```
# `QFileInfo`
`QFileInfo`非常常用，比如你先执行：
`QFileInfo info("D:/Test/main.cpp");`
然后你就可以问：
```cpp
info.isDir(); // main.cpp是不是文件夹
info.isFile(); // main.cpp是不是文件
info.fileName(); // main.cpp的名字
info.absoluteFilePath(); // main.cpp的完整路径
```
注意：`QFileInfo`不保证文件一定存在，使用前最好先判断文件是否存在
