# 类的静态成员变量与静态成员函数
一个类中，被`static`关键字标识的成员变量/成员函数称为静态成员变量/成员函数
## 静态成员变量
在定义成员变量时，加上`static`关键字，这个变量变成静态成员变量
静态成员变量的主要作用：该类的所有实例化对象共享这个静态成员变量
```cpp
class Point
{
public:
	static int count;
	int x;
	int y;
};
```
注意，不能这样写
```cpp
class Point
{
public:
	static int count = 0;
	int x;
	int y;
};
```
对于非 `inline`、非 `const` 的普通静态数据成员，不能直接在类内初始化。这样是错的。
在类内写
```cpp
static int count
```
意思是，在类内声明一个静态成员变量`count`,但是还需要在类外去定义它。
因此正确的初始化是这样的：
```cpp
class Point
{
public:
	static int count;
	int x;
	int y;
};

int Point::count = 1;
```
这个类`Point`的所有实例化对象共享这个静态成员变量
可以使用类名来访问这个变量
```cpp
cout << Point::count << endl;
```
这个打印结果为1
也可以通过类名来修改这个静态成员变量的值
```cpp
Point::count = 10;
cout << Point::count << endl; // 打印结果为10
```
这也说明静态成员变量不属于某一个具体的对象
也可以通过实例化对象的名字来访问
```cpp
Point p1;
Point p2;

cout << p1.count << endl; // 结果为1

p1.count++;

cout << p2.count << endl; // 结果为2
```
这个程序可以说明所以类对象共享静态成员变量
静态成员变量具有**静态存储期**（static storage duration），它的存储持续整个程序运行期间，不会因为某个 `Point` 对象被销毁而消失。
## 静态成员函数
### 静态成员函数的定义
在类内声明成员函数时，使用 `static` 关键字修饰，这个函数就成为静态成员函数。
```cpp
class Point
{
public:
    static int count;

    static void printCount();
};

int Point::count = 0;

void Point::printCount()
{
    cout << count << endl;
}
```
注意：
- `static` 只需要在类内声明时使用，类外定义时不需要重复添加。
- 静态成员函数属于类，不依赖于某个具体对象。
- 所有对象调用的是同一个静态成员函数，而不是每个对象拥有一个独立的函数副本。
### 静态成员函数的访问方式
与静态成员变量类似，静态成员函数也有两种访问方式。
方式一：通过类名访问（推荐）
```cpp
Point::printCount();
```
方式二：通过对象访问
```cpp
Point p1;
Point p2;

p1.printCount();
p2.printCount();
```
两种访问方式都是合法的。
不过，推荐使用 `类名::函数名()`，因为它更能体现静态成员函数不依赖具体对象的特点。
### 静态成员函数没有`this`指针
这是静态成员函数与普通成员函数最重要区别
因为静态成员函数不属于某一个实例化的对象，所以不存在`this`指针的概念
### 静态成员函数只能直接访问静态成员
```cpp
class Point
{
public:
    static int count;
    int x;
    int y;

    static void print()
    {
        cout << count << endl; // 正确
        cout << x << endl;     // 错误
        cout << y << endl;     // 错误
    }
};
```
但是只是不能直接访问非静态成员，不是完全不能访问
如果明确指定某个对象，就可以访问该对象的非静态成员。
例如
```cpp
class Point
{
public:
    static int count;
    int x;

    static void printX(const Point& p)
    {
        cout << p.x << endl; // 正确
    }
};
```
记住这张表即可

| 访问关系            | 是否允许直接访问 |
| --------------- | -------- |
| 静态成员函数 → 静态成员变量 | 是        |
| 静态成员函数 → 普通成员变量 | 否        |
| 静态成员函数 → 静态成员函数 | 是        |
| 静态成员函数 → 普通成员函数 | 否        |
| 普通成员函数 → 静态成员   | 是        |
| 普通成员函数 → 普通成员   | 是        |
# 友元函数
友元函数可以帮助我们在类外访问类的私有成员函数
例如
```cpp
class Point
{
public:
private:
int x;
int y;
}

float Distance(const Point &p1,const Point &p2)
{
	float dis = pow(p1.x-p2.x,2)+pow(p1.y-p2.y,2);
	dis = sqrt(dis);
	return dis;
}
```
这样写会报错，因为你在类的外部，全局函数`Distance`中访问了类的私有成员
这时候就可以把全局函数`Distance`标记为类的友元函数
```cpp
class Point
{
public:
	friend float Distance(const Point &p1,const Point &p2);
private:
	int x;
	int y;
}

float Distance(const Point &p1,const Point &p2)
{
	float dis = pow(p1.x-p2.x,2)+pow(p1.y-p2.y,2);
	dis = sqrt(dis);
	return dis;
}
```
这样就可以在类内指定的一个友元函数中访问该类的私有变量

## 常对象
创建对象的时候使用`const`关键字
例如
```cpp
class Point
{
public:
	Point(int x = 0,int y = 0);
private:
	int x;
	int y;
}

const Point p1;//生命一个常对象p1
```
常对象在程序运行期间不允许被修改。即该对象的数据成员值在整个生存期内不能被修改，因此常对象必须进行初始化且不能被更新。
在C++的基本数据类型中
```cpp
const int x = 10;
x = 20; //错误，不能修改常量
```
第二行会报错，因为不能修改常量
访问对象成员的方式有两种，一种是通过对象名访问，另一种是通过对象成员函数来访问。
第一，为了防止通过对象名修改常对象的数据成员，在常对象中，常对象的数据成员都被视为常量。
第二，为了防止通过对象成员函数修改常对象的数据成员，无法通过常对象调用该常对象的普通成员函数
## 常成员函数
在一个类中，被`const`修饰的成员函数称为常成员函数
例如
```cpp
class Point
{
public:
	void print() const; //常成员函数
private:
}

void Point::print() const //实现部分也必须带const关键字
{
}
```
这里有几个注意点
- `const`关键字是函数定义的一部分，类中生命有`const`，在外部实现时，也需要加上`const`修饰
- `const`也可以用来作为对函数重载的区分。例如下面这个例子
```cpp
class Point
{
public:
	void print();
	void print() const; //常成员函数
private:
}


void Point::print()
{
}

void Point::print() const //实现部分也必须带const关键字
{
}
```
这里这两个函数
```cpp
void Point::print();
void Point::print() const;
```
他们会被认为是同一个函数`print`的重载（函数类型不同，一个是`void`,一个是`const void`）
-  在常成员函数中不能更新任何数据成员，也不能调用该类中没有用`const`修饰的成员函数，**只能调用常成员函数和使用常数据成员**
