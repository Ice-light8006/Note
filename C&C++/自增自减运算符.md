# 例1
```c
#include <stdio.h>

int main(int argc,char** argv)
{
	int i = 2;
	int num = (i++) + (i++) + (i++) + (i++);
	printf("%d\n",num);
	return 0;
}
```
这个`num`的值其实并不一定，根据编译器的不同，会有不同的结果。
大致有两种规则
## 以分号作为结束
此时`i`的值会先全部用作计算，然后直到遇到分号再做四次自增，相当于
```c
num = 2 + 2 + 2 + 2;
i++;
i++;
i++;
i++;
```
此时
```c
num = 8;
i = 6;
```
## 每次遇到自增符号都先把上一次自增做出来
计算步骤如下
```
num = (i++) + (i++) + (i++) + (i++)
num = 2 + (i++) + (i++) + (i++)
i++;
num = 2 + 3 + (i++) + (i++);
i++;
num = 2 + 3 + 4 + (i++);
i++;
num = 2 + 3 + 4 + 5;
i++;
```
最后
```
num = 14
i = 6
```

>**这段代码是未定义行为，实际结果完全由编译器内部实现决定，无法预测且不可移植。上面的“8”和“14”只是在特定老式编译器上观察到的两种典型输出，任何正式代码都不应该这样写。**

# 例2
```c
#include <stdio.h>

int main(int argc,char** argv)
{
	int i = 2;
	int num = (++i) + (++i) + (++i) + (++i);
	printf("%d\n",num);
	return 0;
}
```
某一些编译器会把这个当成一个左结合的加法，即
```
(((++i) + (++i)) + (++i)) + (++i)
```
那么步骤就是
```
先左结合((++i) + (++i)) + (++i) + (++i)
最左边那个整体两次加法
++i;
++i;
此时i=4
num = 4 + 4 + (++i) + (++i)
即
num = 8 + (++i) + (++i)
然后再左结合
num = (8 + (++i)) + (++i)
先计算++i
此时i = 5
然后
num = (8 + 5) + (++i)
即
num = 13 + (++i)
然后再计算++i
此时i = 6
num = 13 + 6
那么num = 19
```
>**警示：以上解释仅针对一些老式编译器的一种内部实现，属于未定义行为，任何正式代码都不应该这样写。**
# 例3
```c
#include <stdio.h>

int main()
{
    int i = 2;
    printf("%d,%d,%d,%d,%d",++i,i++,i,++i,i++);
    return 0;
}
```
首先我们要知道一个知识点，函数传参是从右往左传参的
## Turbo C 等老式编译器的求值规则（经典解释）
1. **从右向左扫描参数**，遇到 `++i` 或 `i++` 就先执行自增，但后置 `++` 会用一个临时变量“记住”自增前的值。
2. 所有的自增都执行完后，`i` 变成了最终值（这里是 6）。
3. 然后再**从左到右依次取各参数的值**去压栈：
- 对于 `++i`，直接取 `i` 的最终值（6）。
- 对于 `i++`，取之前记下来的临时值。
- 对于普通的 `i`，取当前 `i` 的值（此时已经是 6）。
按照这个规则，我们跑一遍这个代码
```
最右边有一个i++，直接取i当前的值
等价于printf("%d,%d,%d,%d,%d",++i,i++,i,++i,2);
然后i++，变成3
然后遇到++i，直接换成i，并把i++，i变成4
printf("%d,%d,%d,%d,%d",++i,i++,i,i,2);
然后遇到i，不动这个，接着往左走，遇到i++，换成i当前的值4
printf("%d,%d,%d,%d,%d",++i,4,i,i,2);
然后i自增，此时i=5
再向左走，遇到++i，直接换成i，然后i自增，此时i=6
printf("%d,%d,%d,%d,%d",i,4,i,i,2);
之后再用i的最终值替换这里面的所有的i，得到
printf("%d,%d,%d,%d,%d",6,4,6,6,2);
那么打印结果就是：
6,4,6,6,2
```
总结：
```
遇到i++就用当前i的值代替然后把i自增
遇到++i就直接用i代替，然后再把i自增，最后执行完这一行语句之后再用i的最终值替换掉这个i
```
>**警示：以上解释仅针对 Turbo C 等老式编译器的一种内部实现，属于未定义行为，任何正式代码都不应该这样写。**
# 例4
```c
#include <stdio.h>
  
int main()
{
    int i = 2;
    int j = 2;
    int k = 2;
  
    int num1 = (++i) + (++i);
    int num2 = 1 + (++j) + (++j);
    int num3 = 0 + (++k) + (++k);
  
    printf("num1 = %d\n",num1);
    printf("num2 = %d\n",num2);
    printf("num3 = %d\n",num3);
    return 0;
}
```
这属于未定义行为，在现代编译器绝对会给你报警告，但是某些老式编译器也许会给你编译成功并有输出结果还不报警告。这个例子讨论起来没有任何意义，列出来只是让读者知道有这么个东西，不必纠结这个东西。

# 总结
上述四个例子仅用来参考、理解和学习C语言，实际写项目时千万不要这么写，这些代码的可读性非常差。
我们要避免在表达式里混用自增运算符，例如下面这个代码
```c
int i = 2;
int sum = (++i) + 5;
```
在我们实际写项目的时候，一定要写成下面的形式
```c
int i = 2;
i++;
int sum = i + 5;
```
这样书写的代码可读性大大提升。
另外，上面所说的示例对自减运算符也适用。
