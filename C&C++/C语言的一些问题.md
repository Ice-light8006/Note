2. C语言属于面向结构的语言，什么是面向结构语言？特点？（优点：灵活，开发效率高！缺点：代码复用性、维护、拓展性差！）---写代码原则：高内聚、低耦合
3. C语言语法标准：C语言之父是**丹尼斯·里奇**，1979年C语言出了第一个版本k&R C，后面又出了C89，C99，C11，C17。但是现在用的最多的是C99，所有的编译器都支持C99。后面的C11、C17标准是微软主导的
# C语言的数据类型
数据类型：基本数据类型、复合数据类型
基本数据类型:
- 整型：`int`,`short`,`long`
- 浮点型：`float`,`double`
- 字符：`char`
- 空类型：`void`
复合数据类型：
数组、结构体、共用体（联合体）、枚举、指针
