# 对指针的理解
## 什么是指针？
指针是一种数据类型，它可以定义一个用来保存内存地址的变量。由于内存地址是固定长度，所以指针变量的长度是固定长度。不同地址的步长不一样，需要不同指针类型的变量来保存
```c
int * p;//整型指针变量
```
可以这样解释：
- p是一个变量，保存的是内存地址，该地址上的数据是整型类型的。
```c
char * p;//字符型指针变量
```
可以这样解释：
- p是一个变量，保存的是内存地址，该地址上的数据是字符型类型的。
## 内存地址是固定长度
看这个代码
```c
#include <stdio.h>

int main()
{
    printf("sizeof(int*) = %d\n",sizeof(int*));
    printf("sizeof(short*) = %d\n",sizeof(short*));
    printf("sizeof(long*) = %d\n",sizeof(long*));
    printf("sizeof(double*) = %d\n",sizeof(double*));
    printf("sizeof(char*) = %d\n",sizeof(char*));
}
```
32位系统结果全都是4
64位系统结果全都是8
这就是因为内存地址是固定长度
## 地址分为了不同类型的原因
一句话：不同类型的指针保存不同步长的地址
指针有一个非常重要的属性，就是**步长**
步长就是做加一操作所移动的字节数
步长由保存的数据类型决定的
## 指针的作用
由于指针变量可以保存地址，所以可以直接操作地址。嵌入式开发中，可以直接操作硬件的寄存器地址，从而实现直接访问硬件。
## `p+n`-随机访问
数组的一个优点是可以随机访问。
假如知道数组名`a`，直接`a+n`就可以通过解引用来访问下标为`n`的元素
这是数组相对于链表来说的优点之一，链表想要访问就只能一个一个遍历沿着链表走
# `*`与`&`
- `*` - 间接运算符
- `&` - 取地址运算符
```c
int num = 5;
int *p = &num;
```
变量`num`占四个字节，这四个字节是连续的，每个字节对应一个内存地址。
变量占用的一段连续地址，`&`得到首地址。
对`0x1000`这个地址进行加一操作，仅仅是跳到下一个字节地址`0x1001`，但是对指针进行加一操作，虽然指针在这里是`0x1000`，但是加一之后会根据这个指针指向的数据的类型的大小来确定，而不是下一个地址。换句话说：
```c
int *p = (int*)0x1000;
```
那么：
```c
p+1
```
结果是：
```
0x1004
```
因为编译器知道
```c
p是int*
sizeof(int) = 4
```
所以
```c
p+1
```
实际上是：
```
0x1000+4
```
而不是
```
0x1000+1
```
换句话说：
>地址本身加1，就是增加一个字节
>但指针加1时，增加的字节数由指针所指向的数据类型决定。

再看刚开始给的例子：
```c
int num = 5;
int *p = &num;
```
这里第二行中的`&num`中的`&`取的是变量`num`的首地址，得到的就是`0x1000`，然后赋值给变量`p`，那么`p`内的数据就是`0x1000`，即：
```Plain Text
p = &num = 0x1000
```
先介绍一下**小端**
小端的规则：
- 低位字节存放在低地址，高位字节存放在高地址。
可以这样解释：
```Plain Text
num对应的内存空间：
 值     内存地址
 00     0x1003
 00     0x1002
 00     0x1001
 05     0x1000
 
p对应的内存空间（假设p对应的内存地址如下）
 值     内存地址
 00     0x2003
 00     0x2002
 10     0x2001
 00     0x2000
 
 这里p对应的内存空间上的值
 00 00 10 00
 每个数字对应一个十六进制数据，一个十六进制位对应4个bit，即：
 00000000 00000000 00010000 00000000
 对应内存地址0x00001000
 省略前面四个0，即0x1000 
 同时，p也有自己的内存地址，即0x2000到0x2003
```
几个容易混淆的语句：
```c
p++;//对p对应的空间的值+1
(*p)++;//对p指向的空间的值+1

*p://先取出变量p对应内存空间上储存的内存地址，然后根据这个内存地址找到这个地址对应的内存空间，然后取出这个内存空间上的值。
//即：取p指向的内存空间的值

p //p对应内存空间的值（注意是p对应内存空间，不是p指向的内存空间）
```

# 多级指针
先看二级指针
```c
int num = 5;
int *p = &num;
int **pp = &p;
```
用大白话描述：`pp`是一个变量，该变量保存一个内存地址，该变量保存的内存地址对应的内存空间上保存了一个内存地址，这个内存地址对应的内存空间又保存了一个`int`类型的数据。
即：`pp`指向`p`，`p`指向`num`
有如下关系式：
```
*pp = p = &num;
**pp = *p = num;
```
对于更多级的指针以此类推
```
num = *p = **pp = ***ppp = ...;
&num = p = *pp = **ppp = ...;
```
C89规定，这个`*`最多只能“套娃”32个
多级指针经常应用在函数传参的时候
# 指针之间的运算
## 赋值
指针之间可以赋值。
```c
#include <stdio.h>

int main(int argc,char **argv)
{
	int num = 0x12345678;
	char a = 'a';
	int *p1 = &num;
	char *p2 = &a;
	p1 = p2;//报错
	return 0;
}
```
这个代码会报一个警告，就是因为把指向`char`的指针赋值给了指向`int`的指针
整型指针加一跳4个字节，字符指针加一跳1个字节，`int*`与`char*` 是不一样的
短指针赋值给长指针：多取数据
长指针赋值给短指针：丢数据
所以一定要相同类型的指针之间赋值。
但是其实，如果非要把不同类型的指针进行赋值，也是可以的
看这个代码
```c
#include<stdio.h>
int main(int argc,char **argv)
{
    int cnt = 5;
    char c = 'a';
    char *pc = &c;
    int* pi = &cnt;
    printf("pc = %p\n",pc);
    printf("pi = %p\n",pi);
    pi = pc;
    printf("*pi = %d",*pi);
    return 0;
}
```
我跑出来测试的运行结果为：
```out
pc = 0061FF13
pi = 0061FF14
*pi = 1377
```
注：内存地址每次运行系统给这个程序分配的内存可能都不一样，我们以本次测试结果为例
这是为什么呢？
在这次测试环境下，初始内存空间和里面的数据如下（`'a'`的ASCII码为97，转换为十六进制为61）
```
  地址       值
0x61FF13    61
0x61FF14    05
0x61FF15    00
0x61FF16    00
0x61FF17    00
```
其中0x61FF13为`pc`指向的内存空间的首地址，0x61FF14为`pi`指向的内存空间的首地址
如果我们把`pc`的值赋值给`pi`，`pi`的值变为0x61FF13在解引用`pi`时，因为`pi`是一个`int`的指针，所以读取四个字节的地址的值，拼接后得到的十六进制数据为00000561，转换成十进制就是1377.
指针也可以进行自增操作，以及加上一个操作数的操作。表达的意思是跳你加的数字个步长
但是指针和指针之间不可以进行相加操作。
指针也可以进行减一个操作数的运算
注意，和加法不同，指针之间是可以直接进行相减操作的，得到的结果就是指针之间相隔了多少个元素
# `void*` - 万能指针
万能指针可以接收任何类型指针的值
万能指针不能进行解引用，因为它不知道该读取多少个字节
但是可以进行自增操作
```c
#include<stdio.h>

int main(int argc,char **argv)
{
	int cnt = 5;
	int *pi = &cnt;
	char c = 'a';
	char *pc = &c;
	void *p;
	
	//任何数据类型的变量都可以赋值给p
	p = pi;
	p = pc;
	
	int m = *p;//会报错，不能对万能指针进行解引用
	
	p++;//可以进行自增操作，步长为1
}
```
万能指针在使用时需要进行强制转换
```c
#include <stdio.h>

void* func()
{
	int num = 5;
	return &num;
}

int main(int argc,char **argv)
{
	//直接用一个void*来接收返回值，但是不能直接使用
	void* p = func();
	
	//需要强制转换才能使用
	int *pi = (int*)p;
	return 0;
}
```
类似的用法还有
```c
#include<stdio.h>
#include<stdlib.h>

int main(int argc,char **argv)
{
	//malloc返回的也是万能指针，需要进行强制转换
	char* ptr = (char *)malloc(sizeof(char)*100);
}
```
# 野指针
指向了一个无效、不确定或不可用内存地址的指针。
## 最典型的野指针：未初始化
未初始化的指针变量，栈上遗留的垃圾值，随机指向一块内存，一旦访问这块内存，非法访问，内存泄漏！！！导致内存错误
```c
int *p;
scanf("%d",p);
```
例如这个，`scanf("%d",p)`尝试输入一个数字然后修改`p`指向的内存空间上的值为你输入的数字。但是，`p`没有初始化，其值是栈上残留的垃圾值。有很大可能指向没有访问权限的内存空间，去访问`p`指向的内存空间就会发生运行时错误
**但是，这并不一定！** 如果我们的程序足够大，假如总共只有4G的空间，而我程序就已经占了2G的空间，然后栈上遗留的垃圾值给了`p`，这个`p`就极有可能恰好指向程序内部的内存空间，这就不会出现非法访问，可以修改`p`指向的空间为5。
所以，大型程序如果有未初始化的指针，极有可能这次运行不会有问题，下次再运行结果报错了。
这就是臭名昭著的**海森堡bug**
## 释放后继续使用
```c
int *p = malloc(sizeof(int));

free(p);

*p = 10;    // 错误
```
但是，这也不一定会报错
```c
int *p = malloc(sizeof(int));

printf("%p\n",p);

free(p);

printf("%p\n",p);
```
你会发现这两个`printf`打印的结果一模一样，但是为什么`free(p)`之后还是能打印出来`p`的值呢
这其实是因为`free(p)`只是单纯的告诉操作系统`p`指向的内存空间可以被分配给其它人，并没有把`p`置空，所以我们使用`free(p)`之后一定要把`p`置空
## 指向已经销毁的局部变量
```c
int* func()
{
    int num = 5;

    return &num;
}
```
函数返回后：
```
num已经不存在了
```
但是：
```
返回的地址还在
```
于是：
```
int *p = func();
```
得到的就是野指针。
## 和空指针的区别
```c
void *p = NULL;
```
此时：
```
p=0
```
这里空指针地址通常为
```
0x00000000
```
表示：
```
我不指向任何对象
```
