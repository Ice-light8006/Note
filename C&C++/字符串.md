## `strlen`的代码实现
```c
int my_strlen(const char* str)
{
    if(str==NULL)
    {
        return 0;
    }
    int len = 0;
    while(str[len]!='\0')
    {
        len++;
    }
    return len;
}
```

## `strncpy`的代码实现
首先要注意一下，`strncpy`的要求是，如果`n`的大小大于`src`的长度，那么剩下的位置要全部补为`'\0'`,而如果`src`的长度大于等于`n`的大小，那么就不会自动在结尾补充`'\0'`。这是一个容易被忽视的细节
```c
char *my_strncpy(char *dest, const char *src, int n)
{
    assert(dest != NULL);
    assert(src != NULL);
    assert(n >= 0);
    int index = 0;
    while (index < n && src[index] != '\0')
    {
        dest[index] = src[index];
        index++;
    }
    while (index < n)
    {
        dest[index] = '\0';
        index++;
    }
    return dest;
}
```

## `strncmp`的代码实现
```c
int my_strncmp(const char *str1, const char *str2, size_t n)
{
    assert(str1 != NULL);
    assert(str2 != NULL);

    size_t i = 0;
    while (i < n && str1[i] != '\0' && str2[i] != '\0' && str1[i] == str2[i])
    {
        i++;
    }

    // i == n代表已经比较完前n个字符，前n个字符完全相等
    if (i == n)
    {
        return 0;
    }

    return str1[i] - str2[i];
}
```
关于字符串的一个细节：
```c
char name[32];
```
在这样定义字符串时，这里的32是包括字符串结尾的`'\0'`的，也就是说虽然定义的字符串长度为32，实际上有效最大长度只有31

在定义字符串时如果同时进行初始化，`[]`内可以不写长度，例如
```c
char str[] = "hello world";
```
此时编译器会自动给这个字符数组分配大小，即字符串的实际大小加上尾部的`'\0'`，所以这个字符数组`str`对应的实际大小为12
但是这样初始化之后，数组`str`的大小就直接锁定为12，后面不可以再修改，例如下面这个示例
```c
char str[] = "hello world";

strcpy(str, "hi");                     // 安全，内容变为 "hi"
strcpy(str, "hello world,hello world");// 危险！编译通过，但运行时缓冲区溢出（这才是真正的“超过长度”错误）
```
另外，我们也绝对不允许下面这样只写了一个没有指明长度的字符数组定义而不进行初始化
```c
char str[];
```
# `double`的占位符
## 1. 输入（`scanf`）：必须是 `%lf`
当你要把用户输入的数据存进一个 `double` 类型的变量时，**只能用 `%lf`**（小写的 l 和 f）。
- **为什么？** `scanf` 需要知道你要往内存里写几个字节。`float` 通常是 4 个字节，对应的占位符是 `%f`；而 `double` 通常是 8 个字节，对应的占位符是 `%lf`。如果你对一个 `double` 变量用了 `%f`，`scanf` 只会往里写 4 个字节，导致数据严重错乱。
## 2. 输出（`printf`）：标准是 `%f`，但写 `%lf` 也可以
当你要打印一个 `double` 变量时，标准的写法其实是 **`%f`**。
- **为什么？** 因为 C 语言有一个古老的规则叫“默认参数提升”。在像 `printf` 这种参数数量可变的函数中，所有的 `float` 都会被自动升级（提升）为 `double` 再传进去。也就是说，在 `printf` 眼里，根本没有 `float`，大家全都是 `double`。所以用 `%f` 就可以统一处理了。
- **写了 `%lf` 会怎样？** 在 C99 标准之后，官方明确规定了在 `printf` 中 `%lf` 和 `%f` 是完全等价的。所以如果你为了好记，输出时也写了 `%lf`，程序依然能完美运行，不会报错。

# 例1
## 题目描述
输入5个数(含负数、小数)将它们按由小到大的顺序排列起来
提示：需要排数的数字通过参数传递进来，
例如：输入:./a.out  -1  2.1  -3  5  7 输出: -3 -1 2.1 5 7
### 代码实现
```c
#include <stdio.h>
#include <string.h>
#include <stdlib.h>

double stringToDouble(char *s)
{
    if (NULL == s)
    {
        printf("String is NULL\n");
        exit(1);
    }

    int i = 0;
    int dot = -1;
    int len = strlen(s);
    if (s[i] == '-')
    {
        i++;
    }

    // 先判断字符串是否合法
    if (len == 0)
    {
        printf("String is not valid!\n");
        exit(1);
    }
    if (0 == strcmp("-", s))
    {
        printf("String is not valid!\n");
        exit(1);
    }
    if (0 == strcmp(".", s))
    {
        printf("String is not valid!\n");
        exit(1);
    }
    if (0 == strcmp("-.", s))
    {
        printf("String is not valid!\n");
        exit(1);
    }
    int dotcnt = 0;
    for (int t = i; t < len; t++)
    {
        if (s[t] == '.')
        {
            dotcnt++;
        }
        else if (!(s[t] >= '0' && s[t] <= '9'))
        {
            printf("String is not valid!\n");
            exit(1);
        }
    }
    if (dotcnt >= 2)
    {
        printf("String is not valid!\n");
        exit(1);
    }

    for (; i < len; i++)
    {
        if (s[i] == '.')
        {
            dot = i;
            break;
        }
    }

    // 处理没有小数点的情况
    if (dot == -1)
    {
        return atoi(s);
    }

    int tmp = len - 1 - dot;
    int j;
    for (j = dot + 1; s[j] != '\0'; j++)
    {
        s[j - 1] = s[j];
    }
    s[j - 1] = s[j];
    double ans = (double)atoi(s);
    while (tmp > 0)
    {
        ans /= 10.0;
        tmp--;
    }
    return ans;
}

void quickSort(int left, int right, double *a)
{
    if (left >= right)
    {
        return;
    }
    int start = left;
    int end = right;
    double pivot = a[left];
    while (left < right)
    {
        while (left < right && a[right] >= pivot)
        {
            right--;
        }
        a[left] = a[right];
        while (left < right && a[left] <= pivot)
        {
            left++;
        }
        a[right] = a[left];
    }
    a[left] = pivot;
    quickSort(start, left - 1, a);
    quickSort(left + 1, end, a);
}

int main(int argc, char **argv)
{
    double s[argc];
    for (int i = 1; i < argc; i++)
    {
        s[i] = stringToDouble(argv[i]);
    }
    quickSort(1, argc - 1, s);
    for (int i = 1; i < argc; i++)
    {
        printf("%lf ", s[i]);
    }
    return 0;
}
```

# 例2
编写一个C函数,将”I am from shanghai ”倒置为”shanghai from am I”,即将句子中的单词位置倒置,而不改变单词内部结构.
## 代码实现
```c
#include <stdio.h>
#include <string.h>

void reverse(char* str,int left,int right)
{
    while(left<right)
    {
        str[left] = str[left] ^ str[right];
        str[right] = str[left] ^ str[right];
        str[left] = str[left] ^ str[right];
        left++;
        right--;
    }
}

int main()
{
    char str[1024];
    gets(str);
    int len = strlen(str);
    reverse(str,0,len-1);
    int cur = 0;
    int bef = -1;
    for(int i = 0;i<=len;i++)
    {
        if(str[i]==' '||str[i]=='\0')
        {
            cur = i;
            reverse(str,bef+1,cur-1);
            bef = cur;
        }
        
    }
    printf("%s\n",str);
    return 0;
}
```
# 寻找子串算法
从一个字符串A中查找某一个特定子串B的位置的算法
介绍这个算法之前，我们先介绍两个名词
这里字符串A称为**文本串**（也叫**主串**）
而子串B称为**模式串**
下面的论述中，我们统一规定主串命名为`txt`，模式串命名为`pattern`
## 暴力算法
```c
int search(const char *txt, const char *pattern, int *buf)
{
    int len_txt = strlen(txt);
    int len_pat = strlen(pattern);
    if (len_pat == 0)
    {
        return 0;
    }
    int index = 0;

    for (int i = 0; i <= len_txt - len_pat; i++)
    {
        int flag = 1;
        for (int j = 0; j < len_pat; j++)
        {
            if (txt[i + j] != pattern[j])
            {
                flag = 0;
                break;
            }
        }
        if (flag)
        {
            buf[index++] = i;
        }
    }

    return index;
}
```
暴力算法复杂度为$O(mn)$
## KMP算法
### 原理剖析
KMP算法由Knuth,Morris,Pratt三位大佬于1977年联合发表，算法名字取自三个人的首字母，是一个更高效的寻找子串的算法
暴力算法有一个很大的缺陷，假如说我们的主串和模式串是这样的
```
txt
AAAAAAAAAAAAAAAAB

pattern
AAAAB
```
我们肉眼可以一眼看出来，只有`pattern`放在最后才能够匹配
但是，暴力算法会傻乎乎的从头到尾匹配一遍
先看这样能否匹配
```
AAAAAAAAAAAAAAAAB
AAAAB
```
不行，然后再看这样能不能匹配
```
AAAAAAAAAAAAAAAAB
 AAAAB
```
还是不行，再看这样能不能匹配
```
AAAAAAAAAAAAAAAAB
  AAAAB
```
还是不可以
以此类推，从头到尾匹配了一遍。
暴力算法的本质就是：从主串的第一个字符与模式串的第一个字符开始，一一比对主串与模式串的字符，当发现有不匹配的字符时，主串回溯到第二个字符，然后模式串回溯到第一个字符，再进行比对，再发现有不匹配的字符时，主串回溯到第三个字符，然后模式串回溯到第一个字符......以此类推
假如主串的长为`n`，子串的长为`m`，那么时间复杂度最坏为`O(mn)`
之所以复杂度高，就是因为每次主串都要回溯。把主串从头到尾遍历了一遍，然后遍历到每一个字符时都要再把模式串遍历一遍
我们能否想，不回溯主串，仅仅回溯模式串呢
我们先介绍一个概念**最长相等前后缀**
>注：这里讨论一个字符串的前缀和后缀不包含这个字符串本身，否则没有什么实际意义

假如一个字符串abadaba，其前缀集合为
$$
\{a,ab,aba,abad,abada,abadab\}
$$
其后缀集合为
$$
\{a,ba,aba,daba,adaba,badaba\}
$$
然后，从前缀集合与后缀集合中寻找相同元素，并组成一个集合
$$
\{a,aba\}
$$
这就是相等前后缀集合。相等前后缀集合中最长的元素即为最长相等前后缀。那么，字符串abadaba的最长相等前后缀为aba
看下面这个，第一行为主串，第二行为子串，第三行为索引，假如S代表成功匹配，F代表匹配失败，G代表未知匹配情况
```
SSSSSFGGGGGGGGGGGGGGG
SSSSSFG
0123456789...
```
那么我们首次在索引5处遇到匹配失败的地方。
主串已匹配的部分记为`txt[0,1,2,3,4]`,模式串中已匹配的部分记为`pattern[0,1,2,3,4]`
则
```
txt[0,1,2,3,4] = pattern[0,1,2,3,4]
```
假X代表已匹配部分的最长相等前后缀，那么现在的情况就是这样的
```
XXSXXFGGGGGGGGGGGGGG
XXSXXFG
0123456789...
```
这时候，我们直接把已匹配部分的最长公共前后缀的前缀移动到已匹配部分的最长公共前后缀的后缀的位置，即：
```
XXSXXGGGGGGGGGGGGGGG
   XXGGGGG
0123456789...
```
直接把模式串移动了3个单位。
而移动1、2个单位一定不能在`i`位置之前每个字符都匹配成功，这里以移动1个单位举例
如果只移动1个单位
```
XXSXXGGGGGGGGGGGGGGG
 MMMMMMM
0123456789...
```
假设这时候与`txt[1,2,3,4]`成功匹配了，那么必然有
```
pattern[0,1,2,3] = txt[1,2,3,4]
```
而在移动一个单位之前，就有
```
pattern[0,1,2,3] = txt[0,1,2,3]
```
那么就可以推导得到
```
txt[0,1,2,3] = txt[1,2,3,4]
```
这时候可以发现，有长度为4的前后缀相等，这与最大前后缀为2相矛盾
我们可以严格证明这个结论：
假设在索引`i`处首次遇到不匹配的位置，即已经匹配了`i`个字符
那么就有
```
txt[0,1,...,i-1] = pattern[0,1,...,i-1]
且
txt[i]!=pattern[i]
```
假设已经匹配成功的部分`pattern[0,...,i-1]`的最长前后缀为的长度为`k`
那么需要移动的次数为`i-k`
假设模式串向右移动`l`次，其中`l<i-k`，那么远匹配位置和新匹配位置之间存在长度为`i-l`的重叠部分，则必然有
```
pattern[0,1,...,i-l-1] = pattern[l,...,i-1]
```
所以`pattern[0,1,...,i-1]`存在长度为`i-l`的相等前后缀
但是，`i-l>k`，与模式串的最长前后缀的长度为`k`相矛盾
所以，我们完全可以放心的去把模式串的最长相等前后缀的前缀移动到后缀的位置来接着进行匹配，因为中间一定不会有一定能够匹配的
那么，问题就转换为了找以索引`i`为后缀的字符串的最长相等前后缀
我们定义一个数组
```cpp
next[i];
```
`next[i]`用来表示模式串的前缀子串`pattern[0,1,2,...,i]`的最长相等前后缀的长度
那么首先显然有
```cpp
next[0] = 0;
```
然后，利用递推的方法去求这个数组
假如当前要求`next[i]`
假设已经知道了`next[i-1]`
那么，记`j = next[i-1]`
假如橙色的部分为0,1...,i-1（即模式串中已经处理完的前缀`pattern[0,1,...,i-1]`）灰色的为模式串后面的部分
![[kmp-1.png]]
橙色部分中的最长相等前后缀用红色来表示
![[kmp-2.png]]
记绿色部分为首个未匹配的元素
![[kmp-3.png]]
有两个红色区域，第一个红色区域后面的那个元素用黄色标记
![[kmp-4.png]]
黄色就是索引`j`对应的位置，绿色就是索引`i`对应的位置
我们的思路就是，如果黄色的元素与绿色的元素相等，那么当前的`next[i]`不就恰好是`next[i-1]+1`吗
如果黄色的元素与绿色的元素不相等呢？
为了简化描述，我们省略灰色部分
![[kmp-5.png]]
红色部分必然也会有红色部分的最大相等前后缀，我们用蓝色标记
![[kmp-6.png]]
四个蓝色标记，每一个蓝色标记的长度就是`next[j-1]`，我们记`k=next[j-1]`
那么，最左边的蓝色部分的的下一个元素用紫色标记
![[kmp-7.png]]
紫色标记对应的索引就是`k`
这时候我们注重于最后一个蓝色的部分与第一个蓝色的部分
如果**第一个蓝色的部分+紫色部分**组成的字符串恰好等于**最后一个蓝色部分+绿色部分**组成的字符串，由于蓝色部分都相同，也就等价于紫色部分恰好等于绿色部分，这时候从开头到绿色位置这部分字符串的最大前后缀就是**第一个蓝色部分+紫色部分**和**最后一个蓝色部分+绿色部分**
那么，现在就需要比较紫色标记对应的元素与绿色标记对应的元素是否相等，即`pattern[k]`与`pattern[i]`是否相等，如果相等，那么`next[i] = k+1`
如果不相等，那么就接着递归，看蓝色部分的最长相等前后缀，不断令`j = next[j-1]`，直到`pattern[j]==pattern[i]`或者`j=0`
如果
```
pattern[j] = pattern[i]
```
那么
```
next[i] = 1
```
如果
```
pattern[j] != pattern[i]
```
那么
```
next[i] = 0
```

---

此时就有一个问题，会不会有一个介于`j = next[i-1]`与`k = next[j-1]`之间的结果呢？
答案是没有的。我们可以采用反证法，假如有一个长度为`L`的`pattern[0,1,...,i-1]`的相等前后缀且`L`介于`next[i-1]`与`next[j-1]`之间，那么就一定有
```
pattern[0,1,...,L-1] = pattern[i-L,...,i-1]
```
这时候，由于
```
pattern[0,1,...,j-1] = pattern[i-j,...,i-1]
```
那么由于`k<L<j`，就有
```
pattern[0,1,...,L-1] = pattern[i-j,...,i-j+L-1]
```
由第一个式子与第三个式子得
```
pattern[i-L,...,i-1] = pattern[i-j,...,i-j+L-1]
```
由此可得到`pattern[i-L,...,i-1]`与`pattern[i-j,...,i-j+L-1]`为`pattern[i-j,...,i-1]`的相等前后缀，而其长度`L`大于`k`。这与`k`是`pattern[i-j,...,i-1]`的最大相等前后缀相矛盾。

### 代码实现
```c
void buildNext(const char *pattern, int *next)
{
    assert(pattern != NULL);
    assert(next != NULL);

    int len = strlen(pattern);
    if (len == 0)
    {
        return;
    }
    next[0] = 0;
    for (int i = 1; i < len; i++)
    {
        int j = next[i - 1];
        while (j > 0 && pattern[j] != pattern[i])
        {
            j = next[j - 1];
        }

        if (pattern[j] == pattern[i])
        {
            j++;
        }
        next[i] = j;
    }
}

int kmp(const char *pattern, const char *txt, const int *next, int *buf)
{
    assert(pattern != NULL);
    assert(txt != NULL);
    assert(next != NULL);
    assert(buf != NULL);

    int len_pat = strlen(pattern);
    int len_txt = strlen(txt);

    if (len_pat == 0)
    {
        return 0;
    }

    // j表示模式串中已经匹配成功的字符个数
    int j = 0;
    int cnt = 0;

    for (int i = 0; i < len_txt; i++)
    {
        while (j > 0 && pattern[j] != txt[i])
        {
            j = next[j - 1];
        }

        if (pattern[j] == txt[i])
        {
            j++;
        }

        if (j == len_pat)
        {
            buf[cnt++] = i - len_pat + 1;
            j = next[j - 1];
        }
    }

    return cnt;
}
```
