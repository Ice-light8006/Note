# 函数基础语法
## 函数三要素
函数名、函数形参、函数返回值
### 函数名
函数名要体现自注释性（自己解释自己）提高代码的可读性
常用命名方法：动词_名词
动词和名次的个数最好不要超过四个，否则代码可读性会降低
最好不要用拼音
例如：
```c
void add_user(char *username)

void del_user(char *username)
```
一眼就能看出来删除用户和添加用户的作用
其实写函数名是一个非常有技巧性的东西
### 函数形参
传什么类型就要用什么类型来接
比如：
- 传一维数组元素指针来接
- 传二维数组用一维数组指针来接
- 传三维数组用二维数组指针来接
- 传指针数组用二级指针来接
### 函数返回值
当不知道返回什么的时候先定义为`void`，在最后`return`的时候再对这个返回值做矫正
另外，注意一下`return`与`exit`的区别
- `return`是一个关键字，作用是结束当前函数
- `exit`是一个函数，作用是结束整个程序
# 函数声明、定义、调用
在调用函数前必须要声明函数
```c
#include <stdio.h>

int main(int argc,har **argv)
{
	int sum = add(4,5);
	return 0;
}

int add(int a,int b)
{
	return a+b;
}
```
这个代码会报警告，就是因为定义在函数下面，必须要在`main`函数之前声明
```c
#include <stdio.h>

int add(int a,int b);//函数声明

int main(int argc,char **argv)
{
	int sum = add(4,5);
	return 0;
}

int add(int a,int b)
{
	return a+b;
}
```
这样就没有问题了。
或者也可以直接定义在前面，这时候同时完成了声明和定义
```c
#include <stdio.h>

int add(int a,int b)
{
	return a+b;
}

int main(int argc,char **argv)
{
	int sum = add(4,5);
	return 0;
}
```
