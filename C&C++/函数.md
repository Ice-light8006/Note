# 函数基础语法
## 函数三要素
函数名、函数形参、函数返回值
### 函数名
函数名要体现自注释性（自己解释自己）提高代码的可读性
常用命名方法：动词_名词
动词和名次的个数最好不要超过四个，否则代码可读性会降低
最好不要用拼音
例如：
```c
void add_user(char *username)

void del_user(char *username)
```
一眼就能看出来删除用户和添加用户的作用
其实写函数名是一个非常有技巧性的东西
### 函数形参与实参
- **形参**：函数定义时列出的“占位符”变量，用于接收数据。
- **实参**：调用函数时实际传入的具体值或表达式。
传参时，传什么类型就要用什么类型来接
比如：
- 传一维数组元素指针来接
- 传二维数组用一维数组指针来接
- 传三维数组用二维数组指针来接
- 传指针数组用二级指针来接
### 函数返回值
当不知道返回什么的时候先定义为`void`，在最后`return`的时候再对这个返回值做矫正
另外，注意一下`return`与`exit`的区别
- `return`是一个关键字，作用是结束当前函数
- `exit`是一个函数，作用是结束整个程序
# 函数声明、定义、调用
## 函数定义与声明
调用函数时在调用函数前必须要声明函数
```c
#include <stdio.h>

int main(int argc,har **argv)
{
	int sum = add(4,5);
	return 0;
}

int add(int a,int b)
{
	return a+b;
}
```
这个代码会报警告，就是因为定义在函数下面，必须要在`main`函数之前声明
```c
#include <stdio.h>

int add(int a,int b);//函数声明

int main(int argc,char **argv)
{
	int sum = add(4,5);
	return 0;
}

int add(int a,int b)
{
	return a+b;
}
```
这样就没有问题了。
或者也可以直接定义在前面，这时候同时完成了声明和定义
```c
#include <stdio.h>

int add(int a,int b)
{
	return a+b;
}

int main(int argc,char **argv)
{
	int sum = add(4,5);
	return 0;
}
```
另外，对于函数声明，可以只提供类型不提供变量名，因为声明是不会给函数分配内存空间的

# 函数传参
## 传值VS传地址
例：编写一个函数，实现交换两个变量的值
```c
#include <stdio.h>

void swap(int a,int b)
{
	int tmp = a;
	a = b;
	b = tmp;
}

int main(int argc,char **argv)
{
	int x = 5,y = 6;
	swap(x,y);
	printf("x = %d,y = %d",x,y);
	return 0;
}
```
这个函数看起来没有任何问题，但是其实暗藏玄机，其打印结果为：
```output
x = 5,y = 6
```
`x`与`y`的值竟然没交换！这是为什么呢？

--- 
这里就要详细介绍一下函数的调用过程。
函数的调用过程可以概括为下面五步：
1.通过函数名找到函数的入口地址
注：函数的地址=函数的入口地址=&函数名，函数名就是这个函数的函数指针
2.给形参分配空间
3.传参：将实参的值传递给形参空间存储
4.执行函数体语句
5.函数返回，并释放空间

---
所以，重点看第三步，这里实际上是把实参的值赋值给了函数的形参，而交换的实际上是函数内部的形参的值。这就导致了变量`x`与`y`根本没有交换，交换的实际上是函数内部的形参变量`a`与`b`
如果我们想要交换`x`与`y`，应该传`x`与`y`的地址
```c
#include <stdio.h>

void swap(int* x,int* y)
{
	*x = *x^*y;
	*y = *x^*y;
	*x = *x^*y;
}

int main(int argc,char **argv)
{
	int x = 5;
	int y = 6;
	swap(&x,&y);
	printf("x = %d,y = %d",x,y);
}
```
这个代码就可以成功交换变量`x`与变量`y`的值了
>传值（传实参变量名）VS传地址（传实参变量的地址）
>当只使用不修改实参变量内存空间的值，在函数调用时，传实参变量名（只能使用不能修改）
>当既实用也修改实参变量内存空间的值，在函数调用时传实参变量的地址（既能使用也能修改）

但是，**传指针也不一定能修改实参变量内存空间的值！** 再看这个例子
```c
#include <stdio.h>

void func(char *ptr)
{
	ptr++;
}

int main(int argc,char **argv)
{
	char *ptr = "hello world";
	func(ptr);
	printf("%s",ptr);
	return 0;
}
```
它的打印结果为：
```output
hello world
```
但是`ptr++`之后，`ptr`指向的不应该是第二个字符`e`吗，结果不应该是`ello world`吗，为什么最终结果是`hello world`呢？
这是因为`func(ptr)` 并不是把 `main` 函数中的指针变量 `ptr` 本身传入函数，而是把 `ptr` 中保存的地址值复制一份，赋给形参 `ptr`。
因此，实参和形参是两个不同的指针变量，只是它们最初保存了相同的地址。函数中的 `ptr++` 只会修改形参中保存的地址，不会修改 `main` 函数中的指针变量。函数结束后形参被销毁，而 `main` 中的 `ptr` 仍然指向字符串的首字符，所以最终输出仍然是 `hello world`。
传入指针后，可以通过解引用修改指针所指向的内存（但是这里`ptr`指向的是一个字符串字面量，不能直接修改）但不能直接修改调用者的指针变量本身。若要修改调用者的指针变量，需要传入指针的地址，即使用二级指针。示例如下
```c
#include <stdio.h>

void func(char** ptr)
{
	(*ptr)++;
}

int main(int argc,char **argv)
{
	char* ptr = "hello world";
	func(&ptr);
	printf("%s",ptr);
	return 0;
}
```
