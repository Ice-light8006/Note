# 树状数组（Fenwick Tree / BIT）
---
# 1. 核心思想
树状数组本质：

> 用二进制拆分维护前缀信息

支持：
- 单点修改
- 前缀和查询
复杂度：

| 操作  | 时间复杂度    |
| --- | -------- |
| 修改  | O(log n) |
| 查询  | O(log n) |
| 空间  | O(n)     |

相比线段树：
- 更短
- 更快
- 更省空间
- 但功能较少
适合：
- 前缀和
- 区间和
- 逆序对
- 动态频率统计
---
# 2. lowbit
核心函数：
```cpp
int lowbit(int x)
{
    return x & -x;
}
```
作用：

> 取出二进制最低位的 1

例：

|x|二进制|lowbit|
|---|---|---|
|6|110|2|
|12|1100|4|
|8|1000|8|

原因：
```text
x      = 1100
-x     = 0100
x & -x = 0100
```

# 3. 树状数组结构

```cpp
int tree[N];
```
含义：
```text
tree[x]
维护一段区间的和
```
区间长度：
$区间长度=lowbit(x)=x \& (−x)$
例如：

|下标|管辖区间|
|---|---|
|tree[1]|[1,1]|
|tree[2]|[1,2]|
|tree[4]|[1,4]|
|tree[6]|[5,6]|
|tree[8]|[1,8]|

# 4. 单点修改
## add(x,val)
```cpp
void add(int x,int val)
{
    while(x<=n)
    {
        tree[x]+=val;
        x+=lowbit(x);
    }
}
```
更新过程：
```text
x += lowbit(x)
```
表示：
> 跳到下一个包含当前点的区间

例：
```text
x=3
3 -> 4 -> 8
```
---
# 5. 前缀和查询
## query(x)
```cpp
int query(int x)
{
    int sum=0;

    while(x)
    {
        sum+=tree[x];
        x-=lowbit(x);
    }

    return sum;
}
```
查询过程：
```text
x -= lowbit(x)
```
表示：
> 去掉当前区间

例：
```text
x=7
7 -> 6 -> 4 -> 0
```
---
# 6. 区间和
区间：
```text
[l,r]
```
计算：
$$sum(l,r)=query(r)−query(l−1)$$
代码：
```cpp
int sum(int l,int r)
{
    return query(r)-query(l-1);
}
```

# 7. 完整模板
```cpp
#include <bits/stdc++.h>
using namespace std;

const int N=1e6+10;

int n,m;
int tree[N];

int lowbit(int x)
{
    return x & -x;
}

void add(int x,int val)
{
    while(x<=n)
    {
        tree[x]+=val;
        x+=lowbit(x);
    }
}

int query(int x)
{
    int sum=0;

    while(x)
    {
        sum+=tree[x];
        x-=lowbit(x);
    }

    return sum;
}

int main()
{
    cin>>n>>m;

    for(int i=1;i<=n;i++)
    {
        int x;
        cin>>x;
        add(i,x);
    }

    while(m--)
    {
        int op,x,y;
        cin>>op>>x>>y;

        if(op==1)
        {
            add(x,y);
        }
        else
        {
            cout<<query(y)-query(x-1)<<'\n';
        }
    }
}
```

# 8. 树状数组与线段树

| 对比   | 树状数组 | 线段树   |
| ---- | ---- | ----- |
| 代码长度 | 短    | 长     |
| 常数   | 小    | 大     |
| 空间   | O(n) | O(4n) |
| 区间修改 | 弱    | 强     |
| 功能   | 少    | 多     |

一般：
```text
能用树状数组
就优先树状数组
```

add(l,val);

```

query(x)
```
---
## 2）区间修改 + 区间查询
需要：
```text
两个树状数组
```
经典结论：
$$ 
\mathrm{prefix}(x)=(x+1)\sum_{i=1}^{x} b_i-\sum_{i=1}^{x}i\cdot b_i  
$$
---
# 10. 树状数组为什么快
因为：
```text
lowbit
直接利用二进制性质
```
每次都会删除一个二进制位。
所以复杂度：
$$O(\log n)$$
