# 试除法
所有的东西都是从最朴素的做法开始。
试除法是所有素数筛里最直观的算法
## 代码实现
```c
#include <stdio.h>
#include <math.h>

//0表示不是质数，1表示是质数
int isPrime(int n)
{
	if(n<=1)return 0;
	if(n==2)return 1;
	if(n%2==0)return 0;
	for(int i = 3;i<=sqrt(n);i+=2)
	{
		if(n%i==0)return 0;
	}
	return 1;
}
```
## 时间复杂度
$$
O(n\sqrt{n})
$$

# 埃氏筛
## 核心思想
**质数的倍数是合数**
## 代码实现
```c
#include <stdio.h>

const int MAX_N = 1000;

int main()
{
	int isPrime[MAX_N+1];
	
	//初始时假设所有数都是素数
	for(int i = 0;i<=MAX_N;i++)
	{
		isPrime[i] = 1;
	}
	
	isPrime[1] = 0;
	isPrime[0] = 0;
	
	for(int p = 2;p*p<=MAX_N;p++)
	{
		if(isPrime[p])
		{
			for(int i = p*p;i<=MAX_N;i+=p)
			{
				isPrime[i] = 0;
			}
		}
	}
	for(int i = 1;i<=MAX_N;i++)
	{
		if(isPrime[i])
		{
			printf("%d\n",i);
		}
	}
	return 0;
}
```
## 外层循环中的`p`代表什么
首先我们假设所有的数都是质数，然后`p`从2开始遍历，如果遇到一个没有被标记的数，那么这个数字一定是质数。首先，我们以2为质数为已知条件。
证明：当$p$不是2时，那么$p$前面一定有一个质数。假设$p$不是质数，那么一定存在一对整数$a,b$使得$a{\times}b=p$，且这一对整数至少有一个是质数，那么这个$p$就已经被之前的这个质数给筛选掉了。
当$p$是2时，$p$是质数
所以，遇到一个没有标记的数一定是一个质数
## 为什么从`p*p`开始枚举
这里
```c
for(int i = p*p;i<=MAX_N;i+=p)
{
	isPrime[i] = 0;
}
```
`i`是从`p*p`开始的
假如`p=5`
那么，`5*2`,`5*3`,`5*4`就已经被前面的质数`2`,`3`给筛选掉了
同理，别的数字也是如此。
为了减少时间复杂度，`i`从`p*p`开始
## 时间复杂度
$$
O(nloglogn)
$$
# 欧拉线性筛
介绍这个之前，我们先看一下算术基本定理（也称唯一分解定理）
**算术基本定理**：任何大于1的正整数都可以拆分为若干个素数的乘积，且这个若干个素数的乘积是唯一的
12能分解为$2*2*3$，在埃氏筛中，同时被2,3两个数筛除
18能分解为$2*3*3$，在埃氏筛中，同时被2,3两个数筛除
30能分解为$2*3*5$，在埃氏筛中，同时被2,3,5三个数筛除
被重复筛除这就会有很多多余的操作。
现在，我们规定，一个数只能被其最小质因数筛除，即：
- 12只能被2筛除
- 18只能被2筛除
- 30只能被2筛除
埃氏筛的出发方向是：

>找到一个质数$p$，然后筛掉$2p$,$3p$,$4p$......

而欧拉筛的出发方向是

>枚举每一个整数$i$，然后用这个$i$乘以每一个已经找到的质数

假如`i=6`，那么当前已经找到的质数为
```
2 3 5
```
用`i`乘以每一个已经找到的质数
```
6*2
6*3
6*5
```
这是欧拉线性筛的出发点
但是，这还是会有重复的问题，看上面，用`6*3`筛掉了$18$
如果当`i=9`时，此时所有的已经找到的素数为
```
2 3 5 7
```
此时`9*2`也会筛掉$18$，这也会出现重复筛除的情况
