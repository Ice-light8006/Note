题目描述：

小苯有个长度为 n 的序列 a，另有一个空的数字集合 S。  

这天小苯突发奇想，将 a 的所有子序列的和都加入了 S。（包括空子序列的和，视为 0。）  

接着他求出了集合 S 的 MEX，记作 m，他发现如果一开始从 a 中删除一些数字，也并不会影响 m 的值。  

因此你的任务就是，帮助他计算一下一开始最多从 a 中删除多少个数字，能使得经过上述操作后仍然不影响 m 的值（也有可能无法删除任何数字，此时输出 0 即可）。

首先，集合S中必存在一个子集使得其为连续自然数集（例如${1,2,3}$与${7,8,9,10,11}$等可以用区间表示），其次连续自然数组成的集合的和必然也是连续的自然数的集合。

考虑一个特殊情况，一个这样的集合{0,1,2,3}

很显然可以发现这个集合所有能构成的和的集合为[0,6]

如果给这个集合{0,1,2,3}加一个数x，那么这个集合所有能构成的和变为了[0,6]与[x,6+x]的并集。

那么我们不难发现，如果x<=7，这个并集必然是连续的。

而前面的[0,6]中的6显然是不加x的数组的前缀和。

所以，假设有一个索引i，在i处，首次出现i处的数值大于i-1的前缀和+1，那么一定就会出现“间断”的地方，这个地方就是MEX。

所以，在这个“间断”的地方的后面的所有数字都可以删去。具体代码如下。

```cpp
#include<iostream>
#include<vector>
#include<algorithm>

using namespace std;

void solve()
{
	int n;
	cin >> n;
	vector<int> a(n+1);
	vector<int> prefix(n+1);
	a[0] = 0;
	prefix[0] = 0;
	for(int i = 1;i<=n;i++)
	{
		cin >> a[i];
	}
	sort(a.begin(),a.end());
	for(int i = 1;i<=n;i++)
	{
		prefix[i] = a[i]+prefix[i-1];
	}
	for(int i = 1;i<=n;i++)
	{
		if(a[i]>prefix[i-1]+1)
		{
			cout << n-i+1 << endl;
			return;
		}
	}
	cout << 0 << endl;
	return;
}

int main()
{
	int t;
	cin >> t;
	while(t--)
	{
		solve();
	}
	return 0;
}
```
