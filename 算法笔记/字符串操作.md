C++中的字符串操作主要通过`std::string`类（头文件`<string>`)来完成。下面是一些常用操作及示例：

## 基础操作
```cpp
#include<iostream>
#include<string>

std::string s1 = "Hello";
std::string s2 = std::string("World");
std::string s3 = s1+s2;//连接"Hello"与"World"，得到"HelloWorld"

//追加操作：
s1+="cpp"; //得到"Hellocpp"
s1.append("!");//得到"Hellocpp!"

//获取长度
size_t len = s1.size();

```

## find函数
### 函数原型：
```cpp
// 1. 查找子串
size_type find(const basic_string& str, size_type pos = 0) const noexcept;

// 2. 查找 C 风格字符串（以 '\0' 结尾）
size_type find(const CharT* s, size_type pos = 0) const;

// 3. 查找 C 风格字符串的前 count 个字符
size_type find(const CharT* s, size_type pos, size_type count) const;

// 4. 查找单个字符
size_type find(CharT ch, size_type pos = 0) const noexcept;
```
#### 其中：
- `size_type`通常是`std::size_t`(无符号整数类型)
- 这里`CharT`对于`std::string`就是`char`
### 参数说明：

| 参数      | 含义                            |
| ------- | ----------------------------- |
| `str`   | 要查找的`std::string`对象           |
| `s`     | 要查找的C风格字符串（以`\0`结尾）           |
| `count` | 从C风格字符串`s`中取前`count`个字符作为查找目标 |
| `ch`    | 要查找的单个字符                      |
| `pos`   | 开始查找的起始位置（下标），默认为0            |
### 返回值
- 成功：返回第一次匹配的子序列的起始索引（从0开始计数）
- 失败：返回`std::string::npos`
### 基本示例：
```cpp
#include<iostream>
#include<string>

int main()
{
	std::string s = "Hello, world! Hello, C++!";
	
	//1.查找子串
	size_t pos1 = s.find("world");
	//这个pos1为7，默认从索引0开始查找，直到找到第一个world，这里第一个world的首字母对应的索引为7，所以这个pos1为7
	
	size_t pos2 = s.find("Hello");
	//这个pos2为0，从0开始查找，第一个Hello的首字母的索引为0，故返回0
	
	//2.从指定位置开始查找
	size_t pos3 = s.find("Hello",pos2+1);
	//从第一个Hello的首字母的下一个位置开始查找，直到找到下一个Hello，这里下一个Hello的首字母对应的索引为14，故pos3为14
	
	//3.查找单个字符
	size_t pos4 = s.find('C');
	//pos4为21
	
	//4.查找失败的情况
	size_t pos5 = s.find("Ice light");
	if(pos5==std::string::npos)
	{
		std::cout << "没找到Ice light" << std::endl;
	}
	//会输出没找到Ice light，因为没找到会返回std::string::npos，使得if的条件成立，执行if语句内部的内容
}
```
### 常见陷阱与注意事项
1. 区分`std::string::npos`与`-1`
```cpp
std::string s = "Hello, world! Hello, C++!";
size_t pos = s.find("x");
if(pos==-1)//错误！size_t是无符号，-1会被转换为很大的整数
if(pos==std::string::npos)//正确
```
2. 查找空字符串
```cpp
std::string s = "abc";
size_t pos = s.find("");//返回0（总是返回pos参数的值）
pos = s.find("",2);//返回2
```
查找空字符串总是返回`pos`(只要`pos<=size()`)，因为空字符串被视为匹配任何位置
3. 查找字符可以传入对应的ASCII码
4. 查找反向（从右往左）
`std::string`还提供`rfind()`函数，用于从右往左查找
```cpp
std::string s = "abc abc abc";
size_t pos = s.rfind("abc");//返回最后一个"abc"的起始位置8
```
5. 上面最开始给的`CharT`是字符类型参数，可以是`char`、`wchar_t`、`char8_t`(C++20)、`char16_t`、`char32_t`等
背景：
`std::string`并不是一个独立的类，而是模版类`std::basic_string`的一个具体实例（别名）。`std::basic_string`的定义大致如下：
```cpp
template<class CharT, class Traits = char_traits<CharT>, class Allocator = allocator<CharT>>
class basic_string;
```
具体含义：
```cpp
using string = basic_string<char>; //C++ 标准库中的真实定义
```
当你在文档或代码注释中看到`CharT`，你可以理解为它只是一个占位符（泛型参数）。当你实际使用`std::string`时，这个`CharT`就具体化为`char`类型，也就是说：
- `std::string` 中的每个字符元素都是 `char` 类型。
- `std::string` 的成员函数（如 `find`、`operator[]`）中涉及字符类型的地方，`CharT` 就是 `char`。
## 利用`<algorithm>`头文件中的`reverse`函数对字符串进行反转
示例：
```cpp
#include<algorithm>
#include<iostream>

std::string str = "Hello, world!";

//原地反转字符串（这个会直接修改原变量的值，相当于引用传参）
std::reverse(str.begin(),str.end());

std::cout << str << std::endl;//输出!dlrow ,olleH
```
