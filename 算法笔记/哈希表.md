# `C++`中`map`与`unordered_map`的区别
| 对比项   | `map`      | `unordered_map`     |
| ----- | ---------- | ------------------- |
| 底层实现  | 红黑树        | 哈希表                 |
| 元素顺序  | 按键自动排序     | 无序                  |
| 查找复杂度 | `O(log n)` | 平均 `O(1)`，最坏 `O(n)` |
| 插入复杂度 | `O(log n)` | 平均 `O(1)`，最坏 `O(n)` |
| 删除复杂度 | `O(log n)` | 平均 `O(1)`，最坏 `O(n)` |
| 对键的要求 | 必须能够比较大小   | 必须能够计算哈希值并判断相等      |
| 范围查找  | 支持         | 不支持                 |
>`map` 和 `unordered_map` 的基本接口相似，但数据组织方式、顺序保证、复杂度和适用场景不同。

# 题目实战
## 例1
### 题目描述
给定一个整数数组 `nums` 和一个整数目标值 `target`，请你在该数组中找出 **和为目标值** _`target`_  的那 **两个** 整数，并返回它们的数组下标。
## 代码实现
```cpp
#include <iostream>
#include <unordered_map>

vector<int> solve(vector<int> &nums,int target)
{
	vector<int> ans;
	unordered_map<int,int> hash;   //哈希表，建立值->下标的关系
	int len = nums.size();
	for(int i = 0;i < len;i++)
	{
		int tmp = target-nums[i];
		auto it = hash.find(tmp);
		if(it!=hash.end())
		{
			ans.push_back(i);
			ans.push_back(it->second);
			return ans;
		}
		hash[nums[i]] = i;
	}
	return ans;
}
```
## 例2
### 题目描述
给你一个整数数组 `nums` 和一个整数 `k` ，请你统计并返回 _该数组中和为 `k` 的子数组的个数_ 。
子数组是数组中元素的连续非空序列。
### 题解
先维护一个前缀和数组`pre`
然后维护一个哈希表
```cpp
unordered_map<int,int> hash;
```
这里`hash[i]`表示当前前缀和为`i`的个数
初始化时，一定有前缀和为0的个数为1，即：
```cpp
hash[0] = 1;
```
遍历一遍前缀和数组
```cpp
for(int i = 0;i<pre.size();i++)
{
	//...
}
```
对于`pre[i]`，只要从前面找到另一个`pre[j]`(`j<i`)，使得
```
pre[i]-pre[j] = k;
```
即
```
pre[j] = pre[i] - k;
```
那么，`hash[pre[i]]`的意义就是以下标`i`上的元素为结尾的所有的子数组中和为`k`的个数
所以，初始化一个计数器`int cnt = 0`用来统计答案，每次遍历到`pre[i]`，都让`cnt`加上`hash[pre[i]-k]`的值。然后再执行`hash[pre[i]]++`维护哈希表。跑完整个循环后最终`cnt`的结果就是答案
### 代码实现
```cpp
#include <unordered_map>
#include <iostream>

int solve(vector<int> &nums,int k)
{
	int ans = 0;
	int len = nums.size();
	vector<int> pre(len,0);
	for(int i = 0;i<len;i++)
	{
		if(i==0)
		{
			pre[i] = nums[i];
		}
		else
		{
			pre[i] = nums[i] + pre[i-1];
		}
	}
	unordered_map<int,int> hash;
	
	//初始时，前缀和为0的个数为1
	hash[0] = 1;
	
	for(int i = 0;i<len;i++)
	{
		int tmp = pre[i]-k;
		auto it = hash.find(tmp);
		if(it!=hash.end())
		{
			ans+=it->second;
		}
		hash[pre[i]]++;
	}
	
	return ans;
}
```
