# 项目根目录的布局推荐
```
STM32_Project/
│
├── Core/                       // CubeMX 生成的核心代码
│   ├── Inc/
│   │   ├── main.h
│   │   ├── gpio.h
│   │   ├── usart.h
│   │   └── freertos.h
│   │
│   └── Src/
│       ├── main.c
│       ├── gpio.c
│       ├── usart.c
│       ├── freertos.c
│       └── stm32f1xx_it.c
│
├── App/                        // 应用层
│   ├── Inc/
│   │   ├── app_tasks.h
│   │   └── attendance.h
│   │
│   └── Src/
│       ├── app_tasks.c
│       └── attendance.c
│
├── BSP/                        // 板级支持包
│   ├── Inc/
│   │   ├── led.h
│   │   └── buzzer.h
│   │
│   └── Src/
│       ├── led.c
│       └── buzzer.c
│
├── Components/                 // 外部器件驱动
│   ├── RC522/
│   │   ├── rc522.h
│   │   └── rc522.c
│   │
│   ├── AS608/
│   │   ├── as608.h
│   │   └── as608.c
│   │
│   └── ESP8266/
│       ├── esp8266.h
│       └── esp8266.c
│
├── Services/                   // 通用服务模块
│   ├── DebugLog/
│   │   ├── debug_log.h
│   │   └── debug_log.c
│   │
│   └── Protocol/
│       ├── protocol.h
│       └── protocol.c
│
├── Drivers/                    // STM32 官方驱动
│   ├── CMSIS/
│   └── STM32F1xx_HAL_Driver/
│
└── Middlewares/                // 中间件
    └── Third_Party/
        └── FreeRTOS/
```
但是一开始做简单的项目没必要划分的那么细，可以先尝试精简版：
```
Project/
│
├── Core/
│   ├── Inc/
│   └── Src/
│
├── App/
│   ├── Inc/
│   └── Src/
│
├── Drivers/
│   ├── Inc/
│   └── Src/
│
├── Services/
│   ├── Inc/
│   └── Src/
│
└── Middlewares/
```
对应关系：

| 目录          | 放置内容                       |
| ----------- | -------------------------- |
| Core        | CubeMX 生成的代码               |
| App         | 业务逻辑、FreeRTOS Tasks        |
| Drivers     | LED、RC522、AS608、ESP8266 驱动 |
| Services    | DebugLog、通信协议等             |
| Middlewares | FreeRTOS 等中间件              |
