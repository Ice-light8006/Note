现在有四个按钮KEY1,KEY2,KEY3,KEY4
有四个引脚PA0,PA1,PA2,PA3
按钮在按下时，PA0,PA1,PA2,PA3会检测到低电平
现在有一个全局变量`num`，初始化为0
```c
int num = 0;
```
我们准备实现下面这个程序
```
按钮KEY1：
单击时，num自增1
长按时，num持续自增1

按钮KEY2：
单击时，num自增1
双击时，num自增2

按钮KEY3：
单击时，num自增1
长按时，num自增3

按钮KEY4：
单击时，num自增1
双击时，num自增2
长按时，num自增3
```
对于每一个按钮，我们可以用两个变量记录当前的状态和上一次状态，即：
定义8个变量
```c
int k1_cur,k2_cur,k3_cur,k4_cur;
int k1_last,k2_last,k3_last,k4_last;
```
其中
```
kx_cur代表按钮KEYx当前状态对应引脚的电平
kx_last代表按钮KEYx上一次状态对应引脚的电平
```
那么，按钮KEYx刚按下瞬间两个变量的值就是
```
kx_cur为0
kx_last为1
```
按钮KEYx按住时两个变量的值：
```
kx_cur为0
kx_last为0
```
按钮KEYx松开时两个变量的值：
```
kx_cur为1
kx_last为0
```
实现这个刚才说的按钮逻辑，我们先介绍一下HAL库中的一个函数
```c
void SysTick_Handler(void);
```
当程序启动时执行：
```c
HAL_Init();
```
HAL会配置STM32的 SysTick 定时器，让它大约每1ms产生一次中断。
当中断到来，CPU会暂时放下主循环，自动跳到：
```c
void SysTick_Handler(void)
{
    ...
}
```
执行完后，再回到原来的主循环继续运行。
也就相当于
```
第0ms    执行一次SysTick_Handler
第1ms    执行一次SysTick_Handler
第2ms    执行一次SysTick_Handler
......
```
注：下面所有的代码都提前定义好了这些宏
```c
#define pressed !k1_cur & k1_last
#define keep_pressed !k1_cur & !k2_cur
#define bounce k1_cur & !k1_last
```
我们现在要做的就是，对每一个按钮都写一个函数，检测按钮当前状态，然后把这个函数放入主函数中的`while(1)`循环中，实时根据这个状态去做相应的修改
# KEY1的逻辑实现
首先，对于单击的判断很简单，一次单击，必然就是先检测到`pressed`，然后检测到一次`bounce`，即可判断一次单击
但是，如果检测到了一次`pressed`然后过了十几秒才检测到`bounce`，能当做单击吗？肯定不可以
这时候我们就要定义一个
```c
int long_flag;
```
用来标记是否要计时，即如果检测到了一次`pressed`，就把这个标记记为1，开始计时。如果检测到了一次`bounce`，就把这个标记清除，停止计时。
然后定义一个
```c
int long_count;
```
用来记录毫秒数
利用函数`SysTick_Handler()`，可以这样写这个函数
```c
void SysTick_Handler()
{
	if(long_flag)
	{
		long_count++;
	}
	else
	{
		long_count = 0;
	}
}
```
即：如果当前检测到了`long_flag`被标记，即“已经按下了但是还没抬起”，那么就计数，把`long_count`自增1，如果当前没有检测到`long_flag`标记，那么就还没有按下，就不计数，把`long_count`清零
所以，KEY1的状态扫描函数这样写
```c
void k1_scan()
{
	if(pressed)
	{
		long_flag = 1;
	}
	
	if(long_count>1000)
	{
		num++;
		printf("num = %d\n",num);
	}
	
	if(bounce)
	{
		long_flag = 0;
	}
	
	if(bounce && long_count<1000)
	{
		num++;
		printf("num = %d\n",num);
	}
}
```
只要检测到了按下，就标记`long_flag`，只要检测到了弹起，就清除标记`long_flag`
只要检测到了`long_count`比1000大（即按下时间大于1000ms）那就自增`num`然后打印输出当前`num`的值（以此来实现长按时持续对num自增），只要检测到了`boucne`并且`long_count`比1000小，就`num`自增然后打印数当前`num`的值（以此来实现单击自增一次的逻辑）
# KEY2的逻辑实现
KEY2主要要做的就是对双击逻辑的实现
对于双击逻辑，我们可以这样做
利用一个变量`double_count`计时，利用一个标记`double_flag`标记是否进行计时
如果`double_flag`标记为1，那么就计时，如果`double_flag`标记为0，那么就把`double_count`清零
那么`SysTick_Handler()`函数可以这样写
```c
void SysTick_Handler(void)
{
	if(double_flag)
	{
		double_count++;
	}
	else
	{
		double_count = 0;
	}
}
```
当检测到第一次按下时，标记`double_flag`为1
在第一次按下之后，当检在规定时间内检测到第二次按下时，就执行双击的动作
如果在第一次按下之后，在规定时间内没有检测到第二次按下，那么就执行单击的动作
而这个规定的时间就是我们给`double_count`设置的阈值
所以，KEY2的扫描函数可以这样写
```c
void k2_scan()
{
	if(pressed)
	{
		double_flag = 1;
	}
	
	//这里后面再加一个double_count>0是因为，当第一次检测到presed时，这时候也满足pressed && double < 200，会直接导致程序把单点视为双击，所以要加上double_count>0
	if(pressed && double_count < 200 && double_count > 0)
	{
		num+=2;
		printf("num = %d\n",num);
		double_flag = 0;
	}
	
	if(double_count > 200)
	{
		double_flag = 0;
		num++;
		printf("num = %d\n",num);
	}
}
```
这个的逻辑就是，当检测到按下时直接把`double_flag`设为1
如果遇到检测到第二次按下，并且此时计数器`double_count`比0大，并且计数器大小比200小，那么就视为双击
如果检测到了`double_count`比200大，那么就视为单击
# KEY3的逻辑实现
这里与KEY1的区别是，KEY1是长按时一直`num`自增，而这个KEY3是只要检测到长按就仅仅自增一次，直到长按结束。
我们设一个变量`long_lock`，用来上锁避免长按时一直自增，每次检测到`pressed`时都把这个变量清零，即去除掉锁
如果检测到没上锁的同时检测到`long_count`比1000大，那么就视为触发了长按，执行一次长按要进行的操作，同时要上锁，避免持续执行长按的操作
如果检测到了弹起就把`long_flag`标记去除
如果检测到了弹起同时`long_count`小于1000，那么就视为一次单击，执行单击的操作
代码如下：
```c
void k3_scan(void)
{
	if(pressed)
	{
		long_flag = 1;
		long_lock = 0;
	}

	if(bounce)
	{
		long_flag = 0;
	}
	
	if(long_count>1000 && long_lock==0)
	{
		long_lock = 1;
		num+=3;
		printf("num = %d\n",num);
	}
	
	if(long_count<1000 && bounce)
	{
		num++;
		printf("num = %d\n",num);
	}
}
```
# KEY4的逻辑实现
对于KEY4，我们只需要结合KEY2和KEY3的思路，理清楚思路然后去实现双击+长按+单击的逻辑
如果直接利用一大堆`if...else`嵌套，逻辑会非常混乱，非常容易混淆，很容易写着写着就晕了
我们可以采用**状态机编程**
首先我们枚举一下按钮的状态
```c
typedef enum{
	KEY_STATE_IDLE,
	KEY_STATE_FIRST_PRESSED,
	KEY_STATE_LONG_PRESSED,
	KEY_STATE_WAIT_SECOND,
	KEY_STATE_SECOND_PRESSED
}KeyState;
```
