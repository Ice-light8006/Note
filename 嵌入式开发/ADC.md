# 一些关于ADC的问题
## 1. ADC不是用来把模拟信号转换为数字信号的东西吗，怎么还有时钟，ADC不是时钟源吧?

**ADC 的作用是把模拟电压转换成数字量；但 ADC 内部仍然需要一个时钟来安排转换过程。**
这里容易混淆两个概念：
- **时钟源**：产生时钟的人
- **ADC 时钟**：ADC 使用的工作节拍
ADC 通常**不是时钟源**，而是一个“使用时钟的外设”。
ADC 不是瞬间完成转换的，它内部要按步骤工作。
以常见的 SAR ADC 为例：
```
1. 采样输入电压
2. 判断最高位
3. 判断次高位
4. 判断下一位...12. 判断最低位
5. 输出最终数字结果
```
这些步骤需要有节奏地进行：
```
ADC时钟： ↑    ↑    ↑    ↑    ↑    ↑         │    │    │    │    │         采样  判断  判断  判断  ... 输出
```
因此，ADC 需要时钟来告诉内部电路：
> “现在进行下一步。”

就像裁判每次吹哨，运动员完成一个动作。裁判不是运动员，也不是比赛内容本身，但比赛需要裁判的节拍。
在 MCU 中，ADC 时钟通常来自：
```
系统时钟/外设时钟
        │
        └── 分频器
	            │
                ↓
            ADC时钟
```
例如：
```
系统时钟 = 72 MHz
ADC时钟分频 = 6
ADC时钟 = 72 MHz ÷ 6 = 12 MHz
```
## 2. ADC输入和GPIO_Input有什么区别
**一句话结论：GPIO_Input 读的是“0 还是 1”（数字量），ADC 输入读的是“电压是多少”（模拟量），两者的内部电路和工作方式完全不同。**

|  | GPIO 输入 | ADC 输入 |
| --- | --- | --- |
| 读什么 | 高/低（0/1） | 电压大小（多档数值） |
| 信号类型 | 数字信号 | 模拟信号 |
| 结果 | 1 位 | 多位（如 12 位） |
| 内部电路 | 数字缓冲/比较 | 采样+比较+逐次逼近 |
| 典型用途 | 按键、开关、电平检测 | 温度、光强、电压测量 |
