## 核的数量
通俗比喻：
- **单核 CPU** = 一个工厂里只有**1 个工人**，不管来多少任务，都得他一个人排队干。
- **多核 CPU** = 工厂里有**多个工人**（4核=4个工人，8核=8个工人），可以**同时**处理多个任务。

### 为什么要分内外晶振？
- RC振荡器
RC振荡器在芯片内部，RC振荡器可以产生固定频率的信号，但是温漂较大
- 外部晶振
优点：外部晶振频率稳定，几乎没有温漂
缺点：需要起振时间
所以刚上电时，使用内部RC振荡器，随后外部晶振来接管
### 外部时钟
MCU：72MHz
外部高速时钟：8MHz --- PLL锁相环：倍频x9 = 72
外部低速时钟：32.768KHz，32768是2的15次方，方便倍频，可以降到1Hz，更方便做一秒钟的计时
### 内部时钟
内部高速：8MHz
内部低速：40KHz

寄存器开发方式：用户直接操作寄存器来实现控制片上外设工作
写代码：
使能对应外设时钟
配置GPIO相关寄存器（CRL，ODR）
## 寄存器开发示例
```c
//使能GPIOB的时钟
	*(unsigned int *)(0x40021000 + 0x18) |= 1 << 3;

	//配置GPIO的PB0：mode：11，cnf：00
	*((unsigned int *)(0x40010C00 + 0x00)) |= (1 << 0 | 1 << 1);
	*((unsigned int *)(0x40010C00 + 0x00)) &= ~(1 << 2 | 1 << 3);
	*((unsigned int *)(0x40010C00 + 0x0C)) |= 1 << 0;

	//配置GPIOB的PB1：mode：11 cnf：00
	*((unsigned int *)(0x40010C00 + 0x00)) |= (1 << 4 | 1 << 5);
	*((unsigned int *)(0x40010C00 + 0x00)) &= ~(1 << 6 | 1 << 7);
	*((unsigned int *)(0x40010C00 + 0x0C)) |= 1 << 1;
	return 0;
```
