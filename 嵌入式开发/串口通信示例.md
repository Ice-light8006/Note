# USART和UART的区别
USART
```
USART = Universal Synchronous/Asynchronous Receiver/Transmitter
通用同步/异步收发器
```
USART既支持同步通信又支持异步通信
UART
```
UART = Universal Asynchronous Receiver/Transmitter
通用异步收发器
```
UART只支持异步通信
## 为什么代码叫USART，但大家说“UART串口”？
```
USART1->BRR
USART1->CR1
USART1->DR
```
硬件外设名称是 `USART1`，但你没有启用同步时钟，而是使用：
```
TX
RX
起始位
停止位
波特率
```
所以实际上工作在异步模式，使用方法和 UART 一样。
因此把驱动文件命名为：
```
uart1.c
uart1.h
```
也是可以的。它表达的是“把 USART1 当作异步 UART 使用”。
