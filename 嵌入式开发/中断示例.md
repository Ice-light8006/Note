有两个按钮KEY1和KEY2
KEY1按下时PA0为低电平，弹起时PA0为高电平
KEY2按下时PA1为低电平，弹起时PA1为高电平
然后有两个发光二极管LED1和LED2，并且有封装好的翻转发光二极管状态的函数
```c
void led_toggle(int led);
```
我们使用中断来实现
```
KEY1弹起时翻转LED1
KEY2弹起时翻转LED2
```
# 寄存器开发示例
## 初始化中断
首先我们要初始化中断，下面是初始化中断函数
```c
void key_init_interrupt(void)
{
    //开启时钟：GPIO,AFIO
    RCC->APB2ENR |= RCC_APB2ENR_AFIOEN;
    RCC->APB2ENR |= RCC_APB2ENR_IOPAEN;


    //配置GPIOA：PA0，PA1 为上拉输入
    KEY_PORT->CRL &= ~GPIO_CRL_MODE0;
    KEY_PORT->CRL |= GPIO_CRL_CNF0_1;
    KEY_PORT->CRL &= ~GPIO_CRL_CNF0_0;

    KEY_PORT->CRL &= ~GPIO_CRL_MODE1;
    KEY_PORT->CRL |= GPIO_CRL_CNF1_1;
    KEY_PORT->CRL &= ~GPIO_CRL_CNF1_0;

    KEY_PORT->BSRR = GPIO_BSRR_BS0;
    KEY_PORT->BSRR = GPIO_BSRR_BS1;
    

    //配置AFIO：确定哪组端口的引脚能够产生中断
    //先把这四位原来设置的位清零
    AFIO->EXTICR[0] &= ~AFIO_EXTICR1_EXTI0;
    //设置PA0可以作为EXIT0的输入来源
    AFIO->EXTICR[0] |= AFIO_EXTICR1_EXTI0_PA;

	//先把这四位原来设置的位清零
    AFIO->EXTICR[0] &= ~AFIO_EXTICR1_EXTI1;
    //设置PA1可以作为EXIT1的输入来源
    AFIO->EXTICR[0] |= AFIO_EXTICR1_EXTI1_PA;

    //配置EXTI：中断屏蔽寄存配置上升沿/下降沿，要先配置上下沿再使能
    EXTI->RTSR |= EXTI_RTSR_TR0;
    EXTI->RTSR |= EXTI_RTSR_TR1;

    //使能中断
    EXTI->IMR |= EXTI_IMR_MR0;
    EXTI->IMR |= EXTI_IMR_MR1;

    //设置中断的优先级
    NVIC_SetPriorityGrouping(3);
    NVIC_SetPriority(EXTI0_IRQn,1);
    NVIC_SetPriority(EXTI1_IRQn,1);


    //使能中断
    NVIC_EnableIRQ(EXTI0_IRQn);
    NVIC_EnableIRQ(EXTI1_IRQn);
}
```
我们逐步解析这个中断初始化函数都在干什么
首先是开启时钟的函数
```c
RCC->APB2ENR |= RCC_APB2ENR_AFIOEN;
RCC->APB2ENR |= RCC_APB2ENR_IOPAEN;
```
这两个函数用来开启时钟
第一行代码
```c
RCC->APB2ENR |= RCC_APB2ENR_AFIOEN;
```
用来开启AFIO的时钟，AFIO 用于选择“哪个 GPIO 端口连接到对应的 EXTI 中断线”。
第二行代码
```c
RCC->APB2ENR |= RCC_APB2ENR_IOPAEN;
```
用来开启GPIOA的时钟
然后是
```c
KEY_PORT->CRL &= ~GPIO_CRL_MODE0;
KEY_PORT->CRL |= GPIO_CRL_CNF0_1;
KEY_PORT->CRL &= ~GPIO_CRL_CNF0_0;

KEY_PORT->CRL &= ~GPIO_CRL_MODE1;
KEY_PORT->CRL |= GPIO_CRL_CNF1_1;
KEY_PORT->CRL &= ~GPIO_CRL_CNF1_0;
```
前三行代码把PA0配置为上拉/下拉输入模式
后三行代码把PA1配置为上拉/下拉输入模式
但是具体是上拉还是下拉这个要利用ODR的值来调
然后是
```c
KEY_PORT->BSRR = GPIO_BSRR_BS0;
KEY_PORT->BSRR = GPIO_BSRR_BS1;
```
第一行代码把ODR0写1，PA0被配置为了上拉输入模式
第二行代码把ODR1写1，PA1被配置为了上拉输入模式
接下来就是配置外部中断寄存器（EXTICR）
先解释一下EXTICR这个词本身
外部中断寄存器的英文为
```
External Interrupt Configuration Register
```
拆开来看就是
```
EXTI  = External Interrupt，外部中断
CR    = Configuration Register，配置寄存器
```
首先我们知道有很多GPIO引脚，例如
```
PA0,PA1,...
PB0,PB1,...
PC0,PC1,...
......
```
但外部中断总线只有
```
EXTI0,EXTI1,...,EXTI15
```
不可能每一个引脚都使用一个外部中断线
STM32F1使用的规定是
```
所有x号引脚竞争EXTIx
```
即：
```
PAx
PBx
PCx
PDx
PEx
PFx
PGx
```
这7个引脚共用EXTIx
但是，EXTIx到底选哪一个引脚作为输入来源呢？这个就是我们自己决定的，而`AFIO_EXTICR`就是用来解决这件事的
STM32F1使用四个外部中断寄存器
```
EXTICR1：负责EXTI0,EXTI1,EXTI2,EXTI3
EXTICR2：负责EXTI4,,EXTI5,EXTI6,EXTI7
EXTICR3：负责EXTI8,EXTI9,EXTI10,EXTI11
EXTICR4：负责EXTI12,EXTI13,EXTI14,EXTI15
```
在代码中对应
```c
AFIO->EXTICR[0]  // EXTICR1，配置 EXTI0～3
AFIO->EXTICR[1]  // EXTICR2，配置 EXTI4～7
AFIO->EXTICR[2]  // EXTICR3，配置 EXTI8～11
AFIO->EXTICR[3]  // EXTICR4，配置 EXTI12～15
```
而EXTIx对应一个四位的端口选择字段，这四位在一起组成一个二进制数字，这个二进制数字的含义如下：
```
0000代表PAx
0001代表PBx
0010代表PCx
0011代表PDx
0100代表PEx
0101代表PFx
0110代表PGx
...
```
如果想要让EXTI0选择PA0作为输入来源，那么就是
```c
AFIO->EXTICR[0] |= AFIO_EXTICR1_EXTI0_PA;
```
但是，我们要先把这个四位端口选择字段清空，因为EXTICR可能已经保存了以前的端口选择，就需要事先清空EXTI0对应的4位端口选择字段，即需要先执行
```c
AFIO->EXTICR[0] &= ~AFIO_EXTICR1_EXTI0;
```
所以，最终的代码就是这样写
```c
AFIO->EXTICR[0] &= ~AFIO_EXTICR1_EXTI0;
AFIO->EXTICR[0] |= AFIO_EXTICR1_EXTI0_PA;

AFIO->EXTICR[0] &= ~AFIO_EXTICR1_EXTI1;
AFIO->EXTICR[0] |= AFIO_EXTICR1_EXTI1_PA; 
```
所形成的效果就是：
```
让EXTI0以PA0为输入源
让EXTI1以PA1为输入源
```
配置好输入源之后，接下来就是要确定是下降沿触发还是上升沿触发
下降沿触发就是：
```
原本为高电平，突然变成低电平，此时就是下降沿，下降沿触发中断
```
上升沿同理
STM32F1提供了上升沿触发选择寄存器（EXTI_RTSR）与下降沿触发选择寄存器（EXTI_FTSR）
```c
EXTI->RTSR |= EXTI_RTSR_TR0;
```
的作用就是配置EXTI0线为上升沿触发
```c
EXTI->RTSR |= EXTI_RTSR_TR1;
```
的作用就是配置EXTI1线为上升沿触发
接下来就是使能中断
>注意，**一定要先设置上下沿再使能**

STM32F1提供了中断屏蔽寄存器（EXTI_IMR）
```c
EXTI->IMR |= EXTI_IMR_MR0;
```
的作用就是使能EXTI0线上的中断
```c
EXTI->IMR |= EXTI_IMR_MR1;
```
的作用就是使能EXTI1线上的中断
接下来就是配置中断的优先级
STM32F1 实现了 4 个有效优先级位，可配置 16 个优先级等级。
> **优先级数值越小，优先级越高。**

优先级分为**抢占优先级**和**响应优先级**

| 优先级   | 作用                     |
| ----- | ---------------------- |
| 抢占优先级 | 决定一个中断能否打断另一个 ISR      |
| 响应优先级 | 抢占优先级相同时，决定多个挂起中断的先后顺序 |

原课件中的“响应优先级”在当前 CMSIS/HAL 文档中通常称为“子优先级”。
优先级分组：

![NVIC 优先级分组](嵌入式开发/assets/03中断系统/image_006.png)

| 分组                     | 抢占优先级位 | 响应优先级位 |
| ---------------------- | -----: | -----: |
| `NVIC_PRIORITYGROUP_0` |      0 |      4 |
| `NVIC_PRIORITYGROUP_1` |      1 |      3 |
| `NVIC_PRIORITYGROUP_2` |      2 |      2 |
| `NVIC_PRIORITYGROUP_3` |      3 |      1 |
| `NVIC_PRIORITYGROUP_4` |      4 |      0 |

优先级判断规则：
1. 优先比较抢占优先级，数值小者优先。
2. 高抢占优先级可以打断低抢占优先级 ISR。
3. 抢占优先级相同时，再比较子优先级。
4. 子优先级只决定等待顺序，不产生中断嵌套。
5. 两种优先级都相同时，异常号较小者先响应。
这一行代码
```c
NVIC_SetPriorityGrouping(3);
```
就是设置4位抢占，0响应位
`NVIC` 是：
```
Nested Vectored Interrupt Controller
```
中文通常叫：
```
嵌套向量中断控制器
```
它位于 STM32 使用的 Cortex-M3 内核中，负责统一管理各种中断请求。
接下来就是设置EXTI0和EXTI1在中断中的优先级
使用的函数如下
```c
NVIC_SetPriority(中断编号, 优先级值);
```
这一行代码
```c
NVIC_SetPriority(EXTI0_IRQn,1);
```
这里IRQn的意思就是
```
Interrupt Request Number
中断请求编号
```
这行代码的意思就是把EXTI0的中断优先级设置为1
这一行代码
```c
NVIC_SetPriority(EXTI1_IRQn,1);
```
意思是把EXTI1的中断优先级设置为1
这两行代码
```c
NVIC_EnableIRQ(EXTI0_IRQn);
NVIC_EnableIRQ(EXTI1_IRQn);
```
就是字面意思，使能中断。
使能中断有两级开关：
```
第一级：EXTI->IMR
第二级：NVIC_EnableIRQ()
```
只有两级都打开，才是真正使能了中断
EXTI->IMR这一级开关打开，意思是
```
允许EXTI提交中断请求
```
NVIC_EnableIRQ这一级开关打开，意思是
```
允许CPU通过NVIC响应EXTI的中断请求
```
这两者缺一不可。
## 中断处理函数
在STM32F1寄存器开发项目中的Startup文件夹中，会有一个类似这个的.s文件
```
startup_stm32f10x_md.s
```
这里面你能找到类似这样的语句
```
                DCD     EXTI0_IRQHandler           ; EXTI Line 0
                DCD     EXTI1_IRQHandler           ; EXTI Line 1
                DCD     EXTI2_IRQHandler           ; EXTI Line 2
                DCD     EXTI3_IRQHandler           ; EXTI Line 3
                DCD     EXTI4_IRQHandler           ; EXTI Line 4
```
这里这个EXTI0_IRQHandler就是EXTI0对应中断处理函数的函数名，后面四个同理
我们直接用这个名字定义这个函数就可以了
```c
void EXTI0_IRQHandler(void)
{
	...
}
```
函数内部我们只需要写按钮的逻辑
我们可以枚举按钮的状态
```c
typedef enum key_status
{
   KEY_RELEASED = 0, //释放状态
   KEY_PRESSED = 1 //按下状态
}Key_Status;
```
再定义两个变量
```c
volatile uint8_t key1_flag = KEY_RELEASED;
volatile uint8_t key2_flag = KEY_RELEASED;
```
用来记录按钮的状态标志
由于我们配置的是上升沿触发，而按钮按下之后PA引脚就从高电平变成了低电平
所以每当我们按下按钮之后弹起按钮时会触发中断函数
当KEY1弹起时，就会触发函数
```c
void EXTI0_IRQHandler(void)
{
	...
}
```
当KEY2弹起时，就会触发函数
```c
void EXTI1_IRQHandler(void)
{
	...
}
```
所以我们可以在中断处理函数来写按钮所触发的功能
EXTI寄存器中有挂起寄存器（EXTI_PR）
>`EXTI_PR` 用来记录哪些 EXTI 线已经产生触发请求；对应位由硬件置1，由软件通过“写1”清零。清除时应使用直接赋值，不能使用 `|=`。

由于EXTI0发生触发请求时，EXTI_PR0对应位会被硬件置1，此时一定要把PR0清楚掉，否则会发生下面的问题
```
CPU执行完中断函数
      ↓
PR0仍然等于1
      ↓
EXTI仍然表示“有请求未处理”
      ↓
NVIC可能再次收到请求
      ↓
CPU再次进入EXTI0_IRQHandler()
```
所以最后我们的触发函数这样写：
```c
void EXTI0_IRQHandler(void)
{
	if(EXTI->PR & EXTI_PR_PR0)
	{
		//对PR写1清除EXTI_PR0对应位
		EXTI->PR = EXTI_PR_PR0;
		
		key1_flag = KEY_PRESSED;
	}
}

void EXTI1_IRQHandler(void)
{
	if(EXTI->PR & EXTI_PR_PR1)
	{
		//对PR写1清除EXTI_PR1对应位
		EXTI->PR = EXTI_PR_PR1;
		
		key2_flag = KEY_PRESSED;
	}
}
```
然后在`main`函数中
```c
int main(int argc,char** argv)
{
	while(1)
	{
		if(key1_flag==KEY_PRESSED)
		{
			led_toggle(LED1);
			key1_flag = KEY_RELEASED;
		}
		if(key2_flag==KEY_PRESSED)
		{
			led_toggle(LED2);
			key2_flag = KEY_RELEASED;
		}
	}
}
```
这就成功利用中断实现了按下按钮翻转LED灯的开关状态
