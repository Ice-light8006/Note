# TCP协议
## 三次握手
假如有两个网络设备A和B，对于三次握手，通俗的讲，可以这样理解
```
A请求连接B，给B发送SYN

B收到A发送的SYN，发送ACK同意请求连接，与此同时向A发送SYN请求连接A
这时候，ACK与SYN合在一个报文里，就是ACK+SYN

A收到B发送的SYN，向B发送ACK表示同意B的请求连接
```

再介绍一下**初始序列号**，英文简称ISN
初始序列号就是在这次TCP连接中某个发送方向上字节流编号起点
TCP是把数据看做一串连续的字节，每个字节都有一个编号。连接刚建立时这个编号从哪儿开始？这就是初始序列号
更准确的过程：

|步骤|方向|报文|含义|
|---|---|---|---|
|1|A → B|SYN，seq=x|A 请求建立连接，并告诉 B：我的初始序列号是 x|
|2|B → A|SYN+ACK，seq=y，ack=x+1|B 确认收到 A 的 SYN；同时 B 也发起自己的 SYN，告诉 A：我的初始序列号是 y|
|3|A → B|ACK，seq=x+1，ack=y+1|A 确认收到 B 的 SYN|
A和B两个设备在三次握手阶段交换了彼此的初始序列号
