# ELMB Sync
ELMB Sync是华硕的动态清晰技术
全称是
```
Extreme Low Motion Blur Sync
```
直白说，它通过让背光在每一帧之间短暂熄灭或闪烁，减少人眼对上一帧画面的残留，从而降低高速运动时的模糊感。
它主要服务于：
- CS2、Valorant、OW等竞技FPS
- 高速赛车、音游
- 画面快速横向移动的场景
不是为了让画面“更流畅”，而是为了让运动物体的边缘**更清楚**。
## 它解决的是什么问题？
即使显示器是180Hz，每一帧仍会停留约：
```
1000 ÷ 180 ≈ 5.56ms
```
当你眼睛跟着一个高速移动的目标移动时，这5.56ms内的持续发光会形成视觉残留。于是你会感觉：
- 转视角时远处细节发糊
- 敌人横移时轮廓不够锐
- 测试页面里的UFO有拖影
- 快速滚动文字不够清晰
ELMB Sync会把每帧的“可见时间”压短。举例：
```
一帧开始 → 像素开始切换 → 等画面稳定 → 背光短暂点亮 → 背光熄灭 → 下一帧
```
人眼只在画面相对稳定的那一小段时间看到它，上一帧残留更少，因此动态画面更干净。
## 为什么开了会变暗？
这是物理规律，不是故障。
不开ELMB时，背光几乎持续点亮；开ELMB后，背光每帧会有一段时间熄灭。发光总时长变少，平均亮度自然下降。
> 动态清晰度提高，亮度和舒适度可能下降。

为了补亮，你可以提高亮度设置，但背光频闪本身导致的暗感不会完全消失。
概括的讲ELMB Sync：
>快速移动时，人眼会把连续显示的多帧画面叠加成一段模糊轨迹，这叫“运动模糊”或视觉残留。ELMB Sync通过缩短每一帧背光实际点亮的时间，减少这段视觉残留，让移动物体看起来更锐利、轮廓更清楚。

# GameVisual
华硕显示器OSD的GameVisual是什么东西
**GameVisual** 是华硕（ASUS）显示器 OSD（On-Screen Display，屏幕菜单）中的一项**预设显示模式**功能。它会根据不同使用场景，一次性调整显示器的多个参数
## 常见的GameVisual模式
 不同型号会有区别，但是大多数话术显示器都有以下几种

|模式|适用场景|特点|
|---|---|---|
|Racing（竞速）|默认模式、游戏|响应速度快，颜色较均衡，是很多机型的默认模式。|
|FPS|射击游戏|提高暗部亮度，让躲在阴影里的敌人更容易看见。|
|RTS/RPG|即时战略、角色扮演|增强画面细节和颜色层次。|
|MOBA|英雄联盟、DOTA 等|调整颜色和对比度，使地图和技能更加醒目。|
|Scenery（风景）|看风景照片|提高饱和度，对比度较高，画面鲜艳。|
|Cinema（影院）|看电影|色彩更浓郁，亮度适中。|
|sRGB|图片处理、设计|尽量符合 sRGB 标准色域，颜色最准确，通常会锁定部分参数。|
|Reading（阅读）|阅读文档|降低亮度，减轻眼睛疲劳。|
|Night View（夜景）|黑暗场景|提高暗部细节。|
