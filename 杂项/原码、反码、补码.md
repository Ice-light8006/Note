- **原码**：最高位是符号位，`0` 表示正，`1` 表示负，其余位表示数值的绝对值。
- **反码**：
    - 正数的反码与原码相同；
    - 负数的反码是在原码基础上，符号位不变，其余位全部取反。
- **补码**：
    - 正数的补码与原码相同；
    - 负数的补码等于它的反码加 `1`。
负数的补码转换回原码，可以这样做：
> **符号位不变，其余位取反，再加 1。**
# 例一
```c
#include <stdio.h>

int main(int argc,char** argv)
{
	printf("%d",~2);
	return 0;
}
```
这个代码的打印结果为
```
-3
```
现代计算机中的**有符号整数**通常使用补码表示。2的原码为
```
0000 0010
```
对应的补码为
```
0000 0010
```
然后`~2`，就是把2的补码的每一位都取反，得到
```
1111 1101
```
然后计算机会把这个视为某一个数字的补码进行。而补码符号位保持不变，其余位取反然后加一得到这个数字的原码。对这个数字符号位保持不变，其余数字取反然后加一，得到
```
1000 0011
```
这个数字就是-3的原码
所以打印结果为-3
# 例二
```c
#include <stdio.h>

int main(int argc,char** argv)
{
	char ch = 127;
	ch++;
	printf("%d\n",ch);
	return 0;
}
```
这里127+1得到128
而128的补码为
```
0 1000 0000
```
由于`ch`只有一个字节，那么最左边的符号位0就会被丢弃掉，存入`ch`的数据实际上为
```
1000 0000
```
这会被视为某一个数字的补码。对应的数字为-128
所以打印结果为-128，而不是128
