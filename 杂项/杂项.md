# 单例模式
单例模式的管理机制，就是保证某个类在整个程序运行期间只有一个实例，并提供一个统一的入口让其他代码访问它。
假设你的 Qt 项目里面有一个 `TcpClient`：
```
class TcpClient
{
public:
    void connectToServer();
    void sendData(const QByteArray& data);
};
```
如果普通方式使用：
```
TcpClient client1;
TcpClient client2;
TcpClient client3;
```
那么实际上存在 **3 个 TcpClient 对象**。
它们可能各自维护：
- TCP 连接
- Socket
- 接收缓冲区
- 连接状态
- 信号槽
这时候就容易产生问题：
```
DeviceControl
    ↓
TcpClient A

MainWindow
    ↓
TcpClient B

Protocol
    ↓
TcpClient C
```
到底哪个才是真正的 TCP 连接？

# 2. 单例模式解决什么问题？
单例模式把它变成：
```
             ┌──────────────┐
MainWindow ──┤              │
             │   TcpClient  │
DeviceCtrl ──┤    唯一实例   │
             │              │
Protocol ────┤              │
             └──────────────┘
```
无论谁访问：
```
TcpClient::instance()
```
拿到的都是**同一个对象**。
