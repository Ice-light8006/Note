# 电阻
拿到一个电阻要关注电阻的**数据手册**
电阻的数据手册首先关注**封装**,**标称**,**额定功率**
封装：看电阻是什么样的，是直插的还是贴片的，大小是多大
标称：看电阻表的电阻阻值是多少，精度是多少，误差1%还是5%还是20%的，精度越高越贵
额定功率：决定了耐压值。电阻能通过的最大电流是固定的，额定功率越高，耐压值就越高，超过了电阻的耐压值会导致电阻烧毁

# 上拉、下拉、推挽、开漏
## 第一步：理解万恶之源 —— "悬空（浮空）状态"

在学上拉/下拉之前，你必须先知道为什么要拉它。

在软件里，如果你声明一个局部变量 `int a;` 但不给它赋值，它的值是**随机的垃圾值**（可能是 348291，也可能是 -5）。  
在硬件里，如果一个 GPIO 引脚配置为输入模式，但外面**什么都没接**（没接高电平，也没接地），这个引脚就叫**悬空（Floating）**。

**悬空的引脚就像一根天线**，空气里的电磁干扰、你手靠近时的静电，都会让它的电平在 0 和 1 之间疯狂乱跳。  
如果你用这个引脚去读按键，你会发现：明明没按按键，程序却以为你按了几百次。

**怎么解决这个"垃圾值"问题？**  
软件里，我们会写 `int a = 0;` 给它一个默认值。  
硬件里，我们就用**上拉电阻**或**下拉电阻**，给引脚一个"默认的物理电平"。

---
## 第二步：上拉（Pull-up）与下拉（Pull-down）—— 给引脚设"默认值"

这两个词听起来很高深，其实极其简单：

### 1. 上拉输入 (Pull-up Input)

- **物理动作**：在芯片内部，用一个小电阻（通常几十kΩ）把这个引脚连到 **VCC（3.3V，即高电平 1）**。
- **软件映射**：相当于 `bool pin_state = true; // 默认值为 1`
- **什么时候用？**
    - **读按键（最常见）**：按键一头接引脚，一头接地（GND）。
        - 没按时：引脚被内部电阻"拉"到 3.3V，你读到的是 **1**。
        - 按下时：引脚直接和地（0V）连通，强大的地线把电压拉低，你读到的是 **0**。
    - **I2C 总线**：I2C 的两根线（SDA, SCL）在空闲时必须是高电平，所以必须加上拉电阻。

### 2. 下拉输入 (Pull-down Input)

- **物理动作**：在芯片内部，用一个小电阻把这个引脚连到 **GND（0V，即低电平 0）**。
- **软件映射**：相当于 `bool pin_state = false; // 默认值为 0`
- **什么时候用？**
    - 按键一头接引脚，一头接 3.3V。没按时读到 **0**，按下时读到 **1**。（这种接法不如上拉常见，因为早期芯片抗干扰能力弱，默认低电平更稳定，但现在随便用）。

### 3. 浮空输入 (Floating Input)

- **物理动作**：内部既不接 VCC，也不接 GND。
- **软件映射**：`bool pin_state; // 未初始化，垃圾值`
- **什么时候用？**
    - 当外部电路已经帮你把电平拉得很稳了（比如接了强驱动的信号源），就不需要内部再加电阻干扰了。
    - **新手避坑指南**：如果你不知道选啥，且外面接的是按键或普通传感器，**无脑选上拉或下拉，千万别选浮空**，否则你的程序会"见鬼"。

---

## 第三步：推挽输出 (Push-Pull) —— "我全都要"的霸道模式

这是你**90%的情况下都会用到的输出模式**（比如点灯、驱动蜂鸣器、控制继电器）。

- **它的超能力**：**既能主动输出强悍的高电平（1），也能主动输出强悍的低电平（0）。**
    
- **为什么叫"推挽"？**
    
    - 想象引脚里有两个开关（MOS管）：一个连着天花板（VCC），一个连着地板（GND）。
    - 输出 1 时：天花板开关打开，地板开关关闭。电流从上面**推**出来（Push）。
    - 输出 0 时：天花板开关关闭，地板开关打开。电流被下面**拉**进去（Pull/挽）。
    - 一推一挽，驱动能力极强，能直接点亮小灯泡。
- **软件映射**：就像一个完美的函数，`return 1;` 就是实打实的 1，`return 0;` 就是实打实的 0。

---
## 第四步：开漏输出 (Open-Drain) —— "只能踩刹车"的卑微模式

这个模式新手最容易懵，但它是 **I2C 通信**的绝对核心。

- **它的缺陷**：**它只能主动输出低电平（0），不能主动输出高电平（1）！**
    
    - 如果它想输出 0，它内部的"地板开关"会打开，把引脚狠狠拉到地（GND）。
    - 如果它想输出 1，它内部的"地板开关"会断开。此时，引脚就**悬空（高阻态）**了！它自己给不出高电平。
- **那怎么输出 1 呢？**
    
    - **必须借助外力！** 你必须在外部（或配置内部上拉）接一个上拉电阻到 VCC。
    - 当开漏输出想输出 1 时，它"撒手不管"（断开地板开关），外部的上拉电阻就慢悠悠地把电压"拉"到 VCC，这就变成了 1。
- **为什么要设计这种"残废"的模式？**
    
    - **为了实现"线与"（Wired-AND）**：  
        想象一条总线上挂了 10 个传感器（比如 I2C 总线）。如果大家都用"推挽"，A 传感器想输出 1（连 VCC），B 传感器想输出 0（连 GND）。**VCC 和 GND 直接短路！砰！芯片烧了。**  
        如果用"开漏"，大家都只能"踩刹车（拉低到0）"。只要有一个传感器踩了刹车，整条线就是 0。只有当**所有传感器都不踩刹车（都撒手）**，外部的上拉电阻才会把线拉成 1。  
        这就是完美的"线与"逻辑，谁也不会烧死谁。
        
    - **为了电平转换**：  
        STM32 是 3.3V 系统，但你要控制一个 5V 的模块。推挽输出最高只能给 3.3V。但开漏输出配合一个**接到 5V 的外部上拉电阻**，就能让引脚在 0V 和 5V 之间切换，完美兼容 5V 设备！


**NRST（或写成 nRST、 RST‾RST ）通常表示“低电平有效的复位引脚”**，就是低电平复位的意思
STM32中VDD一般表示高电平
VDD是3V，VBUS是5V

# 热敏电阻
**NTC**：温度越高阻值越低，负温度系数
**PTC**：温度越高组织越高，正温度系数

NTC是对数的，PTC是线性的
正由于PTC是线性的，所以PTC更便于计算一些
而NTC是对数的，有些时候是不利于计算的。
但是，PTC的变化率非常低，当温度变化较小时，PTC的变化量很小
而NTC的变化率较大
这就导致采集信号时NTC更明显一些
而环境温度基本上也就在-30摄氏度到40摄氏度之间，在这个区间内实际上NTC用到的更多，即使PTC是线性的便于计算

# 在STM3最小系统板上设计普通GPIO拓展的原则
普通排针主要引出“用户可编程 GPIO 和常用接口”，不要把电源、时钟、调试专用、模拟专用引脚混进去。
STM32最小系统板上，如果要把引脚用排针接出来方便拓展，通常不要把VDDA和VSSA接出来
因为 **VDDA 和 VSSA 不是普通 IO 引脚**，它们的作用是：
- **VDDA**：模拟电源
- **VSSA**：模拟地
它们主要给这些模块供电：
- ADC
- 模拟部分
- 某些内部模拟电路
通常也不要把OSC_IN与OSC_OUT引出
因为这是 MCU 的时钟源。
晶振信号：
- 频率高
- 幅度小
- 对干扰敏感
如果外部模块接到这里：
可能导致：
- 晶振不起振
- MCU无法启动
- 时钟异常
或者说：
>VDDA / VSSA 不是 GPIO，不建议混在普通扩展排针里。
