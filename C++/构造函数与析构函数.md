# 默认构造函数
**默认构造函数**指的是不需要提供实参就能调用的构造函数
在一个类中，如果你没有定义无参构造函数，那么编译器会自动生成一个默认构造函数
## 默认构造函数的调用时机
例如一个类
```cpp
class Point
{
public:
	Point(int x,int y)
	:x(x),y(y)
	{}
	Point() // 这个没有任何参数的构造函数就是默认构造函数
	{
		x = 0;
		y = 0;
	}
	int x,int y;
}
```
如果你写
```cpp
Point p;
```
则通过默认构造函数构造这个实例化对象`p`
如果你写
```cpp
Point p(10,20);
```
则通过带参数的构造函数进行初始化
如果你写
```cpp
Point p{};
```
这是C++引入的**列表初始化**，它是一种初始化对象的方式，不仅可以用于类对象，还可以用于基本数据类型、数组等。
如果大括号内没有写任何东西，即刚刚展示的`Point p{}`，那么就会调用类`Point`的默认构造函数去初始化对象`p`
实际上，这两种写法：
```cpp
Point p;
Point p{};
```
都是在没有传任何参数的情况下实例化一个对象。
所以默认构造函数的调用时机就是：
> 在实例化对象时，没有传任何参数

但它们采用的初始化规则不同：
- `Point p;`：默认初始化（Default Initialization）。
- `Point p{};`：列表初始化（List Initialization），具体来说是空花括号初始化。
还有一个有意思的情况
如果你写
```cpp
Point p();
```
这就涉及到了一个经典的语法问题：Most Vexing Parse（最令人困惑的解析）。
你可以这样解释：
```
我通过没有任何参数的构造函数来实例化了类Point的一个对象p
```
也可以这样解释：
```
我定义了一个函数，函数名为p，没有任何形参，返回值类型为一个类Point
```
实际上，C++编译器会按照后者理解。因为C++ 语法规则要求将这种形式解析为函数声明。
## 默认构造函数的行为
在初始化时
- **类对象成员：会调用其各自的默认构造函数进行初始化。
- **内置类型成员（如 `int`, `float`, 指针等）**：
    - 如果在**全局/静态作用域**定义对象：会被初始化为零（0 或 `nullptr`）。
    - 如果在局部作用域（如函数体内部）定义对象：**不会**进行初始化，其值是未定义的垃圾值（Uninitialized / Garbage Value）。
## 示例1
```cpp
class Person
{
public:
private:
	int age;
	string name;
}

int main()
{
	Person p;
}
```
这里变量age就是内置类型成员（`int`类型），而`name`就是类对象成员（`string`类的对象）
在调用
```cpp
Person p;
```
时，实例化一个p
这里p是在main函数内部定义的，此时age为未定义的垃圾值，而name则会调用string类的默认构造函数进行初始化，会被初始化为空字符串
如果把p实例化在全局区，这时候age就不会为垃圾值，而是0
## C++11 提供的类内初始值
在实际开发中，为了避免局部变量里的内置类型变成“垃圾值”，C++11 引入了**类内初始值（In-class Initializers）**。你可以直接在声明成员变量时赋值：
```cpp
class Person {
private:
    int age = 0;       // 提供类内默认值
    std::string name;  // 依然会自动调用默认构造函数初始化为空字符串
};
```
这样即使编译器自动为你生成默认构造函数，`age` 也会被可靠地初始化为 `0`，而不会留有垃圾值。
# 带默认参数的构造函数
例如
```cpp
class Point
{
public:
	Point(int x = 0,int y = 0)
	:x(x),y(y)
	{}
	int x,y;
}

int main()
{
	Point p1;
	Point p2(10,20);
	cout << "p1:" << p1.x << ' ' << p1.y << endl;
	cout << "p2:" << p2.x << ' ' << p2.y << endl;
	return 0;
}
```
这时候的运行输出结果为
```output
p1:0 0
p2:10 20
```
这里
```cpp
Point(int x = 0,int y = 0)
```
意思就是，在调用构造函数时，如果没有传任何参数，则这个参数默认为0
在创建`p1`时，构造函数没有传任何参数，此时`p1`的两个成员变量`x`和`y`的值就都是设定的默认值0
在创建`p2`时，构造函数传了参数10和20，此时`p2`的两个成员变了`x`和`y`的值就是你传的参数
另外，这个
```cpp
Point(int x = 0,int y  = 0)
```
也是**默认构造函数**，因为它可以在创建对象时不传任何参数被调用，而C++对默认构造函数的定义就是不传任何参数就可以被调用的构造函数
# 带参数的构造函数
带参数的构造函数（Parameterized Constructor），也称为有参构造函数，是指在构造函数的形参列表中声明了一个或多个形参的构造函数。
例如：
```cpp
class Point
{
public:
	Point(int x,int y)
	:x(x),y(y)
	{}
	int x,y;
}
```
这里这个
```cpp
Point(int x,int y)
:x(x),y(y)
{}
```
就是带参数的构造函数
另外，有参构造函数和默认构造函数并不是完全互斥的。带默认参数的构造函数是带参数的构造函数的子集
