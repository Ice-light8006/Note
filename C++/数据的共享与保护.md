# 类的静态成员变量与静态成员函数
一个类中，被`static`关键字标识的成员变量/成员函数称为静态成员变量/成员函数
## 静态成员变量
在定义成员变量时，加上`static`关键字，这个变量变成静态成员变量
静态成员变量的主要作用：该类的所有实例化对象共享这个静态成员变量
```cpp
class Point
{
public:
	static int count;
	int x;
	int y;
};
```
注意，不能这样写
```cpp
class Point
{
public:
	static int count = 0;
	int x;
	int y;
};
```
对于非 `inline`、非 `const` 的普通静态数据成员，不能直接在类内初始化。这样是错的。
在类内写
```cpp
static int count
```
意思是，在类内声明一个静态成员变量`count`,但是还需要在类外去定义它。
因此正确的初始化是这样的：
```cpp
class Point
{
public:
	static int count;
	int x;
	int y;
};

int Point::count = 1;
```
这个类`Point`的所有实例化对象共享这个静态成员变量
可以使用类名来访问这个变量
```cpp
cout << Point::count << endl;
```
这个打印结果为1
也可以通过类名来修改这个静态成员变量的值
```cpp
Point::count = 10;
cout << Point::count << endl; // 打印结果为10
```
这也说明静态成员变量不属于某一个具体的对象
也可以通过实例化对象的名字来访问
```cpp
Point p1;
Point p2;

cout << p1.count << endl; // 结果为1

p1.count++;

cout << p2.count << endl; // 结果为2
```
这个程序可以说明所以类对象共享静态成员变量
静态成员变量具有**静态存储期**（static storage duration），它的存储持续整个程序运行期间，不会因为某个 `Point` 对象被销毁而消失。
## 静态成员函数
### 静态成员函数的定义
在类内声明成员函数时，使用 `static` 关键字修饰，这个函数就成为静态成员函数。
```cpp
class Point
{
public:
    static int count;

    static void printCount();
};

int Point::count = 0;

void Point::printCount()
{
    cout << count << endl;
}
```
注意：
- `static` 只需要在类内声明时使用，类外定义时不需要重复添加。
- 静态成员函数属于类，不依赖于某个具体对象。
- 所有对象调用的是同一个静态成员函数，而不是每个对象拥有一个独立的函数副本。
### 静态成员函数的访问方式
与静态成员变量类似，静态成员函数也有两种访问方式。
方式一：通过类名访问（推荐）
```cpp
Point::printCount();
```
方式二：通过对象访问
```cpp
Point p1;
Point p2;

p1.printCount();
p2.printCount();
```
两种访问方式都是合法的。
不过，推荐使用 `类名::函数名()`，因为它更能体现静态成员函数不依赖具体对象的特点。
### 静态成员函数没有`this`指针
这是静态成员函数与普通成员函数最重要区别
因为静态成员函数不属于某一个实例化的对象，所以不存在`this`指针的概念
### 静态成员函数只能直接访问静态成员
```cpp
class Point
{
public:
    static int count;
    int x;
    int y;

    static void print()
    {
        cout << count << endl; // 正确
        cout << x << endl;     // 错误
        cout << y << endl;     // 错误
    }
};
```
但是只是不能直接访问非静态成员，不是完全不能访问
如果明确指定某个对象，就可以访问该对象的非静态成员。
例如
```cpp
class Point
{
public:
    static int count;
    int x;

    static void printX(const Point& p)
    {
        cout << p.x << endl; // 正确
    }
};
```
记住这张表即可

| 访问关系            | 是否允许直接访问 |
| --------------- | -------- |
| 静态成员函数 → 静态成员变量 | 是        |
| 静态成员函数 → 普通成员变量 | 否        |
| 静态成员函数 → 静态成员函数 | 是        |
| 静态成员函数 → 普通成员函数 | 否        |
| 普通成员函数 → 静态成员   | 是        |
| 普通成员函数 → 普通成员   | 是        |
# 友元函数
## 友元函数的定义
友元函数是由类通过 `friend` 声明、被授予访问该类 `private` 和 `protected` 成员权限的函数。
例如
```cpp
class Point
{
public:
private:
int x;
int y;
};

float Distance(const Point &p1,const Point &p2)
{
	float dis = pow(p1.x-p2.x,2)+pow(p1.y-p2.y,2);
	dis = sqrt(dis);
	return dis;
}
```
这样写会报错，因为你在类的外部，全局函数`Distance`中访问了类的私有成员
这时候就可以把全局函数`Distance`标记为类的友元函数
```cpp
class Point
{
public:
	friend float Distance(const Point &p1,const Point &p2);
private:
	int x;
	int y;
};

float Distance(const Point &p1,const Point &p2)
{
	float dis = pow(p1.x-p2.x,2)+pow(p1.y-p2.y,2);
	dis = sqrt(dis);
	return dis;
}
```
这样就可以在类内指定的一个友元函数中访问该类的私有变量
一个类的友元函数可以访问该类的
- `public`
- `private`
- `protected`
另外要注意，类的友元函数不是该类的成员函数。

# 友元类
## 友元类的定义
语法如下
```cpp
friend A;
```
意思是：把类A作为我的友元类，友元类可以访问我的私有、公有和保护成员变量
例如：
```cpp
class B
{
};

class A
{
public:
	friend B;
};
```
但这种写法有一定局限性
`friend B;` 是 C++11 新增的语法，这种写法要求 B 已经被声明为类类型（或对应的类型别名）。而 `friend class B;` 从 C++98 就已经支持，并且不要求 B 提前声明。如果我们这样写：
```cpp
class A
{
public:
	friend B;
};

class B
{
};
```
在C++11之后，就会报错，因为在类A的前面没有声明类B
这样写才是正确的
```cpp
class B; // 先声明B是一个类

class A
{
public:
	friend B;
};

class B
{
};
```
其实还有一种写法，不需要事先声明B是一个类：
```cpp
class A
{
public:
	friend class B;
};

class B
{
};
```
## 友元类声明的单向性
注意，友元类的声明是单向的。可以这样理解：
```cpp
friend xxx;
```
相当于：把xxx声明为我的朋友，他是我的朋友所有可以随便访问我
但是，对方不一定把我当成朋友。
## 友元类没有传递性
例如有三个类A,B,C
```cpp
class A
{
public:
	friend class B;
};

class B
{
public:
	friend class C;
};

class C
{
public:
};
```
虽然B可以访问A的所有成员变量，C可以访问B的所有成员变量，但是C无法访问A的所有成员变量。这就是友元类没有传递性
也就是说：
>朋友的朋友，不一定是自己的朋友
## 友元关系不能继承
看这段代码
```cpp
class A
{
public:
	friend class B;
};

class B
{
public:
};

class C :public B
{
public:
};
```
C虽然继承A的朋友B,但是C不能访问A中的私有成员。
## 一个类可以把类的成员函数作为友元函数
我们刚才对例子是把全局函数作为类的友元函数，其实类的成员函数也可以作为友元函数
```cpp
class B; // 要添加前向声明


class A
{
public:
	void show(const B &b);
};

class B
{
public:
	friend void A::show(const B &b);
private:
	int x;
};

void A::show(const B &b)
{
	cout << b.x << endl;
}
```
这时候类A中的成员函数`show`就可以访问类B的私有变量`x`
这里要注意，需要前向声明
但是单单前向声明还不够
前向声明：
```cpp
class B;
```
前向声明 `class B;` 只能让编译器知道 B 是一个类，但此时 B 仍然是不完整类型（Incomplete Type），编译器尚不知道 B 的完整定义，包括它有哪些成员变量和成员函数。
这时候如果把A的成员函数`show`定义在类B的前面，会报错，因为这个A的成员函数不知道B有哪些成员
所以这里把`show`定义在了类B的后面。
## `friend`声明不受访问限定符的影响
无论放在 public、protected 还是 private 区域，效果都是一样的。
例如：
```cpp
class A
{
private:
    friend class B;
};
```
与
```cpp
class A
{
public:
    friend class B;
};
```
完全等价。
因为 friend 不是普通成员声明，而是在授予访问权限。
# 共享数据的保护
## 常对象
创建对象的时候使用`const`关键字，则这个对象变成常对象
在通常的成员访问规则下，不能通过常对象修改其非 `mutable` 数据成员。
需要注意，`const` 主要是一种**编译期约束**，并不意味着对象所涉及的所有内存都绝对不可变化
例如
```cpp
class Point
{
public:
	Point(int x = 0,int y = 0);
private:
	int x;
	int y;
};

const Point p1;// 定义一个常对象p1
```
常对象在程序运行期间不允许被修改。即该对象的数据成员值在整个生存期内不能被修改，因此常对象必须进行初始化且不能被更新。
### 常对象的初始化方式
常对象必须进行初始化，且不能被更新
对于刚刚的例子
```cpp
const Point p1;
const Point p2(10,20);
const Point p3{10,20};
```
这三种初始化方式都可以
其中`p1`会调用`Point`的默认构造函数
### 访问常对象成员的方式
访问对象成员的方式有两种，一种是通过对象名访问，另一种是通过对象成员函数来访问。
第一，为了防止通过对象名修改常对象的数据成员，在常对象中，常对象的数据成员都被视为常量。
第二，为了防止通过对象成员函数修改常对象的数据成员，无法通过常对象调用该常对象的普通成员函数
### 常对象可以调用哪些成员函数？
这是常对象最重要的知识点之一
```cpp
class Point
{
public:
    Point(int x = 0) : x(x) {}

    void setX(int value)
    {
        x = value;
    }

    int getX()
    {
        return x;
    }

private:
    int x;
};

int main()
{
	const Point p(10);

	p.setX(20); // 错误
	p.getX();   // 错误
}
```
第一个错误很好理解，`setX()`修改了常对象的成员变量，而常对象不允许通过这种方式修改
但是第二个错误是为什么呢？
因为在 C++ 中，成员函数是否会修改对象，是通过函数声明中的 `const` 限定来约束的，而不是由编译器分析函数体有没有赋值语句来决定。
此时 `getX()` 是普通成员函数，因此不能通过常对象调用。
解决方法是将 `getX()` 声明为常成员函数：
```cpp
int getX() const
{
    return x;
}
```
## 常数据成员
### 常数据成员的定义
就是在类的数据成员声明前添加 `const` 关键字。
例如：
```cpp
class Student
{
public:
    const int id;
    int age;
};
```
这里：
- `id` 是常数据成员。
- `age` 是普通数据成员。
对于同一个 `Student` 对象，`id` 初始化完成后不能修改，但 `age` 可以修改。
常数据成员只能读取不能修改
需要注意：即使整个对象不是常对象，其内部的常数据成员也不能修改。
### 常数据成员必须进行初始化
```cpp
class Student
{
public:
	Student(int id,int age)
	{
		this->id = id;// 报错
		this->age = age;
	}
    const int id;
    int age;
};
```
为什么这里这个`this->id`会报错？
因为当函数开始执行构造函数体时，数据成员的初始化阶段已经结束
此时再执行
```cpp
this->id = id;
```
执行的是赋值操作，而不是初始化操作
正确写法：
```cpp
class Student
{
public:
	Studnet(int id,int age)
	:id(id),age(age)
	{
	}
	
	const int id;
	int age;
}
```
初始化列表中的：
```cpp
: id(id), age(age)
```
在进入构造函数函数体之前完成数据成员初始化。
这也是为什么常数据成员一般需要通过构造函数初始化列表进行初始化。
### C++11支持类内成员初始化
C++11 引入了默认成员初始化器，因此常数据成员也可以直接在类内初始化：
```cpp
class Student
{
public:
	cosnt int id = 2001;
	int age;
}
```
这时候，在实例化对象时，实例化对象的`id`的值为`2001`
也可以同时使用默认成员初始化器和初始化列表
```cpp
class Studnet
{
public:
	Studnet(int id)
	:id(id)
	{}
	
	const int id = 2001;
}

int main()
{
	Student s1;
	Student s2(1001);
	cout << s1.id << endl;
	cout << s2.id << endl;
}
```
这时候的打印结果为
```output
2001
1001
```
如果执行
```cpp
Student s1;
```
这时候会调用默认初始化函数来实例化对象`s1`，这时候`id`的值就是类内成员初始化的值
如果执行
```cpp
Student s2(1001);
```
那么就会调用带参数的构造函数来实例化对象`s2`，这时候带参数的构造函数的形参`1001`会覆盖类内成员初始化的值`2001`，这时候`id`的值为`1001`
## 常成员函数
### 常成员函数的定义
在一个类中，被`const`修饰的成员函数称为常成员函数
例如
```cpp
class Point
{
public:
	void print() const; //常成员函数
private:
};

void Point::print() const //实现部分也必须带const关键字
{
}
```
这里有一个注意点
- `const`关键字是函数定义的一部分，类中生命有`const`，在外部实现时，也需要加上`const`修饰
另外，要注意一下这两个的区别
```cpp
int A() const;// 常成员函数
const int A();// 返回值类型为const int的普通成员函数
```
### `const`也可以用来作为对函数重载的区分
例如下面这个例子
```cpp
class Point
{
public:
	void print();
	void print() const; //常成员函数
private:
};


void Point::print()
{
}

void Point::print() const //实现部分也必须带const关键字
{
}
```
这里这两个函数
```cpp
void Point::print();
void Point::print() const;
```
他们会被认为是同一个函数`print`的重载（函数类型不同，一个是`void`,一个是`const void`）
-  在常成员函数中不能更新任何数据成员，也不能调用该类中没有用`const`修饰的成员函数，**只能调用常成员函数和使用常数据成员**
### 常成员函数为什么不能修改数据成员？
可以从`this`指针的理解入手
```cpp
class Point
{
public:
	int setX(int value)
	{
		x = value;
	}
	int x,y;
};
```
这里的
```cpp
x = value;
```
可以理解为
```cpp
this->x = value;
```
在这个例子中，对于`Point`类的普通成员函数，`this`指针的类型为
```cpp
Point*
```
但是如果代码变成这样
```cpp
class Point
{
public:
	int setX(int value) const
	{
		x = value;
	}
	int x,y;
};
```
函数`setX(int value)`变成了常成员函数
在这个常成员函数中，`this`指针的类型为
```cpp
const Point*
```
这时候`this->x`等价于对`this`解引用然后访问其成员变量`x`
```cpp
(*this)
```
得到的是一个常对象其类型为`const Point` ，那么
```cpp
this->x = value
```
相当于修改常对象的成员变量，这显然是不允许的。
所以，常成员函数不可以修改数据成员
本质上，在函数声明后面加`const`关键字，只发生了一件事：
>使函数内部 `this` 指针的类型由 `Point*` 变为 `const Point*`，从而禁止通过 `this` 指针修改对象的非 `mutable` 数据成员。

### 常成员函数之间的调用关系
先来看一段代码
```cpp
class Point
{
public:
	void func1()
	{
		func2();// 正确
		func3();// 正确
	}
	
	void func2() const
	{
		func1();// 错误
		func3();// 正确
	}
	
	void func3() const
	{
	}
}
```
规则如下：
普通成员函数可调用常成员函数和普通成员函数
常成员函数只能调用常成员函数
原因很简单：
- 普通成员函数中的 `this` 是 `Point*`，既可以访问普通成员函数，也可以访问常成员函数。
- 常成员函数中的 `this` 是 `const Point*`，不能通过它调用同一个类的非静态非常成员函数。
### 常成员函数可以被普通对象调用
例如
```cpp
Point p1;
const Point p2;

p1.getX(); // 正确
p2.getX(); // 正确
```
常成员函数并不是只能由常对象调用。
##  常变量
常变量用关键字`const`来修饰
例如
```cpp
const int a = 5;
```
这里列出一个特殊的地方：
