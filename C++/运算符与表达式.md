# 表达式
在 C++ 中，表达式（Expression）是由操作数、运算符以及其他语法结构组成的，用来表示一个计算、对象或函数的指代，或者产生某种副作用的语法结构。
下面这些例子都是C++中的表达式

| 表达式         | 含义          |
| ----------- | ----------- |
| `10`        | 字面量表达式      |
| `a`         | 标识符表达式，指代变量 |
| `a + b`     | 算术表达式       |
| `a > b`     | 关系表达式       |
| `a = 10`    | 赋值表达式       |
| `++a`       | 自增表达式       |
| `func()`    | 函数调用表达式     |
| `a + b * 2` | 复合表达式       |
可以发现，表达式不一定要包含运算符。
例如，单独的 `10`、`a` 都可以是表达式。
## 表达式与表达式的值
```cpp
int a = 5;
int b = 3;
int c  = a + b;
```
这里`a+b`是一个表达式，而8就是这个表达式的值
### 自增表达式的值
例如
```cpp
int a = 3;
int b = a++;
```
这里执行`a++`之后，`a`变成4，而`a++`这个表达式的值是自增之前的值3，所以`b`的值为3
再看
```cpp
int a = 3;
int b = ++a;
```
这里执行`++a`之后，`a`变成4，而`++a`这个表达式是自增之后的值4，所以`b`的值为4
### 赋值表达式的值
这个很容易被忽略
```cpp
int a,b;
b = (a = 10);
```
这里`a=10`是一个赋值表达式，其值为一个代表这个赋值表达式的左值`a`，所以这个表达式的值为10，然后将这个表达式的值赋值给`b`，得到`b`的值为10
### 复合赋值表达式的值
假如#是一个运算符，下面的复合赋值表达式
```cpp
a #= b;
```
等价于
```cpp
a = a # b;
```
是一个左值表达式，标识的对象为变量`a`
所以表达式
```cpp
a #= b;
```
为代表变量`a`的左值，即`a#b`
### 表达式的值类别
C++ 对表达式还有一个更严格的分类，叫做值类别（Value Category）。
有左值和右值，而右值又分为纯右值和将亡值

| 值类别     | 名称  | 简单理解             |
| ------- | --- | ---------------- |
| lvalue  | 左值  | 表示一个具有身份、可以定位的对象 |
| xvalue  | 将亡值 | 表示资源可能被转移的对象     |
| prvalue | 纯右值 | 用于初始化对象或计算结果的纯粹值 |
例如：
```cpp
int a = 10;

a;       // 左值
10;      // 纯右值
a + 5;   // 纯右值
++a;     // 左值
a++;     // 纯右值
```
左值的核心特点：能放在等号左边、有名字、有固定内存地址
纯右值的核心特点：只能放在等号右边、没有名字、是临时值、用完就销毁
```cpp
int a = 10;
```
这里`a`是一个左值表达式，这个表达式标识的对象为变量`a`，其值为10
下面介绍一下`std::move`
`std::move()` 是 C++11 引入的一个工具函数，属于 移动语义（Move Semantics） 体系。
例如
```cpp
string a = "Hello";
string b = std::move(a);
```
这里发生了：
- `a` 原本是一个左值。
- `std::move(a)` 将它转换为一个将亡值（xvalue）。
- 编译器可以据此选择 `string` 的移动构造函数。
- 移动构造函数可以将 `a` 内部管理的字符串资源转移给 `b`，避免重新复制字符串内容。
注意：移动之后，`a` 仍然是一个有效对象，但它的具体状态未指定。不能假设它一定变成空字符串。
### 表达式求值的几个例子
#### 例1
```cpp
int a,b,c;
a = b = c = 10;
```
这个实际上可以解析为
```cpp
a = b = (c = 10);
```
`c`被赋值为了10，然后赋值表达式`c=10`的值为代表赋值表达式的左值`c`，其值为10，所以相当于
```cpp
a = b = 10;
```
即
```cpp
a = (b = 10);
```
后面同理，可以得到`a`,`b`,`c`的值都是10
#### 例2
```cpp
int a = 10;
int b  =20;

(a = b) = 30;

cout << a << endl;
cout << b << endl;
```
这个`(a = b) = 30`与`a = b = 30`完全不一样
首先有
```cpp
a = b
```
这时候`a`被赋值为了20
然后
```cpp
(a=b)=30
```
这时候表达是`a=b`为一个左值表达式，而它标识的是`a`，所以相当于
```cpp
a = 30;
```
而`b`没有被赋值为30，`b`的值还是20
所以最终打印结果为
```cpp
30
20

```
