# 线段树（Segment Tree）

## 一、概念

线段树本质：

> 用二叉树维护区间信息

例如：

```text
                [1,8]
              /       \
          [1,4]       [5,8]
         /    \       /    \
      [1,2] [3,4] [5,6] [7,8]
```

可维护：

- 区间和
- 区间最大值
- 区间最小值
- 区间 gcd
- 区间异或
- 最大子段和

---

## 二、复杂度

| 操作 | 复杂度 |
|---|---|
| 建树 | O(n) |
| 单点修改 | O(log n) |
| 区间查询 | O(log n) |
| 区间修改 | O(log n) |

适合：

```text
频繁修改 + 频繁查询
```

---

## 三、核心思想

父节点信息：

```text
由左右儿子合并得到
```

例如：

```text
sum([1,8])
=
sum([1,4]) + sum([5,8])
```

---

## 四、空间

```cpp
Node tree[N * 4];
```

原因：

```text
线段树是近似完全二叉树
```

# 五、基础模板（区间和）

## 1. 普通线段树

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 1e5 + 5;

int n;
int a[N];

struct Node
{
    int l, r;
    long long sum;
} tree[N * 4];


// 向上更新
void push_up(int p)
{
    tree[p].sum =
        tree[p << 1].sum
        +
        tree[p << 1 | 1].sum;
}


// 建树
void build(int p, int l, int r)
{
    tree[p].l = l;
    tree[p].r = r;

    if (l == r)
    {
        tree[p].sum = a[l];
        return;
    }

    int mid = (l + r) >> 1;

    build(p << 1, l, mid);
    build(p << 1 | 1, mid + 1, r);

    push_up(p);
}


// 单点修改
void update(int p, int x, int val)
{
    if (tree[p].l == tree[p].r)
    {
        tree[p].sum = val;
        return;
    }

    int mid = (tree[p].l + tree[p].r) >> 1;

    if (x <= mid)
        update(p << 1, x, val);
    else
        update(p << 1 | 1, x, val);

    push_up(p);
}


// 区间查询
long long query(int p, int l, int r)
{
    if (l <= tree[p].l && tree[p].r <= r)
        return tree[p].sum;

    int mid = (tree[p].l + tree[p].r) >> 1;

    long long ans = 0;

    if (l <= mid)
        ans += query(p << 1, l, r);

    if (r > mid)
        ans += query(p << 1 | 1, l, r);

    return ans;
}


int main()
{
    cin >> n;

    for (int i = 1; i <= n; i++)
        cin >> a[i];

    build(1, 1, n);

    update(1, 3, 10);

    cout << query(1, 1, 5);

    return 0;
}
```

# 六、Lazy 标记线段树

## 思想

```text
先打标记
以后再下传
```

支持：

```text
区间修改
```

例如：

```text
[2,5] 全部 +10
```

复杂度仍然：

```text
O(log n)
```

---

## Lazy 模板

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 1e5 + 5;

int n;
int a[N];

struct Node
{
    int l, r;
    long long sum;
    long long lazy;
} tree[N * 4];


// 向上更新
void push_up(int p)
{
    tree[p].sum =
        tree[p << 1].sum
        +
        tree[p << 1 | 1].sum;
}


// 下传lazy
void push_down(int p)
{
    long long lazy = tree[p].lazy;

    if (lazy == 0)
        return;

    int left_len =
        tree[p << 1].r
        -
        tree[p << 1].l
        +
        1;

    int right_len =
        tree[p << 1 | 1].r
        -
        tree[p << 1 | 1].l
        +
        1;

    tree[p << 1].sum += lazy * left_len;
    tree[p << 1 | 1].sum += lazy * right_len;

    tree[p << 1].lazy += lazy;
    tree[p << 1 | 1].lazy += lazy;

    tree[p].lazy = 0;
}


// 建树
void build(int p, int l, int r)
{
    tree[p].l = l;
    tree[p].r = r;
    tree[p].lazy = 0;

    if (l == r)
    {
        tree[p].sum = a[l];
        return;
    }

    int mid = (l + r) >> 1;

    build(p << 1, l, mid);
    build(p << 1 | 1, mid + 1, r);

    push_up(p);
}


// 区间修改
void update(int p, int l, int r, int val)
{
    if (l <= tree[p].l && tree[p].r <= r)
    {
        tree[p].sum +=
            1LL * val *
            (tree[p].r - tree[p].l + 1);

        tree[p].lazy += val;

        return;
    }

    push_down(p);

    int mid = (tree[p].l + tree[p].r) >> 1;

    if (l <= mid)
        update(p << 1, l, r, val);

    if (r > mid)
        update(p << 1 | 1, l, r, val);

    push_up(p);
}


// 区间查询
long long query(int p, int l, int r)
{
    if (l <= tree[p].l && tree[p].r <= r)
        return tree[p].sum;

    push_down(p);

    int mid = (tree[p].l + tree[p].r) >> 1;

    long long ans = 0;

    if (l <= mid)
        ans += query(p << 1, l, r);

    if (r > mid)
        ans += query(p << 1 | 1, l, r);

    return ans;
}


int main()
{
    cin >> n;

    for (int i = 1; i <= n; i++)
        cin >> a[i];

    build(1, 1, n);

    // [2,5] 全部 +10
    update(1, 2, 5, 10);

    cout << query(1, 1, 5);

    return 0;
}
```

# 七、位运算技巧

```cpp
p << 1
```

等价于：

```cpp
p * 2
```

表示左儿子。

---

```cpp
p << 1 | 1
```

等价于：

```cpp
p * 2 + 1
```

表示右儿子。

# 十、总结

线段树核心：

```text
二分区间 + 维护信息
```

Lazy核心：

```text
延迟更新
```

最重要：

```cpp
push_up()
push_down()
```

进阶：

- 动态开点
- 主席树
- 最大子段和

- 权值线段树
