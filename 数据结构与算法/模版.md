# 树状数组（Fenwick Tree / BIT）
---
# 1. 核心思想
树状数组本质：

> 用二进制拆分维护前缀信息

支持：
- 单点修改
- 前缀和查询
复杂度：

| 操作  | 时间复杂度    |
| --- | -------- |
| 修改  | O(log n) |
| 查询  | O(log n) |
| 空间  | O(n)     |

相比线段树：
- 更短
- 更快
- 更省空间
- 但功能较少
适合：
- 前缀和
- 区间和
- 逆序对
- 动态频率统计
---
# 2. lowbit
核心函数：
```cpp
int lowbit(int x)
{
    return x & -x;
}
```
作用：

> 取出二进制最低位的 1

例：

|x|二进制|lowbit|
|---|---|---|
|6|110|2|
|12|1100|4|
|8|1000|8|

原因：
```text
x      = 1100
-x     = 0100
x & -x = 0100
```

# 3. 树状数组结构

```cpp
int tree[N];
```
含义：
```text
tree[x]
维护一段区间的和
```
区间长度：
$区间长度=lowbit(x)=x{\&}(−x)$
例如：

|下标|管辖区间|
|---|---|
|tree[1]|[1,1]|
|tree[2]|[1,2]|
|tree[4]|[1,4]|
|tree[6]|[5,6]|
|tree[8]|[1,8]|

# 4. 单点修改
## add(x,val)
```cpp
void add(int x,int val)
{
    while(x<=n)
    {
        tree[x]+=val;
        x+=lowbit(x);
    }
}
```
更新过程：
```text
x += lowbit(x)
```
表示：
> 跳到下一个包含当前点的区间

例：
```text
x=3
3 -> 4 -> 8
```
---
# 5. 前缀和查询
## query(x)
```cpp
int query(int x)
{
    int sum=0;

    while(x)
    {
        sum+=tree[x];
        x-=lowbit(x);
    }

    return sum;
}
```
查询过程：
```text
x -= lowbit(x)
```
表示：
> 去掉当前区间

例：
```text
x=7
7 -> 6 -> 4 -> 0
```
---
# 6. 区间和
区间：
```text
[l,r]
```
计算：
$$sum(l,r)=query(r)−query(l−1)$$
代码：
```cpp
int sum(int l,int r)
{
    return query(r)-query(l-1);
}
```

# 7. 完整模板
```cpp
#include <bits/stdc++.h>
using namespace std;

const int N=1e6+10;

int n,m;
int tree[N];

int lowbit(int x)
{
    return x & -x;
}

void add(int x,int val)
{
    while(x<=n)
    {
        tree[x]+=val;
        x+=lowbit(x);
    }
}

int query(int x)
{
    int sum=0;

    while(x)
    {
        sum+=tree[x];
        x-=lowbit(x);
    }

    return sum;
}

int main()
{
    cin>>n>>m;

    for(int i=1;i<=n;i++)
    {
        int x;
        cin>>x;
        add(i,x);
    }

    while(m--)
    {
        int op,x,y;
        cin>>op>>x>>y;

        if(op==1)
        {
            add(x,y);
        }
        else
        {
            cout<<query(y)-query(x-1)<<'\n';
        }
    }
}
```

# 线段树（Segment Tree）
## 一、概念
线段树本质：
> 用二叉树维护区间信息

例如：
```text
                [1,8]
              /       \
          [1,4]       [5,8]
         /    \       /    \
      [1,2] [3,4] [5,6] [7,8]
```
可维护：
- 区间和
- 区间最大值
- 区间最小值
- 区间 gcd
- 区间异或
- 最大子段和
---
## 二、复杂度

| 操作 | 复杂度 |
|---|---|
| 建树 | O(n) |
| 单点修改 | O(log n) |
| 区间查询 | O(log n) |
| 区间修改 | O(log n) |

适合：
```text
频繁修改 + 频繁查询
```
---
## 三、核心思想
父节点信息：
```text
由左右儿子合并得到
```
例如：
```text
sum([1,8])
=
sum([1,4]) + sum([5,8])
```
---

原因：

```text
线段树是近似完全二叉树
```

# 五、基础模板（区间和）
## 1. 普通线段树
```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 1e5 + 5;

int n;
int a[N];

struct Node
{
    int l, r;
    long long sum;
} tree[N * 4];


// 向上更新
void push_up(int p)
{
    tree[p].sum =
        tree[p << 1].sum
        +
        tree[p << 1 | 1].sum;
}


// 建树
void build(int p, int l, int r)
{
    tree[p].l = l;
    tree[p].r = r;

    if (l == r)
    {
        tree[p].sum = a[l];
        return;
    }

    int mid = (l + r) >> 1;

    build(p << 1, l, mid);
    build(p << 1 | 1, mid + 1, r);

    push_up(p);
}


// 单点修改
void update(int p, int x, int val)
{
    if (tree[p].l == tree[p].r)
    {
        tree[p].sum = val;
        return;
    }

    int mid = (tree[p].l + tree[p].r) >> 1;

    if (x <= mid)
        update(p << 1, x, val);
    else
        update(p << 1 | 1, x, val);

    push_up(p);
}


// 区间查询
long long query(int p, int l, int r)
{
    if (l <= tree[p].l && tree[p].r <= r)
        return tree[p].sum;

    int mid = (tree[p].l + tree[p].r) >> 1;

    long long ans = 0;

    if (l <= mid)
        ans += query(p << 1, l, r);

    if (r > mid)
        ans += query(p << 1 | 1, l, r);

    return ans;
}


int main()
{
    cin >> n;

    for (int i = 1; i <= n; i++)
        cin >> a[i];

    build(1, 1, n);

    update(1, 3, 10);

    cout << query(1, 1, 5);

    return 0;
}
```

# 六、Lazy 标记线段树
## 思想
```text
先打标记
以后再下传
```
支持：
```text
区间修改
```
例如：
```text
[2,5] 全部 +10
```
复杂度仍然：
```text
O(log n)
```
---
## Lazy 模板

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 1e5 + 5;

int n;
int a[N];

struct Node
{
    int l, r;
    long long sum;
    long long lazy;
} tree[N * 4];


// 向上更新
void push_up(int p)
{
    tree[p].sum =
        tree[p << 1].sum
        +
        tree[p << 1 | 1].sum;
}


// 下传lazy
void push_down(int p)
{
    long long lazy = tree[p].lazy;

    if (lazy == 0)
        return;

    int left_len =
        tree[p << 1].r
        -
        tree[p << 1].l
        +
        1;

    int right_len =
        tree[p << 1 | 1].r
        -
        tree[p << 1 | 1].l
        +
        1;

    tree[p << 1].sum += lazy * left_len;
    tree[p << 1 | 1].sum += lazy * right_len;

    tree[p << 1].lazy += lazy;
    tree[p << 1 | 1].lazy += lazy;

    tree[p].lazy = 0;
}


// 建树
void build(int p, int l, int r)
{
    tree[p].l = l;
    tree[p].r = r;
    tree[p].lazy = 0;

    if (l == r)
    {
        tree[p].sum = a[l];
        return;
    }

    int mid = (l + r) >> 1;

    build(p << 1, l, mid);
    build(p << 1 | 1, mid + 1, r);

    push_up(p);
}


// 区间修改
void update(int p, int l, int r, int val)
{
    if (l <= tree[p].l && tree[p].r <= r)
    {
        tree[p].sum +=
            1LL * val *
            (tree[p].r - tree[p].l + 1);

        tree[p].lazy += val;

        return;
    }

    push_down(p);

    int mid = (tree[p].l + tree[p].r) >> 1;

    if (l <= mid)
        update(p << 1, l, r, val);

    if (r > mid)
        update(p << 1 | 1, l, r, val);

    push_up(p);
}


// 区间查询
long long query(int p, int l, int r)
{
    if (l <= tree[p].l && tree[p].r <= r)
        return tree[p].sum;

    push_down(p);

    int mid = (tree[p].l + tree[p].r) >> 1;

    long long ans = 0;

    if (l <= mid)
        ans += query(p << 1, l, r);

    if (r > mid)
        ans += query(p << 1 | 1, l, r);

    return ans;
}


int main()
{
    cin >> n;

    for (int i = 1; i <= n; i++)
        cin >> a[i];

    build(1, 1, n);

    // [2,5] 全部 +10
    update(1, 2, 5, 10);

    cout << query(1, 1, 5);

    return 0;
}
```

# 二进制优化的多重背包
## 原理剖析
多重背包本质上就是有相同物品的01背包。假如一个物品有`n`个，求解时完全可以当成`n`个不同的物品使用01背包进行求解。但是这就面临一个问题，假如一个物品有600个，就会直接当成有600个重复的物品，这时候会时间复杂度会很高。
这时候可以使用二进制优化，把这个600拆分为1+2+4+8+16+32+64+128+256+89，前面的1到256可以表示0到511之间的任意数字，然后加上后面的89就可以表示0到600之间的所有数字。假如这个物品占用空间为1，质量为1，就可以把这种物品分为10组，每组对应的这种物品的个数为1,2,4,8,16,32,64,128,256,89.

| 编号  | 对应物品个数 | 占用空间 | 价值  |
| --- | ------ | ---- | --- |
| 1   | 1      | 1    | 1   |
| 2   | 2      | 2    | 2   |
| 3   | 4      | 4    | 4   |
| 4   | 8      | 8    | 8   |
| 5   | 16     | 16   | 16  |
| 6   | 32     | 32   | 32  |
| 7   | 64     | 64   | 64  |
| 8   | 128    | 128  | 128 |
| 9   | 256    | 256  | 256 |
| 10  | 89     | 89   | 89  |
看这里的对应物品个数，通过组合就可以表示出来0到600之间的所有数字。这样的话就和直接录入600次数据是等价的，但是这相当于只有10个物品，大大降低了复杂度：
- 朴素做法：每个物品拆成$c_i​$个，总物品数 $∑c_i$，复杂度 $O(M×∑ci)$
- 二进制优化：每个物品拆成约 $log⁡_2{c_i}$ 个，总物品数$∑log⁡_2{c_i}$​，复杂度降为$O(M×∑log⁡_2c_i)$
## 例题
### 题目描述
有一个背包容量为$m$，还有$n$种物品，每件物品有$c_j$个，它们的重量分别是$w_1,w_2,...,w_n$，它们的价值分别为$v_1,v_2,...v_n$，它们的个数分别为$c_1,c_2,...,c_n$，求最大总价值。
### 输入格式
第一行：两个整数，M（背包容量，$M<=200$）和N（物品数量，$N<=31$）；
第2,3,...,N+1行：每行三个整数$w_i,v_i,c_i$表示每个物品的重量、价值和个数。
### 输出格式
仅一行，一个数，表示最大总价值。
### 输入样例
```in
10 3
2 1 6
6 10 3
3 6 3
```
输出样例
```out
18
```
### 示例代码
```cpp
#include<iostream>

using namespace std;

int v[105];
int w[105];
int dp[205] = {0};

int main()
{
    int M,N;
    cin >> M >> N;
    int pos = 0;
    for(int i = 0;i<N;i++)
    {
        int v1,w1,c1,k = 1;
        cin >> w1 >> v1 >> c1;
        while(c1>=k)
        {
            v[pos] = v1*k;
            w[pos++] = w1*k;
            c1-=k;
            k<<=1;
        }
        if(c1>0)
        {
            v[pos] = v1*c1;
            w[pos++] = w1*c1;
        }
    }
    for(int i = 0;i<pos;i++)
    {
        for(int j = M;j>=w[i];j--)
        {
            dp[j] = max(dp[j],dp[j-w[i]]+v[i]);
        }
    }
    cout << dp[M] << endl;
    return 0;
}
```

# 有关博弈论问题
## 例一：
问题如下：
-   初始一共有n张卡牌
-   先手第一步最少要拿1张牌，最多要拿n−1张牌。
-   接下来每一步，双方最少要拿1张牌，最多拿等同于上一步对方拿的牌数的牌。
-   拿走最后一张牌的人将取得游戏的胜利。
- 讨论在什么情况下先手具有必胜的策略

对于这个问题先给出结论，当$n = 2^k(k\in N)$时，先手必输，当$n\ne 2^k(k\in N)$时，先手必输

那么问题来了，为什么呢？

首先我们这样想，如果$n = 2^k(k\in N)$时，假设先手拿走了$x$个卡牌，那么后手跟着模仿拿走了$x$张卡牌，那么到下一轮先手时共有$n = 2^k-2x$张卡牌，显然为偶数张。紧接着进行循环往复，直到剩余两张卡牌，这时的先手拿一张后手再拿一张，先手必输。
这里我们会发现，如果$n$不是2的次幂只是偶数，那么$n = 2^k-2x$不也是偶数吗，难道不符合这个规律？
事实上，先手每次拿的一定不能超过一半，否则先手必输，那就只能拿少于一半的数量，那么只有当$n$为2的次幂的时候，这样到最后才有足够的$n$去减去$2x$（这一点慢慢去理解吧）
当$n\ne 2^k(k\in N)$时，先手总是可以拿走一部分让后手面对2的次幂，根据谁面对2的次幂谁必输的原则，后手必输。

下面给出cpp的示例代码
```cpp
#include<iostream>

using namespace std;

bool is2cimi(int n)
{
	if(n<=0)return false;
	return (n&&(n-1))==0;
}

int main()
{
	int n;
	cin >> n;
	if(is2cimi(n)) cout << "先手必输" << endl;
	else cout << "先手必赢" << endl;
	return 0;
}
```
