# 约瑟夫问题的由来
公元 67 年，犹太-罗马战争期间，历史学家 **弗拉维奥·约瑟夫斯**（Flavius Josephus）和同伴被困在约德法特的一个山洞里。据他自己在《犹太战史》中的记载，洞里共 **41 人**，大家约定宁死不降，于是用抽签的方式轮流杀死对方，直到剩下最后一人。约瑟夫斯和另一名同伴最后活了下来，向罗马人投降。
原故事里其实是“抽签定生死”，后来人们把它理想化成了我们今天熟悉的形式：**围成一圈，每次数到 k 的人出列**。“数到 3”是最流行的版本。数学上真正有趣的是它的一般化形式。
# 问题描述
n 个人围成一圈，编号 1 到 n。从 1 号开始报数，报到 k 的人出列；下一个人重新从 1 开始报数，如此反复，直到只剩一个人。求最后幸存者的编号。
例如n = 7,k = 3
```
人的编号：1 2 3 4 5 6 7
报数：3->6->2->5->1->4
最后剩下：7
```
所以这个示例，最后剩下的人是编号为7的人
# 模拟算法
为了方便取模计算，把编号整体减小1，然后得到的结果整体加1
```cpp
#include <iostream>

using namespace std;

int solve()
{
	int n,k;
	cin >> n >> k;
	int cnt;//用来存储当前已经出列的人数
	int index = -1;//用来记录当前出列的人的编号
	while(cnt<n-1)
	{
		cnt++;
		index+=k;
		index %= k;
	}
	index += k;
	index %= k;
	return index;
}

int main()
{
	int ans = solve();
	cout << ans << endl;
	return 0;
}
```
