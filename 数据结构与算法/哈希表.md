# `C++`中`map`与`unordered_map`的区别
| 对比项   | `map`      | `unordered_map`     |
| ----- | ---------- | ------------------- |
| 底层实现  | 红黑树        | 哈希表                 |
| 元素顺序  | 按键自动排序     | 无序                  |
| 查找复杂度 | `O(log n)` | 平均 `O(1)`，最坏 `O(n)` |
| 插入复杂度 | `O(log n)` | 平均 `O(1)`，最坏 `O(n)` |
| 删除复杂度 | `O(log n)` | 平均 `O(1)`，最坏 `O(n)` |
| 对键的要求 | 必须能够比较大小   | 必须能够计算哈希值并判断相等      |
| 范围查找  | 支持         | 不支持                 |
>`map` 和 `unordered_map` 的基本接口相似，但数据组织方式、顺序保证、复杂度和适用场景不同。

# 题目实战
## 例1
### 题目描述
给定一个整数数组 `nums` 和一个整数目标值 `target`，请你在该数组中找出 **和为目标值** _`target`_  的那 **两个** 整数，并返回它们的数组下标。
### 代码实现
```cpp
vector<int> solve(vector<int> &nums,int target)
{
	vector<int> ans;
	unordered_map<int,int> hash;   //哈希表，建立值->下标的关系
	int len = nums.size();
	for(int i = 0;i < len;i++)
	{
		int tmp = target-nums[i];
		auto it = hash.find(tmp);
		if(it!=hash.end())
		{
			ans.push_back(i);
			ans.push_back(it->second);
			return ans;
		}
		hash[nums[i]] = i;
	}
	return ans;
}
```
## 例2
### 题目描述
给你一个整数数组 `nums` 和一个整数 `k` ，请你统计并返回 _该数组中和为 `k` 的子数组的个数_ 。
子数组是数组中元素的连续非空序列。
### 题解
先维护一个前缀和数组`pre`
然后维护一个哈希表
```cpp
unordered_map<int,int> hash;
```
`hash[x]` 表示在当前下标之前，已经出现过的、值为 `x` 的前缀和的个数。
遍历一遍前缀和数组
```cpp
for(int i = 0;i<pre.size();i++)
{
	//...
}
```
对于`pre[i]`，只要从前面找到另一个`pre[j]`(`j<i`)，使得
```
pre[i]-pre[j] = k;
```
即
```
pre[j] = pre[i] - k;
```
那么，`hash[pre[i]-k]`的意义就是以下标`i`上的元素为结尾的所有的子数组中和为`k`的个数
所以，初始化一个计数器`int cnt = 0`用来统计答案，每次遍历到`pre[i]`，都让`cnt`加上`hash[pre[i]-k]`的值。然后再执行`hash[pre[i]]++`维护哈希表。跑完整个循环后最终`cnt`的结果就是答案
但是还要注意一点，就是刚才并没有考虑到从下标为0的元素开始的子数组。即对于`pre[i]`，同时也要考虑
```
pre[i] - 0 = k
```
即：
```
pre[i] = k + 0;
```
那么，初始化哈希表时，一定要让前缀和为0的个数为1，即：
```cpp
hash[0] = 1;
```
### 代码实现
```cpp
int solve(vector<int> &nums,int k)
{
	int ans = 0;
	int len = nums.size();
	vector<int> pre(len,0);
	for(int i = 0;i<len;i++)
	{
		if(i==0)
		{
			pre[i] = nums[i];
		}
		else
		{
			pre[i] = nums[i] + pre[i-1];
		}
	}
	unordered_map<int,int> hash;
	
	//初始时，前缀和为0的个数为1
	hash[0] = 1;
	
	for(int i = 0;i<len;i++)
	{
		int tmp = pre[i]-k;
		auto it = hash.find(tmp);
		if(it!=hash.end())
		{
			ans+=it->second;
		}
		hash[pre[i]]++;
	}
	
	return ans;
}
```
## 例3
### 题目描述
给你一个字符串数组，请你将 字母异位词 组合在一起。可以按任意顺序返回结果列表。
**字母异位词**是通过重新排列不同单词或短语的字母而形成的单词或短语，并使用所有原字母一次。
### 代码实现
```cpp
vector<vector<string>> solve(vector<string> &strs)
{
	vector<vector<string>> ans;
	unordered_map<string,vector<string>> hash;
	for(auto &i:strs)
	{
		string tmp = i;
		sort(tmp.begin(),tmp.end());
		hash[tmp].push_back(i);
	}
	for(auto &i:hash)
	{
		ans.push_back(i.second);
	}
	return ans;
}
```
# 注意事项
## 范围`for`循环
从C++11开始，C++引入了范围`for`循环
语法格式
```cpp
for(元素声明:可遍历对象)
{

}
```
假如写
```cpp
for(auto i:s)
{
}
```
这里写了`auto`，编译器会自动根据`s`推导`i`的类型
假如`s`是元素类型为`int`的数组名
那么就会自动推导出`i`的类型为`int`
另外，这里的`i`是`s`内部元素的拷贝，修改`i`不会对`s`内部的元素造成影响
如果这样写
```cpp
for(auto &i:s)
{
}
```
就是直接引用`s`内部的元素，此时再修改`i`的内容就会直接修改`s`内部的元素
## 结构化绑定
从C++17开始，C++引入了结构化绑定，用来把对象内部的多个成员直接拆分为多个变量
基本语法
```cpp
auto [变量1,变量2,变量3,...] = 对象;
```
对于遍历一些复杂的复合数据类型，例如`pair<int,int>`
这时候就可以尝试利用结构化绑定，以增加代码的书写便捷性
例如
```cpp
pair<int,int> p = {3,4};
auto [u,v] = p;
```
这就是结构化绑定的基本使用，这里
```
u的值为3
v的值为4
```
对于刚刚遍历哈希表，可以尝试使用结构化绑定以提高代码的简洁性和可读性。
同时，这里的`u`和`v`也只是`p`内部成员的值的拷贝
也可以引用
```cpp
pair<int,int> p = {3,4};
auto &[u,v] = p;
```
这时候如果直接修改`u`,`v`的值，就会直接影响到`p`内部成员的值
如果我们这样做
```cpp
pair<int,int> p = {3,4};
auto &[u,v] = p;
u = 5;
```
这时候`p`内部的成员变为：
```
第一个成员的值为5
第二个成员的值为4
```
