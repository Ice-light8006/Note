# 有关博弈论问题
## 例一：
问题如下：
-   初始一共有n张卡牌
-   先手第一步最少要拿1张牌，最多要拿n−1张牌。
-   接下来每一步，双方最少要拿1张牌，最多拿等同于上一步对方拿的牌数的牌。
-   拿走最后一张牌的人将取得游戏的胜利。
- 讨论在什么情况下先手具有必胜的策略

对于这个问题先给出结论，当$n = 2^k(k\in N)$时，先手必输，当$n\ne 2^k(k\in N)$时，先手必输

那么问题来了，为什么呢？

首先我们这样想，如果$n = 2^k(k\in N)$时，假设先手拿走了$x$个卡牌，那么后手跟着模仿拿走了$x$张卡牌，那么到下一轮先手时共有$n = 2^k-2x$张卡牌，显然为偶数张。紧接着进行循环往复，直到剩余两张卡牌，这时的先手拿一张后手再拿一张，先手必输。
这里我们会发现，如果$n$不是2的次幂只是偶数，那么$n = 2^k-2x$不也是偶数吗，难道不符合这个规律？
事实上，先手每次拿的一定不能超过一半，否则先手必输，那就只能拿少于一半的数量，那么只有当$n$为2的次幂的时候，这样到最后才有足够的$n$去减去$2x$（这一点慢慢去理解吧）
当$n\ne 2^k(k\in N)$时，先手总是可以拿走一部分让后手面对2的次幂，根据谁面对2的次幂谁必输的原则，后手必输。

下面给出cpp的示例代码
```cpp
#include<iostream>

using namespace std;

bool is2cimi(int n)
{
	if(n<=0)return false;
	return (n&&(n-1))==0;
}

int main()
{
	int n;
	cin >> n;
	if(is2cimi(n)) cout << "先手必输" << endl;
	else cout << "先手必赢" << endl;
	return 0;
}
```
