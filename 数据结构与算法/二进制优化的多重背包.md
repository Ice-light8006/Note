# 原理剖析
多重背包本质上就是有相同物品的01背包。假如一个物品有`n`个，求解时完全可以当成`n`个不同的物品使用01背包进行求解。但是这就面临一个问题，假如一个物品有600个，就会直接当成有600个重复的物品，这时候会时间复杂度会很高。
这时候可以使用二进制优化，把这个600拆分为1+2+4+8+16+32+64+128+256+89，前面的1到256可以表示0到511之间的任意数字，然后加上后面的89就可以表示0到600之间的所有数字。假如这个物品占用空间为1，质量为1，就可以把这种物品分为10组，每组对应的这种物品的个数为1,2,4,8,16,32,64,128,256,89.

| 编号  | 对应物品个数 | 占用空间 | 价值  |
| --- | ------ | ---- | --- |
| 1   | 1      | 1    | 1   |
| 2   | 2      | 2    | 2   |
| 3   | 4      | 4    | 4   |
| 4   | 8      | 8    | 8   |
| 5   | 16     | 16   | 16  |
| 6   | 32     | 32   | 32  |
| 7   | 64     | 64   | 64  |
| 8   | 128    | 128  | 128 |
| 9   | 256    | 256  | 256 |
| 10  | 89     | 89   | 89  |
看这里的对应物品个数，通过组合就可以表示出来0到600之间的所有数字。这样的话就和直接录入600次数据是等价的，但是这相当于只有10个物品，大大降低了复杂度：
- 朴素做法：每个物品拆成$c_i​$个，总物品数 $∑c_i$，复杂度 $O(M×∑ci)$
- 二进制优化：每个物品拆成约 $log⁡_2{c_i}$ 个，总物品数$∑log⁡_2{c_i}$​，复杂度降为$O(M×∑log⁡_2c_i)$
# 例题
## 题目描述
有一个背包容量为$m$，还有$n$种物品，每件物品有$c_j$个，它们的重量分别是$w_1,w_2,...,w_n$，它们的价值分别为$v_1,v_2,...v_n$，它们的个数分别为$c_1,c_2,...,c_n$，求最大总价值。
## 输入格式
第一行：两个整数，M（背包容量，$M<=200$）和N（物品数量，$N<=31$）；
第2,3,...,N+1行：每行三个整数$w_i,v_i,c_i$表示每个物品的重量、价值和个数。
## 输出格式
仅一行，一个数，表示最大总价值。
## 输入样例
```in
10 3
2 1 6
6 10 3
3 6 3
```
输出样例
```out
18
```
## 示例代码
```cpp
#include<iostream>

using namespace std;

int v[105];
int w[105];
int dp[205] = {0};

int main()
{
    int M,N;
    cin >> M >> N;
    int pos = 0;
    for(int i = 0;i<N;i++)
    {
        int v1,w1,c1,k = 1;
        cin >> w1 >> v1 >> c1;
        while(c1>=k)
        {
            v[pos] = v1*k;
            w[pos++] = w1*k;
            c1-=k;
            k<<=1;
        }
        if(c1>0)
        {
            v[pos] = v1*c1;
            w[pos++] = w1*c1;
        }
    }
    for(int i = 0;i<pos;i++)
    {
        for(int j = M;j>=w[i];j--)
        {
            dp[j] = max(dp[j],dp[j-w[i]]+v[i]);
        }
    }
    cout << dp[M] << endl;
    return 0;
}
```
