# 什么是线性表？
**线性表**（Linear List）是具有相同数据类型的$n$个数据元素的有限序列
当$n$为0时，线性表称为空表。
若用$L$命名线性表，其数学表示为
$$
L = (a_1,a_2,...,a_i,...,a_n)
$$
其中$a_1$称为该线性表的表头元素，$a_n$称为该线性表的表尾元素
除了表头元素之外，每个元素都有一个直接的前驱
除了表尾元素之外，每个元素都有一个直接的后驱
线性表可分为**顺序表**和**链表**
# 顺序表
顺序表就是顺序存储结构的线性表。
例如C语言中的数组就是一个顺序表
在C语言中，我们可以把数组和顺序表的长度封装成一个结构体，如下：
```c
#define MAXSIZE 128
typedef int DataType;

typedef struct node{
	DataType data[MAXSIZE];
	int length;
}SeqList,*PSeqList;
```
顺序表常用的操作函数如下
## 初始化一个顺序表
该函数返回新建的顺序表的指针
```c
PSeqList Init_SeqList(void)
{
	PSeqList PL;
	PL = (PSeqList)malloc(sizeof(SeqList));
	if(PL)
	{
		PL->length = 0;
	}
	return PL;
	//如果PL为0代表分配失败
}
```
## 插入元素
在一个顺序表的索引为`i`对应的元素的前面插入一个节点（可以理解为插入的新节点的索引为`i`），其值为`x`。如果函数执行错误则返回-1
```c
int Insert_SeqList(PSeqList p,DataType x,int i)
{
	if(p->length + 1 > MAXSIZE)
	{
		return -1;
	}
	if(i > p->length || i < 0)
	{
		return -1;
	}
	int j = p->length;
	while(j > i)
	{
		p->data[j] = p->data[j-1];
		j--;
	}
	p->data[i] = x;
	p->length++;
	return 1;
}
```
## 删除元素
删除顺序表中索引为`i`的结点，如果函数执行错误则返回-1
```c
int Delete_SeqList(PSeqList p,int i)
{
	if(i >= p->length || i < 0)
	{
		return -1;
	}
	int j = i;
	while(j < p->length-1)
	{
		p->data[j] = p->data[j+1];
		j++;
	}
	p->length--;
	return 1;
}
```
## 检索操作
在一个顺序表中查找值为`x`的结点并返回其索引，如果找不到则返回-1
```c
int Location_SeqList(PSeqList p,DataType x)
{
	if(p == NULL)
	{
		return -1;
	}
	int i = 0;
	while(i<p->length && p->data[i]!=x)
	{
		i++;
	}
	
	if(i >= p->length)
	{
		return -1;
	}
	return i;
}
```
# 链表
链表是链式存储结构的线性表
每个节点包含两个域：
**数据域**：存放数据元素本身的信息
**指针域**：存放其后继结点的地址
其优点是**便于插入、删除操作，适用于需要频繁插入删除操作的场景**
另外，链表也可以自由控制结点数量，自由分配内存大小
但是，由于每个节点都要有指针域，会额外消耗内存。而且链表不能随机读取，**不适用于需要频繁读取结点的场景**
## 单链表
单链表是链表中最典型的实例
对于一个单链表，首先要区分三个概念：**首元结点**、**头结点**、**头指针**
首元结点：就是第一个结点
头结点：在第一个结点之前附加的一个结点，头结点只使用指针域不使用数据域（有些情况下会使用头结点的数据域来存储整个链表的长度）。其最大的作用是统一和简化操作逻辑，消除边界条件的特殊判断。不管单链表是否为空，头结点的指针都不为空。如果单链表为空，则头结点的指针域为空。有时候头结点也称为**哨位结点**
头指针：**头指针是访问链表的唯一入口**。如果有头结点，则指向头结点；如果没有头结点且链表不为空，则指向首元结点；如果没有头结点且是空表，则头指针为NULL
注：下面的笔记不做说明的情况下，默认是带头结点的链表
### 数据类型定义
```c
typedef int DataType;
typedef struct Node
{
	DataType data;
	struct Node* next;
}*pList,List;
```
### 创建一个空链表
如果创建成功，返回哨位头结点，如果创建失败，返回空指针
```c
pList Init_List(void)
{
	pList p = (pList)malloc(sizeof(List));
	if(p==NULL)
	{
		return NULL;
	}
	p->next = NULL;
	return p;
}
```
### 销毁单链表
单链表被构造之后，其结点均为`malloc`在堆上分配的内存，需要手动调用`free()`来释放，否则会造成内存空间的浪费
```c
void Destroy_List(pList* p)
{
	if(p==NULL)
	{
		return;
	}
	pList m = *p;
	pList n;
	while(m)
	{
		n = m->next;
		free(m);
		m = n;
	}
	*p = NULL;
}
```
这里要传入头结点的指针的地址，而不是头结点的指针，因为释放之后，头结点的指针就变成了悬空指针，我们要在函数内把头结点的指针置空，操作指针变量就需要传二级指针，在这里也就是头结点指针的地址
### 求表长
这里要注意，头结点仅是用来统一和简化操作逻辑，简化边界条件的特殊判断的，所以求表长的时候不要算头结点
```c
int Length_List(pList p)
{
	if(NULL == p)
	{
		return 0;
	}
	int len = 0;
	while(p->next)
	{
		p = p->next;
		len++;
	}
	return len;
}
```
### 查找操作
#### 按索引查找
函数返回链表中索引为`i`的结点的指针，如果不存在索引为`i`的指针或者传入的头指针为空，则返回NULL
```c
pList Locate_List(pList p,int i)
{
	if(NULL == p || i < 0)
	{
		return NULL;
	}
	pList t = p;
	int j = -1;
	while(t->next!=NULL)
	{
		j++;
		t = t->next;
		if(j==i)
		{
			return t;
		}
	}
	return NULL;
}
```
#### 按值查找
返回链表中数据域值为`x`的结点的指针，如果传入的头指针为空或者不存在数据域值为`x`的指针，则返回NULL
```c
pList Locate_List(pList p,DataType x)
{
	if(NULL == p)
	{
		return NULL;
	}
	pList cur = p->next;
	while(cur->data!=x)
	{
		if(NULL == cur->next)
		{
			return NULL;
		}
		cur = cur->next;
	}
	return cur;
}
```
### 插入操作
插入一个新的结点，使得新的结点的索引为`i`
参数列表：
- `PList p`：头指针
- `int i`：要插入的索引
- `PList Node`：要插入的结点的指针
返回值：
- 如果插入成功，返回插入结点的指针
- 如果`p`为空，返回NULL
- 如果`Node`为空，返回NULL
- 如果索引`i`超过了表长所允许的范围，返回NULL
- 如果索引`i`小于0，返回NULL
```c
pList Insert_List(pList p,int i,pList Node)
{
	if(NULL == p || NULL == Node)
	{
		return NULL;
	}
	if(Length_List(p) < i || i < 0)
	{
		return NULL;
	}
	int j = -1;
	while(j!=i-1)
	{
		p = p->next;
		j++;
	}
	Node->next = p->next;
	p->next = Node;
	return Node;
}
```
### 删除操作
删除链表的索引为`i`的结点
参数列表：
- `PList p`：头指针
- `int i`：要删除的结点的索引
返回值：
- 如果删除成功，返回删除后第`i`个结点的指针
- 如果`p`为空，返回NULL
- 如果索引`i`超过了表长所允许的范围，返回NULL
- 如果索引`i`小于0，返回NULL
```c
pList Delete_List(pList p,int i)
{
	if(NULL == p)
	{
		return NULL;
	}
	if(i < 0 || Length_List(p) <= i)
	{
		return NULL;
	}
	int j = -1;
	while(j!=i-1)
	{
		j++;
		p = p->next;
	}
	pList tmp = p->next->next;
	free(p->next);
	p->next = tmp;
	return tmp;
}
```
## 循环链表
单链表的最后一个结点的指针域是空指针。如果将最后一个结点的指针域改为头指针，那么就得到了循环链表
单链表如果想要遍历所有的结点，只能从头结点开始遍历
但是循环链表从任意一个结点开始，都可以可以遍历到任意一个结点
这里要注意一个细节，因为最后一个结点的指针域存的是头指针，在有哨位头结点的时候，头指针指向哨位头结点，在没有哨位头结点时，头指针指向第一个结点。所以，如果带有哨位头结点，那么最后一个结点的指针域指向的就是哨位头结点，如果没有哨位头结点，那么最后一个结点的指针域指向的就是第一个结点
### 循环链表的标识方法
尾指针：指向最后一个结点的指针
普通单链表的标识方法是利用头指针。但是如果单链表想获得尾指针，需要一次一次进行`next`操作来获取。但是，循环链表有一个技巧：
>不利用头指针作为链表的标识，而是利用尾指针作为链表的标识

假设尾指针为`R`，这时候，如果想访问头结点，直接一个`R->next`就可以了，如果想访问尾结点，直接利用位置帧即可。这样提高了访问效率。
### 创建一个循环链表
- 参数列表：空
- 函数名：`List_Create`
- 返回值：类型为`pList`。如果创建成功，则返回创建的链表的尾指针。如果创建失败，则返回空指针。
```c
pList List_Create()
{
    pList rear = (pList)malloc(sizeof(List));
    if(rear == NULL)
    {
	    return NULL;
    }
    rear->next = rear;
    return rear;
}
```
这地方要注意的就是，创建循环链表与创建普通链表不同，循环链表在创建空表时，要把哨兵节点的`next`指向其自身
### 查看是否存在结点
- 参数列表：`pList tail,pList Node`，`tail`为循环链表的尾指针，`Node`为要检查的结点
- 函数名：`List_Exist`
- 返回值：类型为`pList`，如果链表中不存在结点`Node`，或者传入的`tail`为空指针，或者传入的`Node`为空指针，则返回NULL，否则返回结点`Node`的地址。
注意，检查的范围包括哨位头结点
```c
pList List_Exist(pList tail,pList Node)
{
	if(NULL == tail || NULL == Node)
	{
		return NULL;
	}
	pList p = tail->next;
	pList t = p;
	int j = -1;
	do
	{
		if(t == Node)
		{
			return Node;
		}
		j++;
		t = t->next;
	}while(t != p);
	
	return NULL;
}
```
### 在循环链表中插入
- 参数列表：`pList* tail, pList Node, int i`，`tail`为指向循环链表的尾指针的二级指针，`Node`为要插入的结点的指针，`i`为要插入的索引
- 函数名：`List_Insert`
- 返回值：`int`类型，如果插入成功则返回1，如果插入失败则返回0
执行之后，`Node`会被插入到链表中索引为`i`的位置（假设索引从0开始）
```c
int List_Insert(pList* tail, pList Node, int i)
{
	if (i<0)
    {
        return 0;
    }
	if(tail == NULL)
	{
		return 0;
	}
	if(*tail == NULL)
	{
		return 0;
	}
	if(NULL == Node)
	{
		return 0;
	}
	pList p = (*tail)->next;
	if(Node == p)
	{
		return 0;
	}
    if(List_Exist(*tail,Node))
    {
	    return 0;
    }
    int j = -1;
    pList t = p;
    while (t->next != p && j < i - 1)
    {
        t = t->next;
        j++;
    }

    if (j != i - 1)
    {
        return 0;
    }

    Node->next = t->next;

    t->next = Node;
    
    if(t == *tail)
    {
	    *tail = Node;
    }

    return 1;
}
```
注意事项：
- 与普通链表不同，循环链表在插入时，不能以当前结点的`next`是否为空指针来判断是否到达了链表尾部。因为循环链表的最后一个结点的`next`是哨位头结点。所以判断是否到达链表尾部的条件就是`t->next!=p`
- 循环链表在插入时，一定要先判断传入的`Node`是否为头结点，如果是则直接结束函数。如果尝试插入哨位头结点，可能会直接破坏整个链表的结构
- 在插入之前，要判断`Node`是否已经在链表中存在了
- 还有，如果恰好插入到了尾指针后面，需要更新维护尾指针。这时候就需要传二级指针，传了二级指针就需要防止二级指针为空和这个二级指针指向的指针为空
- 传入的索引必须是一个自然数
### 在循环链表中删除
- 参数列表：`pList tail, int i`，`tail`为链表的尾指针，`i`为要删除的结点的索引
- 函数名：`List_Delete`
- 返回值：`int`类型，如果删除失败则返回0，如果删除成功则返回1
```c
int List_Delete(pList tail, int i)
{
	pList p = tail->next;
    if (NULL == p || i < 0)
    {
        return 0;
    }

    pList t = p;

    int j = -1;
    while (t->next != p && j < i - 1)
    {
        t = t->next;
        j++;
    }

    //结点数量小于i+1个
    if(j!=i-1 || t->next == p)
    {
        return 0;
    }

    pList tmp = t->next->next;
    free(t->next);
    t->next = tmp;
    return 1;
}
```
### 在循环链表中的查找操作
#### 按值查找
- 参数列表：`pList tail,DataType data`，`tail`为链表的尾指针，`data`为要查找结点的数据域
- 函数名：`List_Locate`
- 返回值：类型为`pList`，如果找到了，则返回对应结点的指针，如果没找到，则返回NULL
```c
pList List_Locate(pList tail,DataType data)
{
    if(NULL == tail)
    {
        return NULL;
    }

	pList p = tail->next;
    pList t = p->next;

    while(t != p)
    {
        if(t->data == data)
        {
	        return t;
        }
        t = t->next;
    }

    return NULL;
}
```
##### 注意事项
- 如果`t`是哨位头结点，一定不能直接比较`t->data == data`，而是先执行`t = t->next`跳过哨位头结点，因为哨位头结点的数据域在分配内存时是一个随机值，有可能会恰好与要查找的`data`相等。而这里则直接让`t`为首元结点。

### 合并两个循环链表
现在有一个链表H1和一个链表H2，两个链表都是带哨位头结点的循环链表。现在我们要合并这两个链表
首先，合并链表就是让H1的最后一个结点的指针域指向H2的头结点，H2的最后一个结点的指针域指向H1的头结点
但是不能直接这样操作，因为如果这样会出现下面这种情况
<div style="font-family: Consolas, monospace; font-size: 18px; line-height: 2;">
    <span style="padding: 6px 10px; border: 1px solid #666; border-radius: 6px;">
        H1 哨位头结点
    </span>

    <span> → ... → </span>

    <span style="padding: 6px 10px; border: 1px solid #c44; border-radius: 6px;">
        H2 哨位头结点
    </span>

    <span> → </span>

    <span style="padding: 6px 10px; border: 1px solid #666; border-radius: 6px;">
        H2 首元结点
    </span>

    <span> → ...</span>
</div>
看看标红的这一处，发现了吗，这出现了两个哨位头结点，这显然是不可以的。这一点在处理的时候需要格外注意一下
下面给出合并两个循环链表的函数：
参数列表：
- `PList R1`：第一个循环链表的尾指针
- `PList R2`：第二个循环链表的尾指针
返回值：
- 如果成功合并，则返回合并得到的新的链表的尾指针
- 如果`R1`为NULL，返回NULL
- 如果`R2`为NULL，返回NULL
另外，这里我们规定当循环链表为空时，尾指针就是头指针。当循环链表为空时，尾指针的指针域指向自身
```c
pList Merge_List(pList R1,pList R2)
{
	if(NULL == R1 || NULL == R2)
	{
		return NULL;
	}
	pList H1 = R1->next;
	pList H2 = R2->next;
	
	//R1对应的链表为空
	if(R1 == H1)
	{
		free(R1);
		return R2;
	}
	
	//R2对应的链表为空
	if(R2 == H2)
	{
		free(R2);
		return R1;
	}
	
	pList tmp = R2->next->next;
	free(R2->next);
	R2->next = R1->next;
	R1->next = tmp;
	return R2;
}
```
## 双向链表
尽管循环链表可以在任意一个结点通过`next`操作访问到任意一个结点，但是其也有弊端，如果想要访问一个结点的前驱，即使能访问到，但是也要经过大量的操作，如果结点数为 `n`，那么就是`O(n)`的时间复杂度
这时候我们可以使用”用空间换时间“的思想，在每个节点上加一个指向前驱的指针域。虽然多开了一些空间用来存前驱的指针域，但是这时候就可以在`O(1)`的时间内访问到前驱
### 结点定义
```c
typedef int DataType;

typedef struct List
{
	struct List* next;
	struct List* prior;
	DataType data;
}List,*pList;
```
