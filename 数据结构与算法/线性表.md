# 什么是线性表？
**线性表**（Linear List）是具有相同数据类型的$n$个数据元素的有限序列
当$n$为0时，线性表称为空表。
若用$L$命名线性表，其数学表示为
$$
L = (a_1,a_2,...,a_i,...,a_n)
$$
其中$a_1$称为该线性表的表头元素，$a_n$称为该线性表的表尾元素
除了表头元素之外，每个元素都有一个直接的前驱
除了表尾元素之外，每个元素都有一个直接的后驱
线性表可分为**顺序表**和**链表**
# 顺序表
顺序表就是顺序存储结构的线性表。
例如C语言中的数组就是一个顺序表
在C语言中，我们可以把数组和顺序表的长度封装成一个结构体，如下：
```c
#define MAXSIZE 128
typedef DataType int

typedef struct node{
	DataType data[MAXSIZE];
	int length;
}SeqList,*PSeqList;
```
顺序表常用的操作函数如下
初始化一个线性表
```c
PSeqList Init_SeqList(void)
{
	PSeqList PL;
	PL = (PSeqList)malloc(sizeof(SeqList));
	if(PL)
	{
		PL->length = 0;
	}
	return PL;
	//如果PL为0代表分配失败
}
```
