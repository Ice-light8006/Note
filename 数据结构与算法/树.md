# 二叉树
二叉树（Binary Tree） 是一种树形结构，满足：
- 每个结点最多有两个子结点
- 子结点有左右之分，分别称为左孩子和右孩子
- 左右子树不能随意交换，即使只有一个孩子，也必须区分是左孩子和右孩子
注意，“度为2的树“和”二叉树“是有区别的，度为2的树要求结点度数的最大值必须为2，

## 遍历顺序
对于二叉树的遍历顺序，分为**先序遍历**，**中序遍历**，**后序遍历**
- 先序遍历：先访问根节点，再遍历左子树，最后遍历右子树
- 中序遍历：先遍历左子树，再遍历根节点，最后遍历右子树
- 后序遍历：先遍历左子树，再遍历右子树，最后访问根节点

## 非递归算法遍历一个树
递归算法比较简单，难点是非递归算法
这个需要利用栈的数据结构
首先，我们约定使用如下的栈的数据结构
```c
#define MAXSIZE 1024
typedef pNode DataType_Stack;
typedef struct Stack
{
	DataType_Stack data[MAXSIZE];
	int top;
}Stack,*pStack;

pStack Stack_Create()
{
	pStack p = (pStack)malloc(sizeof(Stack));
	if(NULL == p)
	{
		return NULL;
	}
	
	p->top = -1;
	
	return p;
}

DataType_Stack Stack_Pop(pStack p)
{
	if(NULL == p)
	{
		return NULL;
	}
	if(p->top == -1)
	{
		return NULL;
	}
	
	DataType_Stack tmp = p->data[p->top];
	p->top--;
	return tmp;
}

void Stack_Push(pStack p,DataType_Stack s)
{
	if(NULL == p)
	{
		return;
	}
	if(p->top >= MAXSIZE-1)
	{
		return;
	}
	
	p->top++;
	p->data[p->top] = s;
}

bool Stack_IsEmpty(pStack p)
{
	if(p == NULL)
	{
		return false;
	}
	
	return p->top == -1;
}
```
递归算法之所以简单，是因为通过递归写法，函数调用栈帮我们记录了当前状态。但是非递归算法就需要自己手动建栈来记录当前的状态。
### 先序遍历的非递归算法
先序遍历的非递归算法是非递归算法遍历二叉树最基本的算法。
大概思路是：从根节点开始，把根节点压栈，同时打印这个结点，然后访问左孩子，打印左孩子，再把左孩子压栈，一直执行下去，直到左孩子为空指针为止，然后就出栈一次，出栈得到的元素访问其右孩子，再把右孩子入栈，然后右孩子就当成一个新的子树，进行同样的先序遍历算法，一直访问左孩子......
#### C语言代码实现
```c
void PreOrder(pNode t)
{
	if(t == NULL)
	{
		return;
	}
	pStack s = Stack_Create();
	if(s == NULL)
	{
		return;
	}
	pNode p = t;
	do
	{
		while(NULL != p)
		{
			printf("%c",p->data);
			Stack_Push(s,p);
			p = p->left;
		}
		if(!Stack_IsEmpty(s))
		{
			p = Stack_Pop(s);
			p = p->right;
		}
	}while(p!=NULL || !Stack_IsEmpty(s));
}
```

### 后序遍历的非递归算法
这个是最难的。最浅显易懂的算法是双栈法
#### C语言代码实现
```c
void PostOrder(pNode t)
{
	if(NULL == t)
	{
		return;
	}
	pStack s1 = Stack_Create();
	pStack s2 = Stack_Create();
	
	if(NULL == s1 || NULL == s2)
	{
		return;
	}
	
	pNode p = t;
	
	Stack_Push(s1,p);
	while(!Stack_IsEmpty(s1))
	{
		pNode tmp = Stack_Pop(s1);
		Stack_Push(s2,tmp);
		if(NULL != tmp->left)
		{
			Stack_Push(s1,tmp->left);
		}
		if(NULL != tmp->right)
		{
			Stack_Push(s1,tmp->right);
		}
	}
	
	while(!Stack_IsEmpty(s2))
	{
		pNode tmp = Stack_Pop(s2);
		printf("%c",tmp->data);
	}
	
	return;
}
```

我们最终想要得到的后序遍历序列为
```
BCA
```
我们的思路是，先把根节点A压入到栈`s1`中
现在两个栈中的元素
```
s1:A
s2:
```
然后，把栈一中的元素弹出，再压入`s2`中，然后把这个元素的左子树和右子树依次压入到栈`s1`中（不为空的情况下）
现在两个栈中的元素
```
s1:BC
s2:A
```
然后再把`s1`中弹出一个元素，这个结点是C，压入`s2`，由于C没有左孩子和右孩子，故没有新的元素压入栈`s1`
所以，现在两个栈中的元素的情况如下
```
s1:B
s2:AC
```
然后再把`s1`中的元素弹出，这个结点是B，压入`s2`，由于B没有左孩子和右孩子，故没有新的元素压入栈`s1`
所以，现在两个栈中的元素的情况如下
```
s1:
s2:ACB
```
这时候发现了吗，`s2`的出栈序列恰好就是后序遍历序列。
实际上，这里单纯利用栈`s1`就可以得到后序遍历序列的逆向序列，`s2`的作用只是把这个后序遍历序列的逆向序列变成后序遍历序列，仅此而已。
**常规先序遍历**（递归或单栈）的顺序是：**根 -> 左 -> 右**
如果我们在双栈法的 `s1` 压栈时故意调整顺序——**先压左子树、再压右子树**（这样栈顶就是右子树，出栈时就会先处理右子树），那么 `s1` 弹出的顺序就会变成：**根 -> 右 -> 左**。这就是后序遍历的逆序。所以就只需要把`s1`的弹出顺序取一个逆序，就得到了**左 -> 右 -> 根**
## 线索二叉树
在先序遍历、中序遍历、后序遍历这三种遍历次序下，某一个结点在每种遍历次序下都对应着一对不同的前驱和后驱。
在特定的遍历次序下，如果我们想要确定这个结点的前驱和后继，通常有下面两种显而易见办法：
- 遍历：按照要求的遍历次序，把二叉树遍历一遍，然后在这一次遍历中发现指定结点的前驱和后驱
- 增设前驱后驱指针：在指定遍历次序下，在每个结点上增设两个指针域，一个指向该结点的前驱，一个指向该结点的后继
但是，第一种方法耗时较长，而第二种方法又会浪费很多内存空间
这时候就可以考虑下面这种方法
对于一个有$n$个结点的二叉树，总度数为$n-1$,每个节点都有两个指针域，那么指针域总数就为$2n$，所以，对于一个有$n$个结点的二叉树，每个结点有两个指针域，所有结点的指针域，为空指针的指针域个数为
$$2n-(n-1)=n+1$$
那么，我们尝试利用这些空指针。
具体的说，对于每个结点，如果其左指针为空，那么就让其指向前驱。如果其右指针为空，那么就让其指向后继。如果左指针不为空则不改变左指针，如果右指针不为空则不改变右指针。
而被改为前驱或者后继的新的指针，称为**线索**。所得到的二叉树称为**线索二叉树**
线索二叉树根据所选择的次序，可分为**先序线索二叉树**，**中序线索二叉树**，**后序线索二叉树**
但是，还有一个问题，每一个结点我们该如何区分这个结点的指针域到底是孩子指针还是线索呢？
我们可以给每个结点再多加两个标志位`ltag`,`rtag`
并规定：
- `ltag`为0，则`left`指向的是该结点的左孩子
- `ltag`为1，则`left`指向的是该结点的前驱
- `rtag`为0，则`right`指向的是该结点的右孩子
- `rtag`为1，则`right`指向的是该结点的后继
这时候线索二叉树表结构描述如下
```c
typedef char DataType;
typedef struct ThreadNode{
	DataType data;
	struct ThreadNode* left;
	struct ThreadNode* right;
	int ltag;
	int rtag;
}ThreadNode,*pThreadNode;
```
### 递归算法完成对一个已知的二叉树的线索化
#### 先序线索化二叉树的递归算法
##### C语言代码实现
```c
void PreThread(pThreadNode t,pThreadNode* pre)
{
    if(NULL == t)
    {
        return;
    }
    if(NULL == t->left)
    {
        t->ltag = 1;
        t->left = *pre;
    }
    if((*pre) && (*pre)->rtag == NULL)
    {
        (*pre)->rtag = 1;
        (*pre)->right = t;
    }
    *(pre) = t;
    //递归左子树之前，先看看是否存在左子树，或者ltag是不是被置位了
    if(NULL != t->left && !t->ltag)
    {
        PreThread(t->left,pre);
    }
    //递归右子树之前，先看看是否存在右子树，或者rtag是不是被置位了
    if(NULL != t->right && !t->rtag)
    {
        PreThread(t->right,pre);
    }
}
```
这个代码的一些注意事项：
- 开头一定要检验传的`t`是不是空指针
- 第二个参数要用二级指针，或者在C++中使用引用传参，或者使用全局变量，或者使用`static`关键字创建一个局部变量。因为如果不这样做，在这一层对`pre`进行了修改，无法将这个修改的值传回到上一层递归
- 另外，先序线索化的时候，`t`的`left`和`right`可能已经发生了修改变成了线索，这时候在递归时就要先判断是否是这种情况：如果左右子树为空，或者左右指针变成了线索。如果是这种情况，就不能再继续递归了。这是与中序的不同
#### 中序线索化二叉树的递归算法
##### C语言代码实现
```c
void InThread(pThreadNode t,pThreadNode* pre)
{
    if(NULL == t)
    {
        return;
    }

    InThread(t->left,pre);

    if(t->left == NULL)
    {
        t->left = *pre;
        t->ltag = 1;
    }

    if((*pre) && (*pre)->right == NULL)
    {
        (*pre)->right = t;
        (*pre)->rtag = 1;
    }

    (*pre) = t;

    InThread(t->right,pre);
}
```
这里与先序线索化二叉树的递归算法不同的是，这里在执行
```c
InThread(t->left,pre);
```
时，不需要判断当前结点的左指针是否修改了
#### 后序线索化二叉树的递归算法
##### C语言代码实现
```c
void PostThread(pThreadNode t,pThreadNode* pre)
{
    if(NULL == t)
    {
        return;
    }

    PostThread(t->left,pre);
    PostThread(t->right,pre);

    if(t->left == NULL)
    {
        t->left = *pre;
        t->ltag = 1;
    }

    if((*pre) && (*pre)->right == NULL)
    {
        (*pre)->right = t;
        (*pre)->rtag = 1;
    }

    *pre = t;
}
```
### 非递归算法对一个已知的二叉树的线索化
递归算法转换成非递归算法就需要用到栈的数据结构。这里我们还是规定利用上面二叉树的遍历的部分所使用的栈
#### 先序线索化二叉树的非递归算法
在先序遍历二叉树非递归算法的基础上，把访问节点的部分改成线索化的逻辑（如果左右指针域为空，则将其改为线索）即可
##### C语言代码实现
```c
void PreThread(pThreadNode t)
{
    if (NULL == t)
    {
        return;
    }

    pThreadNode pre = NULL;

    pStack s = Stack_Create();

    pThreadNode p = t;

    while (NULL != p || !Stack_IsEmpty(s))
    {
        while (NULL != p)
        {
            Stack_Push(s, p);
            if(p!=NULL && p->left == NULL)
            {
                p->left = pre;
                p->ltag = 1;
            }
            if(pre && pre->right == NULL)
            {
                pre->right = p;
                pre->rtag = 1;
            }
            pre = p;
            if(p->ltag == 0)
            {
                p = p->left;
            }
            else
            {
                p = NULL;
            }
        }

        if (!Stack_IsEmpty(s))
        {
            p = Stack_Pop(s, p);
            if(p->rtag == 0)
            {
                p = p->right;
            }
            else
            {
                p = NULL;
            }
        }
    }
}
```
##### 注意事项
首先，还是先序线索化带来的问题，就是先序是要求先访问根节点再访问左右子树，那么这里，在执行完线索化的代码之后，不能直接执行
```c
p = p->left;
```
因为先进行线索化操作，`p->left`有可能已经被修改成前驱了
所以，要先判断`p->ltag`有没有被置位，如果没有被置位，则把`p`修改为`p`的左孩子，如果被置位了，则说明当前的左指针不是真正的左孩子，而是前驱，这个时候我们就把它直接置为空指针，跳出循环，进入通过栈对右指针的判断
对于右指针也是同理。
#### 中序线索化二叉树的非递归算法
在中序遍历二叉树非递归算法的基础上，把访问节点的部分改成线索化的逻辑（如果左右指针域为空，则将其改为线索）即可
##### C语言代码实现
```c
void InThread(pThreadNode t)
{
    if (NULL == t)
    {
        return;
    }

    pThreadNode pre = NULL;

    pStack s = Stack_Create();

    pThreadNode p = t;

    while (NULL != p || !Stack_IsEmpty(s))
    {
        while (NULL != p)
        {
            Stack_Push(s, p);
            p = p->left;
        }

        if (!Stack_IsEmpty(s))
        {
            p = Stack_Pop(s, p);
            if(p->left == NULL)
            {
                p->left = pre;
                p->ltag = 1;
            }
            if(pre && pre->right == NULL)
            {
                pre->right = p;
                pre->rtag = 1;
            }
            pre = p;
            if(p->rtag == 0)
            {
                p = p->right;
            }
            else
            {
                p = NULL;
            }
        }
    }
}
```
##### 注意事项
相对于先序线索化二叉树，这里在处理左子树时，就不需要判断左指针是否是真正的左孩子，因为中序遍历的顺序是在处理过左子树之后再访问根节点。而右指针则还是需要判断是否是真正的右孩子。
#### 后序线索化二叉树的非递归算法
后序是最难的。首先肯定是在后序遍历二叉树的非递归算法的基础上，把访问结点的逻辑改成线索化的逻辑。
双栈法遍历二叉树的非递归算法是最直观的，我们这里在双栈法的基础上实现
##### C语言代码实现
```c
void PostThread(pThreadNode t)
{
    if(NULL == t)
    {
        return;
    }

    pThreadNode p = t;
    pThreadNode pre = NULL;

    pStack s1 = Stack_Create();
    pStack s2 = Stack_Create();

    Stack_Push(s1,p);

    while(!Stack_IsEmpty(s1))
    {
        p = Stack_Pop(s1);
        if(p->left != NULL)
        {
            Stack_push(s1,p->left);
        }
        if(p->right != NULL)
        {
            Stack_Push(s1,p->right);
        }
        Stack_Push(s2,p);
    }

    while(!Stack_IsEmpty(s2))
    {
        p = Stack_Pop(s2);
        if(p->left == NULL)
        {
            p->left = pre;
            p->ltag = 1;
        }
        if(pre && pre->right == NULL)
        {
            pre->right = p;
            pre->rtag = 1;
        }
        pre = p;
    }
}
```
##### 注意事项
由于是后序遍历顺序的线索化操作，这里在最后进行线索化操作时，不需要判断左指针和右指针是否是真正的左孩子和右孩子。
另外，在`s1`出栈根节点，然后在入栈这个根节点的左孩子和右孩子时，不要忘记考虑左指针和右指针是否为空，如果为空则不能进行入栈。因为一定会有某些结点没有左孩子或者某些结点没有右孩子。
另外，一定要先将左孩子压入栈`s1`，再将右孩子压入`s1`。至于为什么，参考上方对于后序非递归算法遍历二叉树的部分
