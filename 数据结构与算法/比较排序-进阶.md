# 快速排序（Quick Sort）
```c
void Quick_Sort(int* a,int l,int r)
{
    if(a == NULL)
    {
        return;
    }

    if(l >= r)
    {
        return;
    }

    int i,j,pivot;
    pivot = a[l];

    i = l;
    j = r;

    while(i<j)
    {
        while(i<j && a[j]>=pivot)
        {
            j--;
        }
        a[i] = a[j];
        while(i<j && a[i]<=pivot)
        {
            i++;
        }
        a[j] = a[i];
    }
    a[i] = pivot;
    Quick_Sort(a,l,i-1);
    Quick_Sort(a,i+1,r);
}

```
## 注意事项
### 1.内层循环与中枢值的判断要用小于等于
假设用小于（大于）而不是小于（大于）等于，代码如下
```c
void Quick_Sort(int* a,int l,int r)
{
    if(a == NULL)
    {
        return;
    }

    if(l >= r)
    {
        return;
    }

    int i,j,pivot;
    pivot = a[l];

    i = l;
    j = r;

    while(i<j)
    {
        while(i<j && a[j]>pivot)
        {
            j--;
        }
        a[i] = a[j];
        while(i<j && a[i]<pivot)
        {
            i++;
        }
        a[j] = a[i];
    }
    a[i] = pivot;
    Quick_Sort(a,l,i-1);
    Quick_Sort(a,i+1,r);
}
```
假如我们执行
```c
int a[] = {5,5};
quickSort(a,0,1);
```
那么，初始状态
```c
i = 0;
j = 1;
pivot = 5;
```
进入循环，内层的第一个循环为
```c
while(i<j && a[j]>pivot)
```
条件不成立，不会执行
然后执行
```c
a[i] = a[j];
```
由于数组全是5，所以不会有任何变化
同理，下面也是
到最后各个变量的值如下
```c
i = 0;
j = 1;
pivot = 5;
```
还是与初始值相同。
外层循环的条件成立，接着执行。
结果就是死循环。
所以不能用大于（小于），应该用大于（小于）等于
### 2.递归终止条件必须是`l>=r`，而不是`l==r`
这是因为递归时可能会出现空区间
假如基准值最终放入最左边，那么就会出现`left-1`小于`i`的情况。
就不能用`l==r`了而是要用`l>=r`
## 时间复杂度

| 情况   |        时间复杂度 |
| ---- | -----------: |
| 最好情况 | $O(n\log n)$ |
| 平均情况 | $O(n\log n)$ |
| 最坏情况 |     $O(n^2)$ |
