# 快速排序（Quick Sort）
```c
void quickSort(int left,int right,int* a)
{
	if(left>=right)return;
	int start = left;
	int end = right;
	int pivot = a[left];
	while(left<right)
	{
		while(a[right]>=pivot && left<right)
		{
			right--;
		}
		a[left] = a[right];
		while(a[left]<=pivot && left<right)
		{
			left++;
		}
		a[right] = a[left];
	}
	a[left] = pivot;
	quickSort(start,left-1,a);
	quickSort(left+1,end,a);
	return;
}
```
## 注意事项
### 1.内层循环与中枢值的判断要用小于等于
假设用小于（大于）而不是小于（大于）等于，代码如下
```c
void quickSort(int left,int right,int* a)
{
	if(left>=right)return;
	int start = left;
	int end = right;
	int pivot = a[left];
	while(left<right)
	{
		while(left<right && a[right]>pivot)
		{
			right--;
		}
		a[left] = a[right];
		while(left<right && a[left]<pivot)
		{
			left++;
		}
		a[right] = a[left];
	}
	a[left] = pivot;
	quickSort(start,left-1,a);
	quickSort(left+1,end,a);
	return;
}
```
假如我们执行
```c
int a[] = {5,5};
quickSort(0,1,a);
```
那么，初始状态
```c
left = 0;
right = 1;
povit = 5;
```
进入循环，内层的第一个循环为
```c
while(a[right]>pivot && left<right)
```
条件不成立，不会执行
然后执行
```c
a[left] = a[right];
```
由于数组全是5，所以不会有任何变化
同理，下面也是
到最后各个变量的值如下
```c
left = 0;
right = 1;
povit = 5;
```
还是与初始值相同。
外层循环的条件成立，接着执行。
结果就是死循环。
所以不能用大于（小于），应该用大于（小于）等于
### 2.递归终止条件必须是`left>=right`，而不是`left==right`
这是因为递归时可能会出现空区间
假如基准值最终放入最左边，那么就会出现`left-1`小于`start`的情况。
就不能用`left==right`了而是要用`left>=right`
## 时间复杂度

| 情况   |        时间复杂度 |
| ---- | -----------: |
| 最好情况 | $O(n\log n)$ |
| 平均情况 | $O(n\log n)$ |
| 最坏情况 |     $O(n^2)$ |
