先解释一下与查找有关的基本概念：
- 查找表：同一类型的数据元素（记录）组成的集合称为查找表。查找表就是待查文件
- 关键字：数据记录中某个可以标识一个记录的数据项的值称为关键字。若关键字可以唯一的标识一个记录，则该关键字称为主关键字，反之称为次关键字
- 查找：查找就是在查找表中找到关键字等于给定值的某个记录。
- 最大查找长度：对关键字的最大比较次数
- 平均查找长度：对关键字的平均比较次数，也叫ASL（Average Search Length）
例如：一个驾驶证件数据库，里面存储了很多个驾驶证的信息。驾驶证里有姓名和驾驶证号。在这里给定一个姓名，执行查找操作，可以在数据库里找到多个记录。姓名就是次关键字。给定一个驾驶证件号，执行查找操作，可以在数据库里找到唯一的一个记录。驾驶证件号就是主关键字。
# 线性表查找
对于线性表，我们这里采用顺序存储结构的线性表，即顺序表。数据结构定义如下
```c
#define MAXSIZE 128

typedef int KeyType;

typedef struct {
    KeyType key;
}DataType;

typedef struct {
    DataType r[MAXSIZE];
    int len;
}Sqlist;
```
这里这个数组`r`是record（记录）的缩写
Sqlist是Sequential List（顺序表）的缩写
## 顺序查找
顺序查找就是给定一个关键字和一个查找表，逐个比较查找表中每个记录的关键字与给定的关键字，如果能找到给定关键字，则查找成功。否则查找失败
下面这个算法在查找成功时返回对应记录的索引，在查找失败时返回-1
```c
#include <stdio.h>

#define MAXSIZE 128

typedef int KeyType;

typedef struct {
    KeyType key;
}DataType;

typedef struct {
    DataType r[MAXSIZE];
    int len;
}Sqlist;

int SeqSearch(Sqlist s,KeyType k)
{
    int res  = -1;
    for(int i = 0;i<s.len;i++)
    {
        if(s.r[i].key == k)
        {
            res = i;
            break;
        }
    }
    return res;
}

int main()
{
    Sqlist s = {{2,4,1,5,7},5};
    int pos = SeqSearch(s,4);
    printf("%d\n",pos);
    pos = SeqSearch(s,10);
    printf("%d\n",pos);
    return 0;
}
```
输出结果为
```Output
1
-1
```
但是这个算法每一次操作都要先比较`i`与`s.len`，然后再比较`s.r[i].key`与`k`。需要比较两次。
可以增加一个前哨站。算法如下
```c
int SeqSearch_gai(Sqlist s,KeyType k)
{
    int n = s.len;
    DataType t = {k};
    s.r[n] = t;
    int i = 0;
    while(s.r[i].key!=k)
    {
        i++;
    }

    if(i == n)
    {
        return -1;
    }
    else
    {
        return i;
    }
}
```
顺序查找的时间复杂度为$O(logn)$
## 二分查找（折半查找）
对于一个有序的数组，可以使用二分查找。因为有序带来了更多的信息，使得查找需要的比较次数更少。二分查找的复杂度仅为$O(logn)$
下面是经典的二分查找算法
```c
int BinarySearch(Sqlist s,KeyType k)
{
    int i,j,mid;
    i = 0;
    j = s.len-1;
    while(i<=j)
    {
        mid = (i+j)/2;
        if(s.r[mid].key==k)
        {
            return mid;
        }
        if(s.r[mid].key > k)
        {
            j = mid - 1;
        }
        else
        {
            i = mid + 1;
        }
    }
    return -1;
}
```
对于这个算法有几个非常重要的性质：
首先明确：循环结束等价于查找失败。因为如果查找成功会直接返回
性质1：如果查找失败，在循环结束后一定有$i = j + 1$
证明：
首先，一定有
$$i<=mid<=j$$
在进入循环时，如果执行`j = mid - 1`，新的`j`至少也是`i-1`，即：
$$j>=i-1$$
在进入循环时，如果执行`i = mid + 1`，新的`i`至多是`j+1`，即：
$$i<=j+1$$
所以在进入循环并执行完循环体之后，永远有
$$i<=j+1$$
如果想要循环结束，又必须要
$$i>j$$
即
$$i >= j + 1$$
所以，当循环结束时一定有
$$ i = j + 1 $$
性质2：如果查找失败，在循环结束之后，`i`一定指向关键字大于`k`的关键字最小的那个记录，`j`一定指向关键字小于`k`的关键字最大的那个记录
证明：可以利用**循环不变量来证明**
首先证明一个引理A：`i`的左边的关键字一定全都小于`k`，`j`的右边的关键字一定全都大于`k`
首先，在初始化时，`i`为第0个元素，`j`为最后一个元素，`i`的左边和`j`的右边没有元素。所以引理A成立。
假设当前引理A成立，在进入循环之后，如果`r[mid]`小于`k`，则`mid`指向的元素和`mid`左边的元素全部小于`k`，即`mid+1`左边的元素全部小于`k`，所以令`i = mid + 1`之后，`i`左边的元素依然全部小于`k`，依然满足引理A。如果`r[mid]`大于`k`，则`mid`指向的元素和`mid`右边的元素全部大于`k`，即`mid-1`右边的元素全部大于`k`。所以令`j = mid - 1`之后，`j`右边的元素依然全部大于`k`，依然满足引理A。
我们这里论证了初始化时A成立，且在A成立的情况下执行一次循环之后A依然成立。所以由数学归纳法，得到引理A成立。
在循环结束之后，由于$i = j + 1$，且`i`左边的关键字全部比`k`小，`j`右边的关键字全部比`i`大
所以，`j`对应的关键字比`k`小，`i`对应的关键字比`k`大。又$i = j + 1$，`i`就在`j`后面。所以一定有：
>`i`一定指向关键字大于`k`的关键字最小的那个记录，`j`一定指向关键字小于`k`的关键字最大的那个记录

现在延伸一下，我们尝试实现：对于一个查找表，查找比给定关键字大的所有关键字里最小的那个记录。这个操作在数据结构与算法中通常称为`lower_bound`
