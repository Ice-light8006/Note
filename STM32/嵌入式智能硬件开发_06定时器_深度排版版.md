## 1 SysTick：建立系统时间基准

> **内容衔接**：程序首先需要一个稳定的“时间刻度”。SysTick位于Cortex-M内核中，最适合先讲清楚1 ms节拍、定时中断和延时函数，为后续外设定时器打基础。

### 1.1 SysTick是什么

- **SysTick是ARM Cortex-M内核集成的24位递减计数器**

- **专为操作系统或实时任务提供精确的时间基准**

### 1.2 SysTick为什么适合作为系统节拍

- **独立性 ：不依赖特定外设模块，属于CPU内核资源，所有Cortex-M系列芯片均支持**

- **固定时钟源 ：可选择内核时钟（如HCLK）或 HCLK的1/8（具体取决于控制寄存器的设置）**

- **中断驱动 ：计数器归零时触发中断，适用于周期性任务调度**

  - **SysTick定时器能产生中断，CM3为它专门开出一个异常类型**

- **实现1s翻转LED灯**

  - **中断方式**

    - **初始化:SysTick_Init**

      - **配置时钟源  1=AHB(72MHz) 0=AHB/8：SysTick->CTRL |= SysTick_CTRL_CLKSOURCE;**

      - **使能中断： SysTick->CTRL |= SysTick_CTRL_TICKINT;**

      - **定时器 1ms 产生一次中断：SysTick->LOAD = 72000 - 1;**

      - **使能定时器：SysTick->CTRL |= SysTick_CTRL_ENABLE;**

    - **中断处理:SysTick_Handler**

  - **轮询方式**

    - **实现延时函数**

      ```c
      #include "delay.h" // Device header
      
      void Delay_us(uint16_t us)
      {
          /* 设计定时器重装值 */
          SysTick->LOAD = 72 * us;
          /* 清除当前计数值 */
          SysTick->VAL = 0;
          /* 设置内部时钟源（2位->1）,不需要中断（1位->0），并启动定时器(0位->1) */
          SysTick->CTRL = 0x5;
          /* 等待计数到0， 如果计数到0则16位会置为1 */
          while (!(SysTick->CTRL & SysTick_CTRL_COUNTFLAG));
          /* 关闭定时器 */
          SysTick->CTRL &= ~SysTick_CTRL_ENABLE;
      }
      
      void Delay_ms(uint16_t ms)
      {
          while (ms--)
          {
              Delay_us(1000);
          }
      }
      
      void Delay_s(uint16_t s)
      {
          while (s--)
          {
              Delay_ms(1000);
          }
      }
      ```

    ```c
    void HAL_IncTick(void)
    {
        uwTick += uwTickFreq;
        if (uwTick % 1000 == 0)
        {  // 产生了1s的计时
            // 翻转LED灯
            HAL_GPIO_TogglePin(GPIOA, GPIO_PIN_0);
        }
    }
    ```

- **阻塞式延时：HAL_Delay()**

  - **阻塞当前代码执行，等待指定毫秒数（ms）**

  - **实现代码**

    ```c
    __weak void HAL_Delay(uint32_t Delay) {
        uint32_t tickstart = HAL_GetTick();  // 获取当前时间戳
        uint32_t wait = Delay;
        // 处理可能的计数器溢出（uwTick为32位，约49天溢出一次）
        if (wait < HAL_MAX_DELAY) {
            wait += (uint32_t)(uwTickFreq);  // uwTickFreq默认为1（1ms）
        }
        // 阻塞等待，直到时间差达到目标值
        while ((HAL_GetTick() - tickstart) < wait) {
            // 空循环或调用空闲任务（如启用低功耗）
        }
    }
    ```

## 2 基本定时器：从计数到周期中断

> **内容衔接**：SysTick解决了系统节拍问题，但只有一个且功能固定。接下来把时间基准交给独立外设TIM6/TIM7，学习所有STM32定时器共有的PSC、CNT、ARR和更新事件。

### 2.1 为什么还需要基本定时器

- **2个基本定时器只能向上计数，由于没有外部IO，只能计时，不能对外部脉冲进行计数**

  - **主模式**

  - **触发DAC**

- **计算定时时间**

  - **计数器的时钟频率是多少**

    - **内部时钟频率/预分频系数+1**

    - **内部时钟频率72M，预分频系数7199，则计数器时钟频率为10000**

  - **计数器的周期是多少？ 也就是累加一次需要的时间**

    - **预分频系数+1/内部时钟频频率**

    - **1/10000s=100us**

  - **计数器累加多少次产生一次更新事件**

    - **自动重装载值+1**

    - **假设自动重装载值3。则加到4时溢出到0**

  - **定时时间：（预分频系数+1/内部时钟频频率）∗(自动重装载值+1)**

    - **假设定时1s，内部时钟频率72MHz：**

      - **令预分频系数=7200-1,计数器频率=10000**

      - **则自动重装载值=10000-1**

      - **设置中断优先级分组：NVIC_SetPriorityGrouping(3);**

  - **HAL库相关函数**

    #### **1. 定时器初始化函数**

    ##### **函数原型**

    ```c
    HAL_StatusTypeDef HAL_TIM_Base_Init(TIM_HandleTypeDef *htim);
    ```

    - **形参**：

    - `*htim`：指向`TIM_HandleTypeDef`结构体的指针，包含定时器配置参数。

    ```c
    typedef struct {
    
        TIM_TypeDef          *Instance;  // 定时器实例（如TIM6）
    
        TIM_Base_InitTypeDef Init;  // 定时器初始化结构体
    
        HAL_TIM_ActiveChannel  Channel;  // 通道（基本定时器未使用）
    
        DMA_HandleTypeDef      *hdma[7];  // DMA句柄数组（基本定时器通常未使用）
    
        HAL_LockTypeDef        Lock;  // 锁机制
    
        __IO HAL_TIM_StateTypeDef State;  // 定时器状态
    
    } TIM_HandleTypeDef;
    
    typedef struct {
    
        uint32_t Prescaler;  // 预分频系数（0~65535）
    
        uint32_t CounterMode;  // 计数模式（基本定时器仅支持TIM_COUNTERMODE_UP）
    
        uint32_t Period;  // 自动重载值（0~65535）
    
        uint32_t ClockDivision;  // 时钟分频（基本定时器未使用）
    
        uint32_t RepetitionCounter;  // 重复计数器（高级定时器专用，基本定时器未使用）
    
        uint32_t AutoReloadPreload;  // 自动重载预装载（TIM_AUTORELOAD_PRELOAD_ENABLE/DISABLE）
    
    } TIM_Base_InitTypeDef;
    ```

    - **功能**：

    初始化定时器的基本参数（预分频系数、计数模式、自动重载值等）。

    - **返回值**：

    - `HAL_OK`：初始化成功。

    - `HAL_ERROR`：参数错误或硬件错误。

    ---

    #### **2. 定时器启动函数**

    ##### **2.1 启动定时器（无中断/DMA）**

    ```c
    HAL_StatusTypeDef HAL_TIM_Base_Start(TIM_HandleTypeDef *htim);
    ```

    - **形参**：

    - `*htim`：定时器句柄。

    - **功能**：

    启动定时器计数器，但不启用中断或DMA。

    - **返回值**：

    - `HAL_OK`：启动成功。

    - `HAL_ERROR`：定时器未初始化或硬件错误。

    ##### **2.2 启动定时器并启用中断**

    ```c
    HAL_StatusTypeDef HAL_TIM_Base_Start_IT(TIM_HandleTypeDef *htim);
    ```

    - **形参**：

    - `*htim`：定时器句柄。

    - **功能**：

    启动定时器计数器，并启用更新中断（需配置NVIC）。

    - **返回值**：

    - 同`HAL_TIM_Base_Start()`。

    ##### **2.3 启动定时器并启用DMA**

    ```c
    HAL_StatusTypeDef HAL_TIM_Base_Start_DMA(TIM_HandleTypeDef *htim, uint32_t *pData, uint16_t Length);
    ```

    - **形参**：

    - `*htim`：定时器句柄。

    - `*pData`：DMA传输目标缓冲区地址。

    - `Length`：DMA传输数据长度。

    - **功能**：

    启动定时器计数器，并通过DMA传输更新事件触发的数据。

    - **返回值**：

    - `HAL_OK`：启动成功。

    - `HAL_ERROR`：DMA配置错误或硬件故障。

    ---

    #### **3. 定时器停止函数**

    ##### **3.1 停止定时器**

    ```c
    HAL_StatusTypeDef HAL_TIM_Base_Stop(TIM_HandleTypeDef *htim);
    ```

    - **形参**：

    - `*htim`：定时器句柄。

    - **功能**：

    停止定时器计数器，关闭中断/DMA（如果启用）。

    - **返回值**：

    - 同`HAL_TIM_Base_Start()`。

    ##### **3.2 停止定时器中断**

    ```c
    HAL_StatusTypeDef HAL_TIM_Base_Stop_IT(TIM_HandleTypeDef *htim);
    ```

    - **形参**：

    - `*htim`：定时器句柄。

    - **功能**：

    停止定时器计数器，并禁用更新中断。

    ##### **3.3 停止定时器DMA**

    ```c
    HAL_StatusTypeDef HAL_TIM_Base_Stop_DMA(TIM_HandleTypeDef *htim);
    ```

    - **形参**：

    - `*htim`：定时器句柄。

    - **功能**：

    停止定时器计数器，并禁用DMA传输。

    ---

    #### **4. 中断处理函数**

    ##### **4.1 中断请求统一处理**


    - **形参**：

    ### **函数使用示例**

    #### **场景**：配置TIM6每1秒触发中断翻转LED。

    ```c
    TIM_HandleTypeDef htim6;
    
    void MX_TIM6_Init(void) {
    
        htim6.Instance = TIM6;
      htim6.Init.Prescaler = 7199;  // 分频至10kHz

      }
  
  }
    ```

## 3 通用定时器：从定时扩展到信号输入与输出

> **内容衔接**：基本定时器只能在芯片内部计时。通用定时器增加捕获/比较通道后，既能向外输出PWM，也能把外部边沿的到达时刻记录下来。

### 3.1 通用定时器增加了哪些能力

- **支持的定时器 ：TIM2、TIM3、TIM4、TIM5（TIM2/TIM5为32位，TIM3/TIM4为16位）**

- **功能**

  - **基础定时（向上/向下/中央对齐计数）**

  - **PWM信号生成（边沿对齐、中心对齐模式）**

  - **输入捕获（测量脉冲宽度或频率）**

  - **输出比较（生成特定时序的脉冲）**

  - **编码器接口（读取正交编码器信号）**

  - **PWM**

    - **脉冲宽度调制 Pulse-width modulation**

    - **条件：被控制的电路必须要有一定的“惯性”**

      - **比如LED即使断电了也不会立即熄灭，电机断电了也不会立即停止**

    - **作用**

      - **是利用微处理器的数字输出来对模拟电路进行控制的一种非常有效的技术**

      - **通过更改占空比达到对外输出的有效电压的值。**

      - **PWM通常用于控制电机、LED亮度调节等应用**

  - **测量PWM周期原理**

    - **时钟**

      - **对计数器时钟72分频（主要是方便计算），则计数器时钟频率为1MHz，计数器累加一次的时间为 1us**

    - **测量的信号周期小于65535us即频率大于16Hz**

      - **保证在一个周期内，计数器不会溢出。**

      - **当第1个上升沿到来时，重置计数器的值（让计数器从0开始计数）**

      - **当第2个上升沿到来时,计数器的值会自动copy到捕获寄存器，读出捕获寄存器的值，这个值就表示信号的周期**

    - **测量频率超过1MHz（超过计数器的时钟频率）**

      - **第2个上升沿到了之后，计数器还没有完成一次累加，则无法测量**

      - **可以考虑测试第1个上升沿和第n个上升沿的的间隔。这种一般用来测量高频信号，频率超过了计数器的时钟频率。**

        ```c
        void TIM4_Init(void)
        {
            /* 1. 开启时钟 */
            /* 1.1 TIM4的时钟 */
            RCC->APB1ENR |= RCC_APB1ENR_TIM4EN;
            /* 1.2 把引脚(PB6) 对应的端口开启时钟 */
            RCC->APB2ENR |= RCC_APB2ENR_IOPBEN;
            /* 2. PB6设置为输入: 浮空输入 CNF=01 MODE=00 */
            GPIOB->CRL &= ~(GPIO_CRL_CNF6_1 | GPIO_CRL_MODE6);
            GPIOB->CRL |= GPIO_CRL_CNF6_0;
            /* 3. 配置定时器的时基部分 */
            /* 3.1 预分频系数配置 分频后计数器的时钟时1MHz 周期:1us */
            TIM4->PSC = 72 - 1;
            /* 3.2 自动重装载寄存器的值: 设置最大,尽量避免溢出 */
            TIM4->ARR = 65535;
            /* 3.3 计数方向: 向上计数 */
            TIM4->CR1 &= ~TIM_CR1_DIR;
            /* 4. 输入捕获部分 */
            /* 4.1 TI1的选择: 把CH1直接连接到TI1 */
            TIM4->CR2 &= ~TIM_CR2_TI1S;
            /* 4.2 信号的输入滤波器: 不滤波  CCMR1_IC1F=0000 */
            TIM4->CCMR1 &= ~TIM_CCMR1_IC1F;
            /* 4.3 配置边缘检测器: 上升沿 CCER_CC1P=0  1下降沿捕获 */
            TIM4->CCER &= ~TIM_CCER_CC1P;
            /* 4.4 通道1配置为输入,并把信号映射到IC1  CC1S=01 */
            TIM4->CCMR1 &= ~TIM_CCMR1_CC1S_1;
            TIM4->CCMR1 |= TIM_CCMR1_CC1S_0;
            /* 4.5 对信号做分频(信号频率比较高的时候) CCMR1_IC1PSC=00不分频 01=2分频 10=4分频 11=8分频 */
            TIM4->CCMR1 &= ~TIM_CCMR1_IC1PSC;
            /* 4.6 通道1输入捕获使能 CCER_CC1E=1 */
            TIM4->CCER |= TIM_CCER_CC1E;
            /* 4.7 开启捕获中断 DIER_CC1IE=1 */
            TIM4->DIER |= TIM_DIER_CC1IE;
            /* 5. NVIC的配置 */
            /* 5.1 优先级组 */
            NVIC_SetPriorityGrouping(3);
            /* 5.2 优先级 */
            NVIC_SetPriority(TIM4_IRQn, 3);
            /* 5.3 使能中断 */
            NVIC_EnableIRQ(TIM4_IRQn);
        }
        ```

        ```c
        /* 记录上升沿的个数 */
        uint8_t raiseEdgeCount = 0;
        /* 存储信号的周期 */
        uint16_t t = 0;
        /* TIM4中断服务函数 */

        void TIM4_IRQHandler(void)
        {
            /* 判断是否是TIM4的通道1发生了捕获中断 */
            if (TIM4->SR & TIM_SR_CC1IF)
            {
                /* 中断标记位清除 */
                TIM4->SR &= ~TIM_SR_CC1IF;
                /* 上升沿个数 */
                raiseEdgeCount++;
                /* 如果是第1个上升沿,则清零计数器,让计数器从0开始计数 */
                if (raiseEdgeCount == 1)
                {
                    TIM4->CNT = 0; /* 计数器清零 */
                }
                else if (raiseEdgeCount == 2)
                {
                    /* 读取捕获寄存器的值,就是周期 单位是us */
                    t = TIM4->CCR1;
                    /* 上升沿的计数从0重新计数 */
                    raiseEdgeCount = 0;
                }
            }
        }
        ```

    ```c
    volatile uint32_t rise1 = 0, fall = 0, rise2 = 0;
    volatile uint32_t period = 0, high_time = 0, duty = 0;
    
    void TIM4_IRQHandler(void) {
        if (TIM4->SR & TIM_SR_CC1IF) {  // 捕获中断触发
            uint32_t capture = TIM4->CCR1;  // 读取捕获值
            if ((TIM4->CCER & TIM_CCER_CC1P) == 0) {
                // 当前为上升沿触发模式
                if (rise1 == 0) {
                    rise1 = capture;
                    // 切换为下降沿触发
                    TIM4->CCER |= TIM_CCER_CC1P;
                } else {
                    // 第二次上升沿：计算周期
                    rise2 = capture;
                    period = (rise2 - rise1);  // 周期（μs）
                    high_time = fall - rise1;  // 高电平时间（μs）
                    duty = (high_time * 100) / period;  // 占空比（%）
                    rise1 = rise2;  // 重置为下次周期测量
                }
            } else {
                // 当前为下降沿触发模式
                fall = capture;
                // 切换回上升沿触发
                TIM4->CCER &= ~TIM_CCER_CC1P;
            }
            TIM4->SR &= ~TIM_SR_CC1IF;  // 清除中断标志
        }
    }
    ```

        ```c
        void TIM4_Init(void)
        {
            /* 1. 开启时钟 */
            /* 1.1 TIM4的时钟 */
            RCC->APB1ENR |= RCC_APB1ENR_TIM4EN;
            /* 1.2 把引脚(PB6) 对应的端口开启时钟 */
            RCC->APB2ENR |= RCC_APB2ENR_IOPBEN;
            /* 2. PB6设置为输入: 浮空输入 CNF=01 MODE=00 */
            GPIOB->CRL &= ~(GPIO_CRL_CNF6_1 | GPIO_CRL_MODE6);
            GPIOB->CRL |= GPIO_CRL_CNF6_0;
            /* 3. 配置定时器的时基部分 */
            /* 3.1 预分频系数配置 分频后计数器的时钟时1MHz 周期:1us */
            TIM4->PSC = 72 - 1;
            /* 3.2 自动重装载寄存器的值: 设置最大,尽量避免溢出 */
            TIM4->ARR = 65535;
            /* 3.3 计数方向: 向上计数 */
            TIM4->CR1 &= ~TIM_CR1_DIR;
            /* 4. 输入捕获部分 */
            /* 4.1 输入信号不滤波 */
            TIM4->CCMR1 &= ~TIM_CCMR1_IC1F;
            /* 4.2 配置边缘检测: 去IC1上升沿 去IC2的下降沿 */
            TIM4->CCER &= ~TIM_CCER_CC1P;
            TIM4->CCER |= TIM_CCER_CC2P;
            /* 4.3 把 IC1映射到TI1 CCMR1_CC1S=01 上升沿 */
            TIM4->CCMR1 &= ~TIM_CCMR1_CC1S_1;
            TIM4->CCMR1 |= TIM_CCMR1_CC1S_0;
            /* 4.4 把 IC2映射到TI1 CCMR1_CC2S=10 下降沿 */
            TIM4->CCMR1 |= TIM_CCMR1_CC2S_1;
            TIM4->CCMR1 &= ~TIM_CCMR1_CC2S_0;
            /* 4.5 IC1和IC2的预分频 都不分频 */
            TIM4->CCMR1 &= ~TIM_CCMR1_IC1PSC;
            TIM4->CCMR1 &= ~TIM_CCMR1_IC2PSC;
            /* 4.6 配置TRGI信号:  TI1FP1   SMCR_TS=101 */
            TIM4->SMCR |= (TIM_SMCR_TS_2 | TIM_SMCR_TS_0);
            TIM4->SMCR &= ~TIM_SMCR_TS_1;
            /* 4.7 配置从模式: 为复位模式 SMCR_SMS=100 */
            TIM4->SMCR |= TIM_SMCR_SMS_2;
            TIM4->SMCR &= ~(TIM_SMCR_SMS_1 | TIM_SMCR_SMS_0);
            /* 4.8 使能通道1捕获和通道2捕获 */
            TIM4->CCER |= TIM_CCER_CC1E;
            TIM4->CCER |= TIM_CCER_CC2E;
        }
        ```

      double TIM4_GetPWMCycle(void)

      ```c
          return (1 + __HAL_TIM_GetCompare(&htim4, TIM_CHANNEL_2)) * 1.0 / (1 + __HAL_TIM_GetCompare(&htim4, TIM_CHANNEL_1));
      }
      ```

## 4 高级定时器：面向功率驱动与复杂控制

> **内容衔接**：通用定时器已经能产生和测量PWM，但直接驱动电机或功率电路还需要互补输出、死区、刹车与重复计数。高级定时器正是在通用定时器基础上的安全增强。

### 4.1 高级定时器为何面向电机控制

- **高级定时器（如TIM1、TIM8）专为复杂应用设计，支持电机控制、电源转换等场景**

### 4.4 利用重复计数器输出有限周期PWM

**讲解路径：** 先确定PWM频率 → 设置重复次数 → 使能高级定时器主输出 → 更新中断中停止输出。

- **实现思路**

  - **使用高级定时器的重复计数器，当计数器溢出时，在溢出中断中停止定时器工作。重复计数器寄存器的值设置为4，即可输出5个周期的PWM波，发光二极管会闪烁5次。**

  - **2Hz的周期是500ms，需要将72MHz的时钟预分配7200，得到10KHz, 每计数一次需要0.1ms，那么自动预装载器的值就是5000-1才能得到2Hz的pwm脉冲**

    - **初始化定时器：TIM1_Init**

      ```c
      void TIM1_Init(void)
      {
          /* 1. 开启时钟 */
          /* 1.1 TIM1的时钟 */
          RCC->APB2ENR |= RCC_APB2ENR_TIM1EN;
          /* 1.2 GPIO的时钟 */
          RCC->APB2ENR |= RCC_APB2ENR_IOPAEN;
          /* 2. 给PA8配置复用推挽输出 CNF=10  MODE=11 */
          GPIOA->CRH |= (GPIO_CRH_CNF8_1 | GPIO_CRH_MODE8);
          GPIOA->CRH &= ~GPIO_CRH_CNF8_0;
          /* 3. 时基单元的配置  频率是2Hz的PWM */
          /* 3.1 预分频 */
          TIM1->PSC = 7200 - 1;
          /* 3.2 自动重装载寄存器的值 */
          TIM1->ARR = 5000 - 1;
          /* 3.3 计数方向 0=向上计数 1=向下计数 */
          TIM1->CR1 &= ~TIM_CR1_DIR;
          /* 3.4 重复寄存器 RCR=4 表示CNT计数器溢出5次,才会产生更新时间(中断) */
          TIM1->RCR = 4;
          /* 4. 输出部分配置 */
          /* 4.1 把通道1配置为输出 */
          TIM1->CCMR1 &= ~TIM_CCMR1_CC1S;
          /* 4.2 配置捕获比较寄存器的值 */;
          TIM1->CCR1 = 2500; /* 占空比 50% */
          /* 4.3 输出的极性 0=高电平有效 1=低电平有效 */;
          TIM1->CCER &= TIM_CCER_CC1P;
          /* 4.4 使能通道1 */;
          TIM1->CCER |= TIM_CCER_CC1E;
          /* 4.5 配置通道1输出模式: PWM1=110 */
          TIM1->CCMR1 |= (TIM_CCMR1_OC1M_2 | TIM_CCMR1_OC1M_1);
          TIM1->CCMR1 &= ~TIM_CCMR1_OC1M_0;
          /* 4.6 主输出使能(只有高级定时器需要配置) */
          TIM1->BDTR |= TIM_BDTR_MOE;
          /* 4.7 防止一启动就进入更新中断: 1. 使用UG位产生一个更新事件 2.然后预分频和重复计数器的值更新到影子寄存器 */;
          TIM1->EGR |= TIM_EGR_UG;
          TIM1->SR &= ~TIM_SR_UIF;
          /* 5. 配置中断 */
          /* 5.1 定时器更新中断使能 */
          TIM1->DIER |= TIM_DIER_UIE;
          /* 5.2 NVIC的配置 */
          NVIC_SetPriorityGrouping(3);
          NVIC_SetPriority(TIM1_UP_IRQn, 3);
          NVIC_EnableIRQ(TIM1_UP_IRQn);
      }

      void Driver_TIM1_Start(void)
      {
          TIM1->CR1 |= TIM_CR1_CEN;
      }

      void Driver_TIM1_Stop(void)
      {
          TIM1->CR1 &= ~TIM_CR1_CEN;
      }
      ```

    - **中断服务程序：TIM1_UP_IRQHandler**

      ```c
      void TIM1_UP_IRQHandler(void)
      {
          // 停掉计数器
          printf("a\r\n");
          TIM1->SR &= ~TIM_SR_UIF;
          Driver_TIM1_Stop();
      }
      ```
