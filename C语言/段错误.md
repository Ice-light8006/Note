# 一个例子
```c
char* ptr = "Helloworld";
ptr++;
(*ptr) = 'L';
```
**这段代码会导致未定义行为（在 Linux 等常见平台上通常表现为段错误）**
这段代码的错误在于：**试图修改字符串字面量（string literal）的内容**，这是**未定义行为**，通常会导致程序崩溃（如段错误）。

---

### 为什么错误？
```c
char* ptr = "Helloworld";
```
这里 `"Helloworld"` 是一个**字符串字面量**，它通常被编译器放在**只读内存区域**（例如 `.rodata` 段），是**不可修改的常量**。  
`ptr` 只是一个指向这块只读内存的指针。

接着：
```c
ptr++;         // ptr 现在指向 'e'（第二个字符）
(*ptr) = 'L';  // 尝试将 'e' 改为 'L' → 修改只读内存 → 未定义行为
```
C标准规定修改字符串字面量的内容是未定义行为，可能什么都不发生，也可能直接崩溃（SIGSEGV），且不同平台表现不一致。

---
### 如何修正？

如果需要可修改的字符串，应该**用字符数组**来存储，例如：
```c
char str[] = "Helloworld";   // 数组在栈上，内容可修改
char* ptr = str;
ptr++;
*ptr = 'L';                  // 正确，现在 str 变为 "HLlloworld"
```
或者直接使用数组下标：
```c
char str[] = "Helloworld";
str[1] = 'L';
```
---
### 总结

- **字符串字面量**（如 `"Helloworld"`）是**只读的常量**，通过指针修改它是非法的。
- 要创建可修改的字符串，必须用**字符数组**来保存副本。
- 为了避免这类错误，建议声明指向字面量的指针时加上 `const`：  
    `const char* ptr = "Helloworld";`  
    这样 `*ptr = 'L'` 在编译阶段就会报错（因为试图修改常量）。
