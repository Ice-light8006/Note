`printf`：行缓冲
`scanf`：缓冲区垃圾
# `scanf`垃圾问题
```c
#include <stdio.h>

int main(int argc,char** argv)
{
	int num;
	scanf("%d",&num);
	printf("num = %d\n",num);
	
	char ch;
	scanf("%c",&ch);
	printf("ch = %c\n");
	return 0;
}
```
这个代码如果输入如下内容
```
5
```
打印的结果为
```
num = 5
ch = 

```
为什么呢，明明`ch`的值我还没输入就已经打印出来`ch`了
这就是因为，在我输入5之后要敲一个回车，而这个回车恰好也被读入了输入缓冲区，然后输入缓冲区的内容就是`"5\n"`，然后`scanf("%d",&num);`把这个5读入给了`num`，这时输入缓冲区残留一个回车，而这个回车就被接下来的`scanf("%c",&ch);`读入给了`ch`，然后结果就是`ch`的值不需要我们输入，而是直接读取了我们在给`num`赋值的时候残留的空格。
这就是`scanf`垃圾问题。
解决办法是，我们在读入`num`之后添加一个`getchar()`，把这个残留的空格读走，如下：
```c
#include <stdio.h>

int main(int argc,char **argv)
{
	int num;
	scanf("%d",&num);
	printf("num = %d\n",num);
	
	getchar();//添加一个getchar去除输入缓冲区的残留空格
	
	char ch;
	scanf("%c",&ch);
	printf("ch = %c\n");
	return 0;
}
```
