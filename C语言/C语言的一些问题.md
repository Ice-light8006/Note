# 虚拟地址与物理地址
事实上，针对有操作系统的计算机，程序不能直接操作物理内存，只有操作系统可以直接操作物理内存。
当你在操作系统上运行一个程序时，实际上被操作系统抽象为一个**进程**，进程就是程序运行活动的抽象。操作系统会给每个进程通过抽象的方式实现虚拟地址空间，程序运行在虚拟的内存空间。我们程序员在操作系统上所看到的都是虚拟地址，而不是物理内存的地址

```c
int num = 5;
&num;
printf("%p",&num);
```
这个打印结果看到的内存地址都是虚拟内存地址
虚拟地址转换物理地址：分页管理、分段管理
有一个东西叫MMU，做的就是这件事情，把虚拟地址转换为物理地址
但是在MCU开发中，没有操作系统，这时候我们直接操作的就是物理地址
# 作用域
```c
int main()
{
	int num = 5;
	int num = 6;
}
```
这样编译器会报错
```c
int main()
{
	int num = 5;
	{
		int num = 6;
	}
}
```
这样加一个`{}`括起来就没有问题
这就是作用域，第一个`num`在整个`main`函数内都可见，而第二个`num`仅在这个花括号内可见 
```c
int num = 5;
```
如果要解释这个代码，就是：
```
定义一个整型变量num，所占内存4个字节，如果是局部变量，保存在栈空间，离开作用域后释放；全局变量 保存数据区，程序结束后再释放
```
